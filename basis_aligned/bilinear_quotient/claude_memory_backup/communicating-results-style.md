Logan wrote `basis_aligned/communicating_results.md`: lead with the current path and the delta,
tag every number as fold / edit / response / fit, state the evaluation set and whether rows are
fresh / opened / replay, keep a claim table (claim, tag, rows, numbers, status) that retains
falsified rows, two significant figures in the body, receipts in an appendix, one behaviour per
document, never call something a "circuit" before removal plus a preservation control against a
null, and never write "narrowly missed" — report the number and the gate.

**Why:** updates had read as logs and mixed evidence types; readers could not tell what would
have falsified a number.

**How to apply:** follow it in board entries, scorecards and any `explanations/for_logan/`
update; put load-bearing limitations in the summary. See [[claude-circuit-lane-2026-09-17]].
