How we took bilin18 apart

A methods primer: each technique explained with a hand-checkable toy model, its assumptions, the real implementation, and one real sentence from the held-back data.

The program decomposes an eighteen-layer language model on four ledgers: Representation (can we rewrite each component exactly, in better coordinates?), Substitutability (can we replace it with something simpler at measured cost?), Function (what is it causally doing?), and Meaning (can we name what it computes, in code, and have the name survive a held-out test?). Every method below serves one or more of those ledgers, and every causal number is a paired, held-back measurement — the same one hundred fifty-two FineWeb sequences (numbers 448 through 599), never used for discovery or fitting.

The model in three sentences. bilin18 is an 18-layer, GPT-2-vocabulary transformer with no softmax: each attention head's pattern is a product of two bilinear forms, (q1·k1)(q2·k2)/d², causal and unnormalized, and each feed-forward block is a bilinear MLP, Down(Lx ⊙ Rx) — a pure quadratic. There are 9 heads per layer (162 in all), a 1152-dimensional residual stream, and a 30·tanh soft-cap before the readout; base cross-entropy on the held-back slice is about 3.2 nats. Because every MLP is exactly quadratic, the whole network folds into an exact tensor network — which is what makes several of the methods below possible at all.

(importance rank 1)1. Mean-ablation necessity testing

(a) Intuition

The most basic causal question about a component is: does the model get worse when this piece stops doing its job? The subtlety is what "stops" means. Setting a component's output to zero does not turn it off — it feeds the rest of the network a value it has never seen, and the damage you measure is mostly the shock of that alien input, not the component's information. The honest "off" state is the component's average output — everything downstream still receives a perfectly typical value, but one that no longer depends on the context. The number reported is the increase in cross-entropy (in nats) when the component's output is replaced by its per-position mean, and it is always computed paired: for each token we take the difference between the ablated and the intact model on that same token, then average the differences — so sequence-to-sequence variation cancels and the standard error reflects only the effect itself.

(b) Toy model

A one-neuron linear predictor with two input features: prediction ŷ = 5·f1 + f2, and the true target is y = 5 + f2, with f2 = ±1 varying from example to example. On the data, f1 = 1 always — it is a constant carrier, not a computation.

  • Zero-ablation lies. Set f1 = 0: every prediction drops by 5, squared error jumps from 0 to 25 on every example. Verdict: "f1 is the most important feature in the model." False — it never carried a bit of information.
  • Mean-ablation is honest. Set f1 to its data mean, which is 1: nothing changes, error stays 0. Set f2 to its mean, 0: error becomes f2² = 1 per example. Correct verdict: all the information is in f2.
  • Where the assumption breaks: the mean must be in-distribution per position. Now let f1 alternate: +1 at even positions, −1 at odd, with target y = 5·f1 + f2. The global mean of f1 is 0 — so "mean-ablation" with a global mean is zero-ablation in disguise and reports a spurious error of 25. The per-position mean (+1 at even, −1 at odd) again correctly reports 0. This is why the program uses per-position means throughout: positional structure is kept, only content-dependence is removed.

(c) Assumptions

  • The mean is taken on-distribution and per-position; a global or zero baseline conflates "removed information" with "fed the network an impossible input."
  • Necessity is measured one component at a time — so it silently fails when a function is duplicated across components (see method 6) or carried by a redundant code (method 8): a component can matter and still show zero.
  • Paired differences require evaluating the same tokens under both models; the standard error is over per-token paired differences.
  • The verdict is distribution-relative: a component unnecessary on FineWeb prose may be necessary on code or tables.
(d) Real implementation

This is the causal workhorse behind every verified circuit (the harness in qk_unsup_verify.py, reused verbatim by every later detector). The zero-point lesson was learned the hard way and is on the record: switching from zero-ablation to per-position mean-ablation deflated every layer's apparent pattern load 10–60× — layer 5's attention pattern fell from +2.303 nats (zero-ablated) to +0.036 nats (mean-ablated), layer 2 from +0.390 to +0.027. Ninety-plus percent of the "importance" had been the off-distribution shock. A typical verified positive: attention head 6 of layer 9 (h.L9.6), a sentence-boundary subject-pronoun predictor, costs +0.077 ± 0.023 nats (3.3 standard errors) at its firing positions when mean-ablated.

(e) Held-back example
"…by far the best selection of plants I have seen. Quite the drive but worth it." → " They" Held-back FineWeb, sequence 451 (held index 3), position 28. The head fires on the sentence-ending period; the actual next token is " They".

This is exactly the class of position where h.L9.6 earns its +0.077 nats: on a sentence-final period it boosts the next sentence's subject pronouns (they / it / They / that). What we learned: a real but modest grammatical circuit, discovered unsupervised and priced against an honest zero point — under zero-ablation its cost would have been buried inside a fake load an order of magnitude larger.

(importance rank 3)2. Sufficiency / keep-subset testing

(a) Intuition

Necessity asks "what breaks when I delete this part?"; sufficiency asks the mirror question: "if I keep only this part and delete everything else, how much function survives?" These sound interchangeable and are not. In any system with backup copies, deletion tests read zero on every part (each removal is compensated), while keep-subset tests reveal that a small fraction of the parts carries essentially the whole function. A component can therefore be completely opaque to necessity-based attribution and perfectly transparent to a sufficiency hierarchy. The two are different ledgers, and you need both.

(b) Toy model

A two-copy code. A signal s ∈ {+1, −1} is written into two channels, c1 = s and c2 = s, and the readout is y = (c1 + c2)/2, classified by its sign. Intact: y = s, always correct.

InterventionySign correct?What the test concludes
Delete c1 (set to 0)s/2yesnecessity of c1: zero
Delete c2s/2yesnecessity of c2: zero
Keep only c1 (delete c2)s/2yesc1 alone is 100% sufficient
Delete both0chancethe function existed all along

The necessity ledger sums to zero over all parts; the sufficiency ledger says half the parts carry everything. Both are true — that pair of statements is the signature of redundancy (this exact toy returns, quantitatively, in method 8). Where the assumption breaks: sufficiency identifies a sufficient carrier, not the mechanism. Add a third channel c3 that merely correlates with s on the training distribution (say, it copies s in the data you test on but is causally driven by something else). Keep-only-c3 passes the sufficiency test on-distribution and fails off-distribution — sufficiency claims are distribution-bound and do not confer uniqueness.

(c) Assumptions

  • Deleting "everything else" must use the same honest zero point (per-position means), or the kept part is evaluated inside a broken model.
  • A sufficient subset is not thereby the mechanism: other subsets may be equally sufficient (in redundant codes, most are).
  • Sufficiency is distribution-relative; a correlated bystander can pass on-distribution.
  • Comparing kept-subset choices requires a control: the same-size random subset. Without it, "compact sufficiency" might just be "any large-enough fragment works."
(d) Real implementation

The decisive use was on the layer-1 feed-forward hub (MLP1), the model's single largest component (removing it costs 5.574 ± 0.032 nats), where every necessity-based tool — single directions, sparse-autoencoder features, searched coalitions of up to 512 features — had returned essentially nothing (methods 7 and 8 tell that story). The keep-subset test (qk_hub_hierarchy.py): replace the hub's 1152-dimensional output by its mean plus the projection onto only the top-K principal directions. Keeping 144 of 1152 directions loses only 1.5% of the hub's function (+0.084 nats of 5.574); keeping a random 144 loses 61% — the principal hierarchy beats random forty-fold. Extending the same idea to the computation itself (qk_hub_maprestrict.py): the hub's bilinear map restricted to 288 input × 144 output directions — roughly 128× fewer coefficients — retains 96.7% of its causal function.

(e) Held-back example
"…up to an application layer transparent proxy and optional gateways to anonymous networks such as Tor and I2P." → " It" Held-back FineWeb, sequence 466 (held index 18), position 80.

Sufficiency statements are whole-distribution statements, so the honest per-example reading is this: at every token of this sentence — and every other held-back token — swapping the hub's full 1152-dimensional output for "mean plus its top 144 principal directions" changes the model's next-token predictions by 0.084 nats on average, about a one percent perturbation. What we learned: the component that was unattributable in parts is compactly sufficient in the right basis — necessity-blindness was a property of the test, not of the hub.

(importance rank 2)3. The exact bilinear fold

(a) Intuition

A bilinear MLP computes Down(Lx ⊙ Rx): two linear maps, an elementwise product, a linear read-out. Because there is no ReLU or sigmoid anywhere, this is a pure quadratic polynomial in the input — and any quadratic can be rewritten, exactly, as a single third-order tensor T acting on two copies of the input. The rewrite kills the neuron basis: permuting or rescaling hidden neurons changes L, R, Down but leaves T untouched, which is why this program never interprets individual neurons — the neuron basis is pure gauge, an arbitrary bookkeeping choice. All later structure (terms, streams, restricted cores, the certified proxy) is analysis of T, and it inherits T's exactness: the fold is a change of coordinates, not an approximation.

(b) Toy model

Two-dimensional input x = (x1, x2), two hidden neurons, one output:

L = [[1, 1], [0, 1]], R = [[1, 0], [1, −1]], Down = [2, 1].

Then Lx = (x1+x2, x2) and Rx = (x1, x1−x2), so the hidden product is ((x1+x2)x1, x2(x1−x2)) and the output is

y = 2(x1² + x1x2) + (x1x2 − x2²) = 2x1² + 3x1x2 − x2².

That polynomial is the folded tensor: T = [[2, 1.5], [1.5, −1]] (symmetrized, so the two off-diagonal entries share the 3). Check at x = (1, 2): the network path gives Lx = (3, 2), Rx = (1, −1), product (3, −2), output 2·3 + 1·(−2) = 4; the tensor path gives 2·1 + 3·2 − 1·4 = 4. Same number, by identity. Gauge invariance by hand: double hidden neuron 1's L row and halve its Down weight — L = [[2, 2], [0, 1]], Down = [1, 1]. The three matrices all changed; recompute T and you get [[2, 1.5], [1.5, −1]] again. Neuron-level stories about "what neuron 1 does" changed; the function did not. Where the assumption breaks: put a ReLU on the hidden layer and the output becomes max(0, x1+x2)·… — piecewise, not polynomial, and no finite tensor reproduces it. The fold is an architecture property (bilinear and gated-SwiGLU models do not have it), not a universal method.

(c) Assumptions

  • Exact bilinearity (no ReLU, GELU, or SwiGLU gating in the MLP). Provably fails for standard transformers — on those, only the fold-free surrogates below apply.
  • Normalization must fold out too: for rms-norm this is exact — MLP(rms(x)) = D·T(x,x)/‖x‖² + bias, a scalar gauge — verified at ~10⁻⁷.
  • Every use of the fold is gated: reconstruction is checked at ~10⁻⁶ relative error, globally and at the worst position, before any conclusion is drawn from it.
  • Exactness of representation does not mean compressibility: naked rank-truncation of the folded cores fails (measured); compression has to come from stream structure (methods 4 and the restricted cores).
(d) Real implementation

Every feed-forward block of bilin18 is folded, and every layer's composed fold reconstructs the model at relative error ≈ 1.25 × 10⁻⁶ (individual gates from 4.8 × 10⁻⁷ to 1.6 × 10⁻⁶; scripts qk_hub_streampairs.py, qk_allterm_census.py, the composed-fold arc). The value of exactness was quantified by racing the fold against the best fold-free alternative (qk_fold_necessity.py): a rank-matched generic low-rank surrogate — the kind of thing you can fit on any architecture — leaves the model broken at +4.86 nats, while the exact fold chain leaves +0.034; on the softmax SwiGLU control model, where no fold exists, the generic surrogate is stuck at +3.42 with nothing to close the gap. Approximate structure is three-quarters architecture-general; faithfulness is all fold.

(e) Held-back example
"…These two varieties have thicker shells than the standard European walnuts. For walnut production, Black Walnut (Juglans niger)…" Held-back FineWeb, sequence 448 (held index 0), positions 79–86.

On this sentence — and on every held-back sentence — the folded tensor-network rewrite of bilin18 reproduces every next-token logit to about one part in a million: the bracket is closed, the Latin name is continued, with bit-level agreement for practical purposes. What we learned: nothing about this text in particular, and that is the point — the fold is not a model of the model but the model itself in different coordinates, which is what licenses every term-level surgery in the entries below.

(importance rank 4)4. Stream / provenance term decomposition

(a) Intuition

A layer's input is not an anonymous vector — it is an exact sum of contributions with known provenance: the token embedding, each earlier attention output, each earlier feed-forward output. Feed a sum into a bilinear map and the algebra does something wonderful: T(a+b, a+b) = T(a,a) + 2T(a,b) + T(b,b). The layer's computation splits, exactly, into named pairwise interaction terms — "embedding times context," "previous block squared" — each a causal object you can keep or delete on its own. Where learned features give you anonymous directions, the architecture's own coordinates give you a small set of terms with English names.

(b) Toy model

Reuse the folded tensor from method 3, T = [[2, 1.5], [1.5, −1]], and split the input x = (1, 2) into two streams: a = (1, 0) (say, "the current token's embedding") and b = (0, 2) ("what attention brought in"). Writing B(u, v) for the symmetric bilinear form:

Note the cross term is the largest: the layer is not "a function of the token plus a function of the context" — it is their product. That is what a bilinear layer is for, and the toy already shows it. Where the assumption breaks: the split requires that the streams sum exactly to the input (a gate you must check) and that the map is bilinear (method 3's assumption). On a softmax-SwiGLU model no term expansion exists; the best you can do is mean-ablate one input group at a time — a coarser intervention that recovers the flow map but not the interaction terms.

(c) Assumptions

  • Bilinearity (method 3), plus an exact stream-sum gate: the named streams must reconstruct the layer input to ~10⁻⁶.
  • Terms are exact but not orthogonal: their energies can exceed 100% under cancellation (layer 17 does exactly this — see method 9), so keep/delete costs, not energy shares, are the causal currency.
  • Naming a term ("embedding × context") names its provenance, not automatically its function; function still comes from causal tests on the term.
(d) Real implementation

On the layer-1 hub (qk_hub_streampairs.py), the four input streams — embedding, attention-0, MLP-0, attention-1 — give ten pairwise terms, and the decomposition is exact at 9.8 × 10⁻⁷. The headline: five named terms restore essentially the full 5.574-nat function (keeping them costs only +0.0019 ± 0.0006 nats) — after sparse autoencoders and principal directions had failed to find any compact causal split of the same component. Three structural facts fell out at once: the attention-0 row is causally dead through the hub (deleting all four attention-0 terms costs 0.0000 nats; each kept alone is indistinguishable from keeping nothing); the hub is an interaction device (keeping only the four same-stream "diagonal" terms costs +0.525, keeping only the six cross terms costs +0.044 — ten times less); and the embedding-squared term is a bigram-table-like correction (the current token's identity alone explains 90% of its variance). The census extension to all 18 blocks (qk_allterm_census.py) found the early stack compact (2–5 terms to 95%) and produced this gem: layer 2 is almost literally "square the previous block's output" — its mlp-recent² term alone leaves just 0.093 of its 0.739-nat floor, and two named terms cover 98% of the layer.

(e) Held-back example
"…A corollary branching off from this thought is that AMISOM is a project perpetrated at the expense of the Somali people." → " It" Held-back FineWeb, sequence 483 (held index 35), position 53.

Walk the streams at that period: the embedding stream carries the token "." itself; the MLP-0 stream carries its transformed identity ("this is a clause boundary"); the attention-1 stream carries a summary of the sentence gathered from earlier positions. The hub's function at positions like this lives in the products — its context-carrying terms are context-gated content-word boosters (at their firing sites the MLP-0 × attention-1 term pushes word-class logits by +1767 and capital-class by +1160, while damping them elsewhere). What we learned: "boundary, and context says a new sentence is coming" is computed as boundary × context, not boundary + context — the interaction structure is the mechanism, and it was invisible until the input was split by provenance.

(importance rank 7)5. Trigger and effect fingerprints — and type-specific causal detectors

(a) Intuition

Every candidate circuit has two faces: a trigger (what contexts make it fire — readable from its top-activating positions) and an effect (what it does to the prediction). The program's most-repeated empirical lesson is an asymmetry between them: trigger fingerprints generalize — in every verified case the trigger held on data the circuit was not discovered on — but the cheap effect read-out (project the circuit's output straight onto the vocabulary, the "direct-to-logits linear proxy") is unreliable: it has been wrong in magnitude, in sign, and even in letter-case, because the true effect passes through the downstream layers and the 30·tanh cap. The consequence is architectural for the whole toolbox: effects must be read from causal ablation, and — since "the effect" of a copy head, a class-pusher, and a suppressor are different kinds of object — each circuit type needs its own causal test.

(b) Toy model

A path writes p onto the residual; the readout would score it directly, but a downstream layer also responds. Let the downstream response be d = −1.5·p (a damping layer), so the token-A logit is p + d = −0.5·p.

  • The linear proxy reads only the direct write: with p = 2 it reports "+2 on token A — this path boosts A."
  • Causal ablation removes p and lets the downstream layer respond: the logit changes from −0.5·2 = −1 to 0, i.e. removal raises the token-A logit by 1. The path is really a net suppressor of A. The proxy got the sign wrong by design, and no amount of averaging fixes it — the error is structural (the proxy deletes the downstream response).

Type-specificity in the same toy: suppose instead the path copies whatever token it attended to. Then there is no fixed direction to score at all — its "effect" is a different object per position (the attended token's logit). A fixed-direction purity metric scores it near zero however strong it is; the right test is source-specific: does ablation drop the logit of the attended token, versus random tokens? One causal question per circuit type.

(c) Assumptions

  • Trigger fingerprints are trusted only after an out-of-sample check on a disjoint slice (this filter alone killed a family of rare-suffix "circuits" whose purity collapsed from high to 0.000 out of sample).
  • The direct-to-logits proxy is assumed unreliable by default; it may rank candidates but never states an effect. (Method 10 is the structural fix.)
  • Each detector's verification move must match its circuit type: class-summed logit movement for class-pushers, source-specific logit drops for copy heads, rise-on-ablation for suppressors, joint ablation for redundant families.
  • Cleanliness is not importance: measured across all 234 paths, the cleanliness score and causal importance correlate at Pearson 0.006 — essentially zero.
(d) Real implementation

The detector catalog (TECHNIQUES_unsup_discovery.md) grew to ten type-specific tools; two exemplars. The copy / value-router detector (qk_unsup_copy.py, qk_arc_digits.py): attention head 3 of layer 8 (h.L8.3) attends to digit tokens (out-of-sample trigger purity 0.97) and is a verbatim value-router — ablating it drops the attended token's logit by 0.809 ± 0.077 relative to random tokens, and its damage concentrates entirely where the next number can be copied from earlier context: +0.155 ± 0.032 nats on copyable next-digit positions versus +0.000 ± 0.008 on non-copyable ones. Its neighbor h.L8.7 is the exact mirror (damage only on non-copyable positions, no source boost) — one "digit head" cleanliness class, two different algorithms, separable only by the causal dissociation. The class-push detector (qk_unsup_classpush.py): built after the census showed the cleanliness ranking misses the model's largest effects (distributed pushes over a whole token class). It ranks by causal importance and characterizes effects by class-summed logit movement; its score tracks true importance at Pearson 0.986 (versus 0.006), and its strongest find, feed-forward direction mlp.L17.d1, pushes the capital class with specificity z = 48.6.

(importance rank 5)6. Joint ablation / redundancy detection

(a) Intuition

Single-component ablation cannot tell "this part is useless" from "this part has a backup." Both read as zero. The discriminating experiment is to ablate a candidate family together and compare the joint damage to the sum of the solo damages: a redundancy ratio near 1 means the parts are independent (and if all are near zero, genuinely unimportant); a ratio well above 1 means the family shares a duplicated function that only appears when all copies are removed. The essential control is a same-size random set of components: joint ablation of anything removes capacity, so the family must beat every random draw, not just zero.

(b) Toy model

Two heads each independently deliver the same evidence: h1 = 1.2 and h2 = 1.2, the decision variable is y = h1 + h2 = 2.4, and the prediction is correct as long as y ≥ 1 (loss = max(0, 1 − y)).

InterventionyLoss
Intact2.40
Ablate h1 only1.20
Ablate h2 only1.20
Ablate both01

Sum of solo damages: 0. Joint damage: 1. Redundancy ratio: effectively infinite — the pure signature. Each head, examined alone, is indistinguishable from a dead head; the pair is load-bearing. Where the assumption breaks: a large joint effect alone proves nothing — ablate any two of a model's components and you may cross some capacity threshold. Add a third, unrelated head h3 to the toy and ablate the random pair {h1, h3}: if that also breaks the model, "redundant family" was the wrong conclusion. The claim requires the specific family to exceed all same-size random sets, and (a second control) the effect must vanish when the family is ablated at random positions instead of its own firing positions.

(c) Assumptions

  • The family hypothesis comes from somewhere (a shared trigger fingerprint, method 5); joint ablation tests it but does not generate it.
  • Same-size random-set control is mandatory (rules out generic capacity loss), as is the random-positions control (rules out unspecific damage).
  • Greedy minimal-subset search is a heuristic; report the subset with its recovery fraction, not as "the" circuit.
  • Significance versus the random control is control-pool-dependent; report the order of magnitude, not a point z-value.
(d) Real implementation

qk_unsup_redundant.py, on the copy-head family the copy detector had flagged as "clearly copying yet individually near-null" ({L8H3, L8H4, L13H0, L14H7, L7H3, L5H5}): joint damage +0.430 ± 0.051 nats versus a solo sum of 0.111 — redundancy ratio 3.86. A minimal four-head subset {L8H3, L5H5, L7H3, L8H4} recovers 87% of the joint effect. The family exceeds all forty same-size random draws (significance of order ten-plus standard deviations, draw-dependent), and ablating it at random positions collapses the effect from 0.430 to 0.033 — specific, not capacity. The copy output collapses only jointly: the attended-source token survives as the model's top-1 under any single ablation, but its median rank drops from 1 to 7 under joint removal. The honest negative that certifies the tool: the diffuse newline cluster has ratio 1.12 and does not beat random (z = 0.68) — genuinely unimportant, not redundant. Single ablation could not have told these two clusters apart.

(importance rank 8)7. Sparse dictionaries: naming vs reconstructing vs explaining

(a) Intuition

A sparse autoencoder (a learned overcomplete dictionary with few features active per token) is the standard tool for finding interpretable features in activations. The program used it as a red-team against its own "this component is irreducibly distributed" claim — and the result was a three-way split that has become a slogan: naming, reconstructing, and explaining are three different things. A dictionary can find beautifully monosemantic features (naming) and rebuild the component's output with high fidelity (reconstructing) while attributing essentially none of the component's causal effect to any feature or feature set (explaining). Purity and fidelity are variance-level facts; causation, in a redundant code, lives elsewhere.

(b) Toy model

The two-copy code from method 2, now attacked with a dictionary. Activations are two-dimensional: h = (s, s), with s = 1 on half the data (say, on determiner tokens) and s = 0 elsewhere. The downstream readout is y = (h1 + h2)/2, thresholded at 0.5.

  • Naming: perfect. The dictionary learns f1 = h1, f2 = h2. Each fires exactly on determiners — trigger purity 1.00, a textbook monosemantic feature you would happily christen "the determiner feature."
  • Reconstructing: perfect. f1·(1,0) + f2·(0,1) = h exactly; fraction of variance explained 1.00.
  • Explaining: zero. Mean-ablate f1 (h1 → its mean, 0.5): y = (0.5 + s)/2 ∈ {0.25, 0.75} — the threshold still classifies every token correctly, causal effect 0. Same for f2. Every feature attribution is zero, yet ablating both gives y = 0.5 everywhere: chance. The function was real, collectively carried, and invisible to per-feature accounting.

Where the naming itself can mislead: the toy's features are only "the determiner feature" on this data; the causal claim buried in the name (this feature makes the model do something determiner-related) was never tested and is false — each feature is individually bypassable. The name describes variance, not mechanism.

(c) Assumptions

  • Feature interpretability is judged by trigger class purity with an enrichment bar, out of sample — not by eyeballing top tokens.
  • Reconstruction fidelity must be reported held-out (train fidelity overfits; here the held ceiling moved from 0.72 to 0.85 only when the training corpus grew tenfold).
  • Causal capture is measured with the same mean-ablation currency as everything else, per feature and cumulatively — plus the two-sided control: ablate the reconstruction (keep the residual) and ablate the residual (keep the features). If both are individually inert, the encoding is collective.
  • A dictionary failing to explain is weaker evidence than one succeeding — hence the escalation: bigger dictionaries, converged training, ten times the data, feature coalitions. The negative had to survive all of them before being claimed.
(d) Real implementation

On the layer-1 hub (qk_redteam_sae_hub.py, qk_sae_converged.py, qk_sae_moredata.py): the best dictionary (16,384 features, 64 active per token, ten-times corpus) reaches held-back reconstruction fidelity 0.85 and 17–26 of its top 32 features are monosemantic (versus 0 of 32 for raw principal directions — naming genuinely crossed a boundary SVD could not). But causally: 0 of 32 features clear the load-bearing bar, and all 16,384 features together capture 2.01% of the hub's 5.57-nat effect — a number that stayed flat (2.15%, 2.22%, 2.01%) across every fidelity from 0.69 to 0.85. Coalition search over up to 512 features across five construction families never reached 1% at size 128. The result replicates on the softmax SwiGLU model's hub (qk_sae_swiglu_hub.py) in its sharpest form: the SAE reconstruction, substituted whole, carries 98.7% of the layer's function — causally sufficient as a whole, unattributable in parts.

(e) Held-back example
"…on the basis of presidential decisions. He must learn to rely on people to fulfill the mandate of his regime.\nAs part and parcel of the leadership, the cabinet must share the qualities of the president." Held-back FineWeb, sequence 477 (held index 29). Every " the" highlighted.

The dictionaries reliably learn a pure determiner feature — on bilin18 a " the"-feature enriched 11.7× over base rate, on the SwiGLU model several features firing on " the" alone at purity 1.00 — which would fire six times in this one passage. Mean-ablating that beautifully nameable feature does nothing measurable to the model's predictions here or anywhere. What we learned: a feature can be perfectly named and causally null at once; a dictionary of such features is a description of the activations' variance, and treating it as a decomposition of the computation is the precise mistake this experiment was built to expose.

(importance rank 6)8. Redundant-code diagnostics: amplitude and random-subspace sweeps

(a) Intuition

After methods 6 and 7, a suspicion forms: maybe the reason no part of a component is necessary is that its output is a redundant code — the same message written many times over, like an error-correcting code, so that any fragment of the signal suffices and no fragment is needed. That hypothesis makes two quantitative predictions you can test directly without knowing what the message says: (i) amplitude robustness — scale the whole output toward its mean by a factor alpha and the function should survive far below alpha = 1; (ii) dimension redundancy — delete the output's projection onto a random subspace and the function should survive until most of the space is gone, then fall off a cliff. Flat-then-cliff on both sweeps is the fingerprint of sufficiency-without-necessity, and it tells you in advance that every deletion-based attribution tool will read zero.

(b) Toy model

A four-fold copy of method 7's code: h = s·(1, 1, 1, 1), s ∈ {0, 1}, readout y = mean(h), threshold at 0.4.

Flat, flat, flat, cliff — half the amplitude free, half the dimensions free, breakdown only near total removal. Both sweeps are computable in your head, and both would be reported as "no single dimension matters" by any deletion-based attribution. Where the assumption breaks: the flatness depends on the downstream consumer being tolerant (here a threshold; in the real model, layers that renormalize). If the readout were linearly loss-sensitive to y, the amplitude sweep would show graded damage, and flatness would falsely suggest the component does nothing. The sweep diagnoses the code only relative to the actual downstream consumers — which is why it is run through the real model, not a probe.

(c) Assumptions

  • The sweeps scale or delete the component's deviation from its per-position mean (method 1's zero point), through the full downstream model.
  • Random-subspace deletion must be averaged over draws; a single unlucky subspace can align with structure.
  • Flat-then-cliff supports "redundant code," not "no computation" — the distinction is the full-removal endpoint (here 5.574 nats, enormous).
  • Conclusion transfers to attribution methodology: the floor of any deletion-based attribution is set by the code's redundancy margin, not by the analyst's skill.
(d) Real implementation

qk_hub_threshold.py, on the layer-1 hub. Amplitude: keeping only half the amplitude costs +0.069 ± 0.003 nats — 1.2% of the 5.574-nat full effect; three-quarter amplitude costs 0.13%; even quarter amplitude retains 63% of function. Dimensions: deleting the projection onto a random half of all 1152 dimensions costs +0.095 ± 0.003 (1.7%); deleting 75% costs 16%; the model only breaks past roughly 90% deletion (75% of the effect appears there). Sufficiency without necessity, quantified — and it is the single mechanism behind the program's two hardest puzzles: it is why every deletion tool (methods 6 and 7, plus coalition search) read approximately zero on the hub, and, remarkably, why mid-stack activation injections also fail (method 9's washout): the code erases tampering in either direction, because the readout re-derives its message from the many untouched copies.

What we learned: the sufficiency-without-necessity signature is not exotic — it is the normal condition of context-conditioned base rates in this model, from single heads all the way up to the hub.

(importance rank 9)9. Editing: amplitude dials vs input transplants

(a) Intuition

If you understand a circuit, you should be able to steer it. Two fundamentally different handles exist. An amplitude dial scales a component's own output (its deviation from mean) by a factor alpha — cheap, graded, reversible, but it can only make the component's existing writes louder or quieter: it scales the writes where the component already decided to write them, and cannot re-aim that decision, because the conditioning is encoded in the activation pattern itself. An input transplant instead replaces what the component reads — donate the "context" input from a position where the desired behavior is natural — and re-aims the decision itself. The program's closing law: amplitude edits cannot re-aim; input edits re-aim surgically, but only at the readout layer, because everywhere else the redundant code (method 8) re-derives the conditioning from unedited copies and washes the injection out.

(b) Toy model

y = g(c)·x with x = 1, and a hard gate: g(c) = 1 if the context c is a sentence boundary, else 0. The unit adds y to the capital-letter logit.

No value of alpha makes a mid-sentence capital happen: the dial multiplies a zero. Replacing c does it exactly and only at the edited position. Where the transplant's assumption breaks: give the downstream consumer a second, unedited copy of the context, g′ = majority(g(c), g(c2)), and transplanting c alone changes nothing — the consumer re-derives the gate from the intact copy. That is the washout: input edits work only where no redundant copy remains to outvote them.

(c) Assumptions

  • Dials scale the deviation from the per-position mean (sign-safe, with alpha = 1 the identity and alpha = 0 exactly the mean-ablation used in discovery).
  • Every dial needs a placebo: a random direction (or negligible-energy term) of matched norm swept over the same alphas.
  • Specificity is a measured ratio (targeted change per off-target cross-entropy cost), not an impression; report the whole dose-response curve, including where it saturates or reverses.
  • Transplant claims require the collateral gate (logit changes at all non-edited positions — here literally 0.0, bit-identical) and donor controls (random-position donors, norm-matched placebo).
(d) Real implementation

Three generations of handle on the capitalization machinery. The direction dial (qk_edit_capselector.py): scaling the verified capital-selector mlp.L17.d1 sweeps capital probability at capital-due positions monotonically 0.37 → 0.69 across alpha ∈ [−2, 4] (Spearman 0.94, placebo 25× smaller) — but forcing capitals where they are not due costs runaway global damage: the conditioning lives upstream. Term dials (qk_edit_terms.py, on the layer-17 differential pair — the readout's two dominant provenance terms, whose class-writes are anti-aligned at cosine −0.965, a push-pull contrast stage): amplitude edits still cannot re-aim, and now we know why (scaling a term scales its writes without re-aiming them), but a genuinely new knob appeared — scaling the pair coherently doubles the contrast at only +0.053 nats global cost and improves bracket-open decisions by −0.255 ± 0.040 nats (six standard errors better than the natural model; the incoherent single-arm version instead blows those positions up by +1.296). Input transplants (qk_stream_transplant.py): donating boundary context into the readout's input at 500 mid-sentence positions raises capital probability by +0.0280 ± 0.0032 (nine standard errors) via the attention-history group — and by +0.2474 ± 0.0120 via the accumulated feed-forward history — with collateral over all 18,134 unedited positions exactly zero, bit-identical. The scope test (qk_transplant_depth.py): the same transplant retains 0.7% of its force at layer 8, 3.0% at layer 12, 5.5% at layer 15, 100% at layer 17 — the boundary is washout, not collateral, and the washout mechanism is method 8's redundant code erasing the injection.

(importance rank 10)10. The certified restricted-core proxy

(a) Intuition

Causal ablation is the gold standard but costs a full forward pass per candidate per token; a discovery loop screening hundreds of candidates needs a cheap predictor of "what would ablation say?" The obvious cheap predictor — propagate the candidate's perturbation linearly to the logits — is the proxy that lied all over this program (methods 5 and 6). The fix uses the fold: propagate the perturbation through the actual downstream layers, but with each downstream bilinear MLP replaced by its folded compact core (the method-2 restriction: top input and output principal directions from training data; attention kept exact). The restricted model is a poor absolute predictor — but paired causal differences ranked through it track the truth, because polynomial cores preserve the causal ordering that linearization destroys. "Certified" means the trust is earned by controls: a random-basis version must collapse (proving the specific cores carry the signal) and fidelity must improve with core rank (proving the errors are capacity, not concept).

(b) Toy model

A two-layer polynomial model. The residual is three-dimensional, r = (r1, r2, r3); a downstream quadratic layer computes f(r) = r1·r2 and the output is o = r1 + f(r). A candidate path writes p = (1, 0, 0); the baseline residual (everything else) is b = (1, −3, 0.2).

  • Truth: with the path, r = (2, −3, 0.2): o = 2 + (2·−3) = −4. Ablated, r = (1, −3, 0.2): o = 1 + (−3) = −2. The path's true effect on the output is −2 (it hurts).
  • Linear proxy (direct write only, downstream response deleted): the path adds +1 to r1, so predicted effect +1. Wrong sign — it never sees that raising r1 doubles a negative product downstream.
  • Restricted core: keep the downstream layer quadratic but restrict it to the two principal directions the training data actually varies in (e1, e2): f̃(r) = f(projection onto e1, e2) = r1·r2, unchanged. Predicted effect: −4 − (−2) = −2. Exact, at two-thirds the width.
  • Certification control: restrict instead to a wrong basis containing e3 but not e2: f̃ loses the r1r2 product, predicts +1 — collapses back to linear-proxy quality. The right compact basis, not compactness itself, carries the causal signal.

Where the assumption breaks: the toy also shows the failure mode — if the function had been f(r) = r1·r3 and the training data never exercised r3, the data-derived basis would drop the load-bearing direction and the proxy would fail while looking certified on-distribution. The certification catches basis-quality failures you can test for (random-basis collapse, rank sensitivity), not distribution shift.

(c) Assumptions

  • Downstream cores must be foldable (method 3) to be restrictable-with-nonlinearity-intact; attention and the readout are kept exact.
  • The restriction bases come from training-data statistics; ground truth stays on held-back data.
  • Certified means: random-basis control collapses, fidelity rises with rank, and a positive control reproduces known ablation numbers exactly.
  • The proxy is a candidate ranker; full-model causal ablation remains the final gate for any claim.
(d) Real implementation

qk_certified_proxy.py, on 24 census candidates against full-model ablation ground truth. The linear proxy, at its strongest fair version: Spearman rank correlation 0.43, sign agreement 0.67–0.73, and characteristically wrong on every early-layer path — the previous-token head h.L0.3 has true effect +0.061 nats; the linear proxy predicts −0.0001 (nothing), because the head's effect acts entirely through downstream computation that linearization deletes. The restricted-core proxy: Spearman 0.81 (sign agreement 0.91, and 1.00 on sign-clear cases), recovering every early-layer case (h.L0.3 predicted +0.090); at double core rank it reaches Spearman 0.93, Pearson 0.99, perfect sign. Certification: random orthonormal bases of the same rank collapse fidelity to 0.59. The recurring "the proxy lies" lesson now has a structural fix, and every detector in the toolbox inherits it as its ranking stage.

(e) Held-back example
"…deliver apps. Secondly WP7 has a far more powerful version of Bing - which includes scout, voice search, video search, barcode recognition etc etc." → " Also" Held-back FineWeb, sequence 449 (held index 1), position 98.

A capitalized discourse opener after a sentence boundary — the very distinction the linear proxy once got wrong at the letter-case level: for the sentence-opener head h.L6.0, the proxy surfaced the lowercase shadow ("therefore", "also") while causal verification showed the true output is the capitalized openers (" Lastly", " Finally", " Similarly", " Additionally" — the class this position's " Also" belongs to), because the case correction happens in the downstream layers the proxy skips. What we learned: the difference between "also" and " Also" is a downstream computation — a proxy that deletes downstream computation cannot see it, and a compact proxy that keeps the downstream nonlinearity can.

Coda: how the ten methods fit together

Read in order, the arc is one story. Honest necessity testing (1) found the model's individually nameable circuits; sufficiency testing (2) caught what necessity is structurally blind to. The fold (3) turned the model into an exact object whose own coordinates (4) finally decomposed the component that learned features could not. Fingerprints and type-specific detectors (5) industrialized discovery; joint ablation (6) explained the first wave of "null" heads as redundancy; sparse dictionaries (7) proved that naming, reconstructing, and explaining are three different achievements; the code diagnostics (8) measured the redundancy that unifies all the negatives. Editing (9) converted understanding into control and found its two-sided law, and the certified proxy (10) closed the loop by making the discovery machinery trust-worthy at scale. Every number above is a paired, held-back measurement, and every headline positive shares the page with the control or honest negative that certifies it.

11. Freeze-patch mediation — who consumes a component's output? (importance rank: mid-tier — enabled the flow map, but only with its control)

(a) Intuition. To learn where a component's output goes, ablate it and then freeze a candidate downstream consumer to its clean (un-ablated) value. If the damage largely disappears, the ablated component's influence was routed through that consumer. Sweeping the frozen block over depth yields a flow map: which stages feed the next stage, and which write output directly.

(b) Toy model. Let block A compute a = x, block B compute b = a·a (it squares A's output), and the loss read only b. Ablate A (set a to its mean 0): the loss collapses. Now freeze B to its clean value b_clean: the loss is fully restored — 100 percent of A's damage is "rescued," correctly showing B is A's consumer. The assumption breaks when B is compensatory rather than a pure router: let b = a + r, where r is a redundant copy of the same signal. Ablating A costs little (r covers it) — but now inject a random perturbation into a and freeze B clean: the rescue is again large, even though B has no special relationship to the perturbation. A big freeze-rescue by itself does not prove routing; it can mean the downstream stage absorbs any deviation. The mandatory control: measure the same freeze-rescue for a matched-norm random perturbation, and quote the excess of the real rescue over the generic one.

Assumptions. (1) Freezing is first-order — the frozen block is inconsistent with the ablated stream, so fractions need not sum to one. (2) A large rescue is only evidence of routing relative to the generic-compensation control. (3) Upstream freezes must rescue exactly nothing (causal sanity gate).

(d) Real implementation. The depth-first flow map of bilin18 (results sections 96, 98, 99, 101; scripts qk_arc_square_2.py, qk_cascade_end.py, qk_redteam_arcs.py). Freezing block 3 clean removes 84 percent of block 2's ablation damage, and freezing block 4 removes 83 percent of block 3's — but the circularity control found matched random perturbations get 66-to-68-percent rescues, so the chain-specific excess is seventeen-to-twenty points early, shrinking to six by block 5. The corrected reading: preferential next-block consumption inside a broadly compensatory stack. Upstream-freeze controls were exactly zero.

(e) Real text example. Block 4's strongest deviation fires on but after a concessive clause — held-back snippet: "...Graphics ideas are still welcome, but" — and pushes word-class probability at that position; yet its direct write to the readout carries only 6.8 percent of the push. Ninety-four percent of what this block does at that comma-but juncture reaches the loss only through later blocks' squares — the fingerprint of a cascade-region component, versus block 14's comma-inside-numbers deviation whose direct write is the whole story.

Related upgrade to method 2: the sufficiency family gained a new member in this series — the token-conditional-mean substitute: replace a whole block's output with "the average output for this current token." For block 0 this lookup-table surrogate recovers 85.5 percent of the block's causal function, converting a variance identity into a causal sufficiency statement.

12. Cross-layer term folding — the consumer names the gate (importance rank: mid-tier — powerful, but so far applied to specific sites)

(a) Intuition

A component that "looks conditional" — it helps at one position and hurts at the next, or seems to mean different things after different tokens — is usually being multiplied by something downstream. In a bilinear network you can find out by what: substitute the component's exact output expression into the bilinear form of the block that consumes it. The consumer then expands, exactly, into a sum of product terms, each pairing two upstream sources — and the context that was gating your component stops being a hidden variable and appears as its explicit multiplicative partner term. Ranking those terms by deletion and by keep-alone does for cross-layer structure what the stream terms of method 4 did within a single layer.

(b) Toy model

A two-layer bilinear toy. Layer 1 computes a from the input; layer 2 receives s = a + b, where b is fresh context arriving at layer 2, and outputs y = s² = (a + b)². Expanding is exact: y = a² + 2ab + b² — three terms with provenance: layer-1-squared, layer-1 × context (the cross-layer term), and context-squared. Take a = 2, b = 3, so y = 25 = 4 + 12 + 9. The term-deletion ranking:

InterventionyCostVerdict
Intact250—
Drop a² (layer-1 squared)214smallest single term
Drop 2ab (layer-1 × context)1312the cross-layer product dominates
Drop b² (context squared)169context alone is second

The cross-layer product is also why layer 1 looks conditional: layer 1's total contribution a² + 2ab is 4 when b = 0 but 16 when b = 3 — a fourfold change with layer 1's own output unchanged. The fold names b as the gate. Where the assumption breaks: give layer 2 a nonlinear consumer, y = relu(a + b), with a = 2, b = −3. The true output is relu(−1) = 0, but no finite term expansion exists: the natural attempt relu(a) + relu(b) = 2 + 0 = 2 is wrong at the first step, and unlike the bilinear case no cross term repairs it exactly — only Taylor approximations, whose truncation error grows with activation scale. The same failure applies to a softmax consumer. Exact folding is a polynomial (here bilinear) privilege.

(c) Assumptions

  • The consumer must be polynomial in its input (exactly bilinear here); softmax or other nonlinear consumers admit only approximate expansions with uncontrolled truncation error.
  • The input streams must be exact analytic expressions — the fold (method 3) and the stream algebra (method 4) are prerequisites, gated by reconstruction at one part in a million.
  • Term deletion inherits every mean-ablation caveat (per-position means, paired standard errors), and the term count grows quadratically with the number of streams — so a "these terms are the layer" claim needs a multiple-comparisons control (here, a permutation sweep over all triples).
  • A token-indexed fold is only defined for tokens seen in the fitting slice; on unseen tokens it degrades to the token-blind map, so coverage must be reported alongside the headline.
(d) Real implementation

Two sites (scripts qk_xfold_terms.py, qk_xfold_table.py; red-team qk_redteam_xfold.py). Block 3 expanded into its twenty-one exact cross-layer term pairs: three terms are the layer — block-2-output × itself (the iterated square, energy 0.099), fresh-attention × block-2 (0.098), block-1-hub × block-2 (0.061). Keeping the three restores block 3 to within +0.033 nats of its 0.616 floor, and the named triple is the best of all 160 tested triples by eight standard errors. The mixer term is the context supplier (only 5.0 percent of its variance is current-token-determined) and is statistically tied with the iterated square in necessity. Block 0's write is causally dead as a direct input to blocks 2 and 3 (−0.0000 ± 0.0002); it reaches them only through block 1, which consumes it at both ports (+0.155 ± 0.005 feed-forward, +0.091 ± 0.003 attention). The token-table fold: substituting block 0's token lookup into block 1 turns block 1 into a token-indexed family of affine operators on the two attention streams — 41.7 percent of held output variance versus 0.1 percent for the token-blind linearization, and 93.6 percent causal (95.3 percent on the 80.5 percent of covered positions; no better than the blind map on train-unseen tokens). Median pairwise cosine between the 200 most frequent tokens' effective maps: 0.18 — after different tokens, layer 1 is a different operator.

13. Message-bottleneck + conditioning-variable hunt (importance rank: mid-tier — powerful, but so far applied to specific sites)

(a) Intuition

When several blocks are mutually redundant (methods 6 and 8 territory), per-block analysis dead-ends: every block matters and none does. The move is to change the unit of analysis. Treat the whole region's summed write as a single message, ask how many dimensions it really has (keep-top-k principal directions against random-k controls — sufficiency logic, method 2, applied to the joint object), and then ask what the message is about: regress the top message coordinates on candidate observable variables — current token, position, topic, distance since newline, next-token category — each with a shuffled-label control, and read off the best conditioning variable. A coordinate that is well predicted by an observable and has a coherent unembedding readout earns a name.

(b) Toy model

Three residual dimensions, two carriers, one message. An observable c = ±1 conditions the message scalar m = 2c. Carrier A writes (m, 0, m); carrier B writes (0, m, m); the joint write is (m, m, 2m). For c = +1 the joint write is (2, 2, 4); for c = −1 it is (−2, −2, −4): every joint write lies on the single line through (1, 1, 2), so the top principal direction captures 100 percent of the variance — the message dimension is 1 of 3, and PCA finds it. Redundancy: delete carrier A and the third coordinate still reads m from carrier B — half the amplitude, right sign. The conditioning hunt: regressing the message coordinate on c gives R² = 1.0 exactly (m = 2c); regressing it on an irrelevant coin-flip observable gives R² ≈ 0. The hunt names c — not the coin — as what the region is talking about. Where the assumption breaks: message dimension equal to carrier dimension. Let the two carriers instead write three independent scalars filling all three dimensions. Now the top principal direction captures about one-third of the variance — exactly what a random direction gets — there is no privileged compact head, and nothing compresses. "Message + broadcast" is only a useful model when the message is smaller than the carrier space, and the random-k control is what tells you whether it is.

(c) Assumptions

  • The message basis is fit on the training gram and judged causally on held data; a keep-k number without its random-k twin is meaningless.
  • Group R² on a high-cardinality variable (token identity: hundreds of groups) overfits mechanically, so the shuffled-label control is mandatory (it reads 0.046 here), and frequency confounds must be checked by re-scoring with the most frequent tokens excluded.
  • The hunt can only name variables you thought to include: the best found variable is a lower bound on what conditions the message, never proof that nothing better exists.
  • Redundancy claims need matched deletion comparisons. This method's own red-team caught an unmatched one: a surrogate with independent random frames whose exact-zero robustness under half-deletion was a linear-algebra certainty of the construction, not a measurement — the honest scale is same-subspace deletion applied to both codes.
(d) Real implementation

Blocks 5–11 of bilin18, jointly (scripts qk_msg_bottleneck.py and _2; red-team qk_redteam_msg.py). Replacing all seven blocks' outputs with per-position means jointly costs +1.6528 ± 0.0156 nats — 3.79× the sum of the seven per-block floors (0.4366), with the super-additivity already present at pair scale (blocks 7 + 9: ratio 1.65). Sixteen shared principal directions restore half the function (49.4 percent versus 1.2 for random-k), but ninety percent needs 576 of the 1,152 dimensions — a privileged head with a long tail, robust across five basis-allocation schemes. Best conditioning variable: current-token identity, group R² 0.47 (control 0.046), rising to 0.52 when the twenty most frequent tokens (29 percent of positions) are excluded — versus block 0's 0.953. Three coordinates earned names: boundary-reset (R² 0.753), clause-continuation (0.499), discourse-turn expectation (0.487). Matched half-subspace deletions: the real code costs about 25 percent less than an unprotected code (+0.54–0.58 versus +0.73), and independent per-block deletions cost less than a shared one (+0.47–0.49) — partial cross-block covering, far from a full repetition code.

(e) Held-back example
"…But they also like things to look upscale, so we tried to incorporate all of that into this location."" → "\nThen" Held-back FineWeb, sequence 583 (held index 135), position 80. The current token is the sentence-final closing quote '."'; the actual continuation is a newline and the sentence opener "Then".

This is a peak firing of the boundary-reset state (message dimension with R² 0.753 against current-token identity) at a non-end-of-text position: a sentence-final closing quote. The state's unembedding readout pushes sentence openers — " Although", "This", " While", " There" — and suppresses determiners; the actual continuation, "Then", is exactly that register. What was learned: a seven-block region whose every per-block ablation reads near zero is, at its most compressed, broadcasting a nameable syntactic-register signal — "a sentence boundary just closed; expect an opener" — redundantly across blocks, and that signal is conditioned mostly on the current token even in the middle of the stack.
