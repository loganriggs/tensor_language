## Confounds, invariances, and alternative-route audit

- **Capability is not occupancy or causality.** A large restricted weight norm can be
  unused; frequent activation can be epiphenomenal. Promotion requires reconstructable
  weight geometry, held-out occupancy or deliberate actuation, and selective causal
  patch/reset/rescue.
- **H/R gauge.** Per-factor rescaling changes raw H and R reciprocally while preserving
  Q. Primary reports must use exact products, projectors, normalized maps, spectra, and
  finite causal effects—not unnormalized H/R magnitude comparisons.
- **Input-support limitation.** Activation PCA/SAE may explain which possible states a
  corpus visits, including impossible-looking weight modes that never occur. It cannot
  define the all-input computation. Conversely, a weight mode absent from observed data
  is only capability, not an active circuit.
- **Normalization boundary.** RMSNorm and QK normalization make global end-to-end weight
  contractions input-dependent. Exact restricted MLP tensors are globally exact for
  that module; downstream path claims need live normalization or a separately validated
  fixed-normalization intervention with an exact no-op.
- **Distributed routes.** The prior unconditional v15 adaptive greedy search had no
  small selective prefix. Repeating it would be duplication. The new search is licensed
  only after H/R conditions the state and a complete union patch is material.
- **Overfitting and DAS.** The failed answer prototype and construction-specific gain
  reinforce the constrained-DAS red-team conclusion: a complement objective can
  memorize task rows or exploit correlated transfer labels. Noise/KL regularization is
  useful only with reporter-, construction-, and lexical-held-out selection plus
  frozen complement tests; it cannot replace full causal localization.
