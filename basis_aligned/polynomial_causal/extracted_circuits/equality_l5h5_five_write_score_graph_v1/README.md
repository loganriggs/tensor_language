# Equality L5H5 five-write score graph V1

This package refines the validated `L2+L3+L4` score boundary into the canonical
module-write expression

`M2 + (A3+M3) + (A4+M4)`.

It omits `A2`, the only module write removable under the frozen natural
selection rule. Natural parent-score error/cosine is `.05038/.99925`; frozen
code error/cosine is `.03875/.99934`; downstream recovery is `.88553`; noncopy
damage is `.00132` nat; and its complete Möbius graph closes at `9.60e-9`.

This is retained from a valid null because the stronger preregistered demand of
at most four writes failed. It is an executable boundary refinement, not a
claim that the module-level graph is very sparse or that the five native write
producers have been recursively extracted.
