# Temporal `is`/`was` v23 source × destination cell atlas v4 — padding repair

V3 executed all 84 frozen scientific arms and reproduced every immutable v2 full-head behavior
within `2.64e-7`. Its registered closure prediction was nevertheless false because one diagnostic
compared the all-cell reset with native output over the padded query tail. The three destination
roles intentionally partition only real causal queries through each row's semantic endpoint, so an
uncovered padded query remains donor-valued under reset and cannot satisfy native closure. This
produced a maximum of `34.4392`; it is not evidence about a token cell or any evaluated logit.

V4 is a prospective instrument repair. It makes exactly one change: the all-cell reset closure is
reduced over `covered_destinations`, the same declared domain used by the other cell/base/donor
closure checks. It reruns all 84 arms rather than relabeling v3. Population, routes, cell roles,
reciprocal bars, predictions A--E, exact price, controls, and terminals are byte-for-byte inherited
from the v3 preregistration. The invalid v3 result and its original runner remain preserved in git.

The correction is validated if closure is at most `1e-4` and every full-head behavioral replay is
at most `2e-3`. A failure remains `invalid_instrument`. No v3 scientific outcome is used to change
cell selection, thresholds, or predictions.
