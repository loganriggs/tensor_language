# Short-Givens sparse-frame pilot

Target is the same T[12,1152,128] mixed operator. Fix output/head HOSVD frames from weights. Learn only a residual coordinate transform as a sequence of disjoint-pair rotation rounds. Three deterministic random pairing schedules (61327, 61328, 61329), forty rounds each; each round has 576 pair rotations. Optimize sum of fourth powers of core entries with exact pair maximizers. This is a sparsity surrogate, not the final tail-error objective.

A: planted rotated one-row support recovered to relative 1e-10; pair/global fourth-power objective nondecreasing within relative1e-10 and norm preserved within1e-10. B: at least one trajectory checkpoint improves actual packed storage by >=5% relative to the initial output/head frame at 10% coefficient error, charging every rotation. C: same >=5% gain at 2% error. Checkpoints0,1,5,10,20,40 are declared in advance. Report all checkpoints and all starts. Each rotation costs two uint16 coordinate IDs plus two FP32 sine/cosine values (12bytes), plus existing adapters, bitmap and FP32 retained coefficients. This allows direct execution without dense residual matrix or runtime trigonometry. No convergence claim for forty-round budget; report last objective changes. A failure of surrogate optimization to improve actual storage is not absence of sparse structure.

Primary method context: Shalit and Chechik2014, https://proceedings.mlr.press/v32/shalit14.html; Frerix and Bruna2019, https://arxiv.org/abs/1905.05796. Their orthogonal-coordinate and structured-rotation approaches motivate the representation; this custom fourth-power objective/finite randomized schedule does not inherit a global recovery guarantee.
