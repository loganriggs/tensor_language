**Approximate functional sharing now proposes a graph edit, refits the whole program, and checks its total error and cost.**

The proposal pass compares internal feature values on a declared probe distribution, fits a scalar rescaling between candidate features, and proposes at most four globally applied merges with local relative error below10%. Similarity does not certify equivalence. Each proposed topology is refitted with the existing differentiable DAG; acceptance requires total relative error below1%and improvement in squared relative error plus .005per product,1e-5per addition and1e-5per stored coefficient. Shared computation is counted once, and other consumers remain in the cost. Degrees and acyclicity constrain replacements.

Five planted near-duplicate families pass: product, sum of squares, sum of products, affine product, and quartic square. After baseline fitting, accepted merges reduce products6→5,7→6,7→6,6→5,and5→3. Fresh artificial-probe errors range1.8e-8to1.1e-7; all exported evaluations replay exactly. Baseline fitting itself had already recovered the teacher function almost exactly but retained redundant topology. The discrete merge removes that redundancy. This tests a known-nearby program, not discovery of the correct graph from random initialization.

A necessary negative control passes. Let q=ab and r=q+.01cd. The two features differ by about1%, but outputs include100(r−q). Replacing r with a scaled q deletes information needed by that output. After refitting, squared relative output error is.67114(about81.9%relative error), so the edit is rejected despite saving one product. This explicitly tests downstream sensitivity rather than treating highly correlated features as interchangeable semantic units.

This is a proposal screen, not a completed native refit or an adopted approximation. The tiny cost benefit does not justify calling it a discovered reusable circuit. Its errors are relative to the archived approximate program, not the full native model.

The new capability is a genuine second-stage operation distinct from deleting a product: one intermediate is redirected to another shared computation, with its consumers preserved, then coefficients are refit. Broad native improvement still requires proposals that remove meaningful independent computation while retaining behavior. Neither toy recovery nor local feature correlation establishes monosemanticity, OOD circuit prediction, selective removal, or stable feature identity.
