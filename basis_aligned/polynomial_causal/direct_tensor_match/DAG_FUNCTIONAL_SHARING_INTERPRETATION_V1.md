**Stage two now has a bounded exact functional-sharing edit, beyond structural duplicate detection.**

The existing DAG compiler shared identical expressions and factored common operands. The new pass also recognizes differently written intermediates when bounded formal polynomial expansion proves them equal. For example, (a+b)^2-a^2-b^2 can share the same node as2ab, and differently grouped quartic products can share one computation. It proposes replacing one intermediate globally, counts every remaining consumer, and accepts only a lower globally reachable operation price. Ancestor/descendant checks prevent cycles; conservative node-degree bounds remain respected.

Five planted examples reduce product counts6→3,7→5,8→5,4→2,and5→3, respectively: quadratic polarization, quartic cancellation, quartic regrouping, affine-square cancellation and signed quadratic factorization. These counts include their consumers; some test outputs have degree five because quartic intermediates feed another product. Exact rational coefficient-polynomial replay passes for every accepted edit. A1e-20perturbation is correctly rejected as unequal; identities above dense opaque leaves are accepted; cycle/degree controls pass. This is function preservation, not semantic labeling or unique-feature recovery.

To bound expansion, a subexpression exceeding256monomials or4096pair products is treated as a distinct opaque symbol. Equality of the resulting formal polynomials is a valid identity for the actual subexpressions. Failure to match is inconclusive, because different opaque expressions can still be equal. This restriction avoids constructing the full native coefficient tensor.
