# Subject-number native embedding decoder V1

Registered after closing the topology-specific MLP8 response/port repairs. This
opened-authority discovery asks whether the model's own normalized subject-token
embedding contains a topology-stable grammatical-number node that can replace the
external categorical direction port of the fixed L11H3 writer graph.

Use three disjoint opened noun families: the 16-pair cardinality-prototype corpus,
the 16-pair response-weighted fourth corpus, and the 16-pair two-clause corpus.
Every form is one token. For each reciprocal leave-one-family-out fold, normalize
the checkpoint token-embedding rows exactly as the model does before layer 0. On
the other 32 pairs, define one unit axis as the normalized mean of
`plural_embedding - singular_embedding`; define one threshold as the mean projected
pair midpoint. No behavioral outcome, activation, prompt context, or downstream
state enters the decoder.

On each held family report endpoint classification accuracy, pair-order accuracy,
and signed margins. Compare with 64 equal-norm Gaussian axes; every null threshold
is computed by the identical training-midpoint rule. The native decoder must reach
at least `.90` endpoint accuracy and `.90` pair-order accuracy in every held family,
and exceed the pooled median-null endpoint accuracy by at least `.15`.

Instrumentation requires the frozen checkpoint hash, exactly 96 distinct one-token
forms in 48 disjoint pairs, three leave-family-out decoders plus one all-opened-row
freeze, 192 random-axis controls, finite unit axes, and zero model forwards,
gradients, or parameter updates.

If all gates pass, freeze the all-opened-row axis and threshold before authoring any
new noun or prompt. Passing licenses a prospective token-to-direction test only;
it does not yet establish behavioral substitution, removal, or two-site composition
of the integrated graph. Failure closes a single linear token-embedding decoder,
not all earlier native representations.
