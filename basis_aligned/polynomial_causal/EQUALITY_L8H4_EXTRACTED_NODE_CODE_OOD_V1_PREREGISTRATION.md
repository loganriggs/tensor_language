# Equality L8H4 extracted-node code-OOD V1

## Question

The frozen A8 oracle edge remains dominant on code OOD but over-recovers at
`1.17756`, outside its preregistered natural-to-code calibration band.  Preserve
that valid calibration null.  Test the orthogonal extraction claim: replace the
row-specific native A8 donation by the explicit zero-parameter node

`bmm(score * equality_support, projected_payload)`

using live L8H4 score and projected value/output ports.  On all 192 frozen
code-OOD documents compare:

- package subtraction from the otherwise native L8H4 write against the
  authoritative recipient-absent removal;
- package addition to the absent A8 write, with MLP8/A9 held at their absent
  oracle values, against the frozen A8-only oracle intervention; and
- the package's four-term bilinear expansion under sums of the live L5H5 and
  L8H4 score/payload ports.

No outcome, direction, scale, or parameter is fitted.  The package has zero
learned parameters and does not claim to extract the upstream score/payload
producers.

## Predictions

- **A — executor replay:** package term error versus the authoritative native
  equality term, package-removal logits/MLP9 write versus authoritative absent,
  and package-install logits/MLP9 write versus oracle A8-only are each at most
  `2e-5` relative L2.
- **B — behavioral identity:** package and oracle A8-only aggregate recovery
  differ by at most `.005`; their cell and half recoveries differ by at most
  `.01`.
- **C — removal:** package subtraction retains a positive absent-minus-native
  copy effect in aggregate and both halves.
- **D — OOD installation:** package A8-only recovery remains at least `.85`,
  all registered cell/half recoveries exceed `.70`, and all-noncopy mean damage
  is at most `.01` nat.
- **E — extraction:** the manifest declares zero learned parameters and the
  package source is the only executor used for both removal and installation.
- **F — compositionality:** the live two-score/two-payload four-term expansion
  has relative L2 error at most `2e-6`.

Passing yields an extracted, removable, installable, compositionally reusable
edge executor whose OOD causal magnitude is known.  It does not repair the
failed natural-to-code scalar calibration prediction, nor extract the native
score/payload producer subgraph.

## Price

One checkpoint load; all 192 code-OOD documents; five forwards per
four-document batch (native, authoritative absent, package removal, oracle
A8-only, package A8-only): exactly 240 forwards.  No fits, gradients, new text,
or parameter updates.
