# Subject-number native head-response coordinate discovery V1

The native L11H3 output-axis coordinate and the MLP8-input E/A/U/W secant coordinate failed to predict the frozen direction-by-cardinality program amplitude. This assay tests a different, causally defined upstream coordinate on the same already-open 32-row authority.

For background subset $b$, let $x_b$ be the raw MLP8 input with that subset installed and let $x_{b,YZ}$ additionally contain the opposite-number MLP6/7 `YZ` source. Let $H(x)$ be the exact L11H3 projected write reconstructed by the registered decomposed head function, and let $u$ be the frozen checkpoint-native top output singular axis. Define

$$
z_b = u^\top H(x_b),
\qquad
s_b = u^\top\left(H(x_{b,YZ})-H(x_b)\right).
$$

Thus $s_b$ is the signed change in L11H3's native output-axis coordinate caused by switching the upstream MLP6/7 source while holding the E/A/U/W background fixed. It is a head-local causal-response coordinate. It is distinct from the earlier fixed-direction readers, which projected full 1,152-dimensional L11H3 write displacements onto downstream answer-margin gradients.

Compare four frozen ordinary-least-squares designs for the already-frozen program coefficient $\alpha(d,|b|)$:

$$
\begin{aligned}
\text{native baseline} &: [1,z_b],\\
\text{response only} &: [1,s_b],\\
\text{joint additive} &: [1,z_b,s_b],\\
\text{joint interaction} &: [1,z_b,s_b,z_bs_b].
\end{aligned}
$$

Evaluate every form by leave-one-construction-out prediction and once on all rows, for twelve scalar fits total. A response form passes only if its cross-construction relative $L_2$ error is at most `.40` and improves on the native baseline by at least `.10`. Select the smallest passing response form in the order response-only, joint-additive, joint-interaction.

This is outcome-blind discovery on an opened authority. The experiment reads no answer logits, behavioral effects, downstream causal outcomes, or exact installed-write effects; performs no backward pass, update, or quantization; and opens no fresh rows. It uses the opposite-number donor MLP6/7 state to define $s_b$, so a passing result would license a later donor-free predictive or prospective causal test, not establish a native generator by itself. Price: one model forward over 96 role sequences, exact offline evaluations of the registered L11H3 function for 32 rows by 16 backgrounds by two YZ conditions, and twelve scalar least-squares fits.

If no response form passes, reject this native-axis head-response family and move to a vector-valued predictive-state coordinate rather than widening scalar polynomials on the same axis.
