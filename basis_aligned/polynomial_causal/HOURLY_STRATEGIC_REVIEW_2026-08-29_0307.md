### B. Add finite-secant port preservation after family-F admission

For frozen directions $u$, compare candidate and native suffix responses to both signs
and two amplitudes:

$$
\left[G_x(C\pm\epsilon u)-G_x(C)\right]
-\left[G_x(N\pm\epsilon u)-G_x(N)\right].
$$

This asks whether the compressed MLP3 write is a reusable interface under edits, not
only whether it matches ordinary logits.  Four directions can be fixed from typed
omissions and residual principal components.  It is cheap and directly relevant to
extraction/removal, but is contingent on family F first admitting a candidate.

### C. Freeze and implement the 68-action decision/replay reducer

Prospectively specify all comparators and document-bootstrap upper-bound decisions,
then reduce the typed `FinalObservationBundle` with hard rejection of reordered arms,
mixed support, empty frequency bins, comparator drift, and fabricated defaults.  This
closes a real missing interface, but the existing preregistration still licenses only
local final-role evidence.  A later common-denominator experiment is required for
actual extraction/removal/OOD ledger credit.

### D. Resolve the free-stream oracle, then choose the fallback grammar

The current GPU job substitutes the lower-layer stream for the raw embedding as the
oracle map input.  If it sharply reduces the 0.65--0.72 residual, a small priced map
from that already-computed state becomes justified.  If it plateaus, prune token-local
fallbacks and allocate price to a contextual/shared program instead.  No duplicate job
is useful while this discriminator is running.

### E. Diagnose context-conditioned gate bundles if global family F fails

Use document-group score gradients in the balanced native gauge.  Stable low-rank
gradient covariance would predict that a small context router can choose among a few
gate bundles; split-unstable or full-rank covariance would prune that path.  This is a
cheap fit-role diagnostic but should not complicate the frozen first family-F run.
