## Goal and frontier

The goal remains a substantially smaller *literal* bilin18 tensor program that is predictive on census/fresh/OOD
text, composes across replacements, preserves named signed interventions, and counts every stored tensor, state,
route, exception, and executed map. The smallest fully gated artifact is context-QK rank56:
**512,561,462 scalars, +.01250780 census, 43/62 certificates**, shifted mean/p95/max
`+.005698/.037966/.056886`, and signed cosine/error `.981641/.236669`. Rank48 is smaller and predictively smooth
but falls to 29 certificates; it is a mapped ledge, not an adoption.

## Step back: is the current path still best?

Yes, but the object has changed. Another uniform physical rank ladder is no longer the highest-information move.
The design problem can now be written as a constrained allocation problem. If family `f` has induced-metric
singular tail `T_f(r)`, measured damage follows

`D_f(r) = a_f T_f(r)^(b_f)`,

with different `a_f,b_f` by family. Marginal ranks should be allocated by consequence-weighted tail reduction per
stored scalar, not equal rank. Meanwhile certificate member `i` approximately obeys

`v_i = s k_i`, and it holds iff `s k_i < 1`.

The best next route is therefore to learn a prospective map from an allocation's family tail/components to the
single intensity `s`, enumerate legal allocations on CPU, and physically test only one candidate chosen before its
receipt exists. This is a new theory-guided design step, not post-hoc tuning of rung352.

## Confound audit

- **Baseline/frame mixing:** all new damage vectors use saved compiled/native CEVs in one baseline frame; native
  ablation margins are fixed. Composition remains measured physically rather than inferred from mixed frames.
- **Nonlinear composition:** cross-family tax rises from about 1.02 to 1.052 near the ledge. The allocator must
  include that residual or carry an uncertainty band; pure additivity is not exact.
- **Projection leakage:** rung356 estimates held-out ray intensity from the held-out vector. It validates the
  *shape* and first-passage count conditional on intensity; it does not yet predict a new intensity. Do not claim
  an end-to-end certificate oracle until that scale map is cross-validated.
- **Post-selection:** the Q/K ladder is closed under its registered stop rule. A new composition may run only if
  selected by the frozen allocator and judged against frozen certificate/CE/OOD/price bars.
- **Shared token difficulty and OOD reuse:** WikiText-2 test is exhausted and WikiText-103 test is text-identical.
  Current evaluations use non-overlapping spans from hashed WikiText-103 raw train rows100000:110000.
- **Precision/noise:** small negative shifted means are treated as sampling-scale zero. Exact price and live rank,
  map-count, fit-hash, route, and active-set assertions remain mandatory.
- **Dead knobs:** the finite router and both scalar covariance reweightings have explicit no-tuning decisions.

## Ranked next moves and kill evidence

1. **Certificate-constrained water-filling.** Fit/cross-validate certificate-ray intensity from saved family member
   vectors and measured singular tails; enumerate allocations with exact scalar prices. Kill if scale error implies
   more than three certificates of uncertainty or if leave-one-construction validation fails.
2. **One allocator-selected physical composition.** Run only if its lower confidence bound can improve the current
   price frontier while retaining a preregistered certificate grade. Kill on its frozen certificate, census, OOD,
   identity, or price bar; no neighboring rank search.
3. **MDL crossover calculation.** Convert scalar savings and CE damage into corpus-size crossovers under fp32,
   fp16, and int8 storage. Kill its usefulness if all plausible precision/corpus assumptions select the same
   already-known point; otherwise it supplies an honest deployment-specific operating point.
4. **Vocabulary sparse-residual correction.** Select rows on fit counts only and test unseen/rare target tails on
   shifted text at a literal bill. Kill if the correction budget cannot bring both corpora below the frozen damage
   target or merely memorizes fit rows.
5. **Vector-valued downstream MLP objective.** Optimize a low-rank map against several held-out suffix Jacobian
   directions jointly. Kill if it cannot beat ordinary context covariance on p95/max in both corpora at equal
   price and split stability.

The current route survives because it changes GPU work from search into falsification. The immediate concrete step
is a CPU-only prospective scale/allocator rung, followed—only if its interval identifies a genuine frontier
candidate—by one managed-runner physical gate.
