# Induction typed multi-module consumer response V1

The valid singleton response-restoration screen found no eligible sublayer from MLP8 through MLP17: the best worst-cell vocabulary-RMS reduction was 15.05% against the frozen 25% bar. The task authority permits a new experiment only under an independently motivated multi-module or typed-consumer intervention grammar. This experiment freezes that grammar by architecture, without using singleton rankings.

Reuse the exact 96 frozen capable directed rows and their 12-group DISCOVERY / 12-group CONFIRM split. Install the same four donor equality terms at L5H5, L7H3, L8H3, and L8H4. Each response arm restores the native recipient final-query writes for every module in one fixed architectural group:

- `all_mlp`: MLP8–MLP17 (10 modules)
- `all_attention`: attention9–attention17 (9)
- `early_all`: MLP8 and attention/MLP9–12 (9)
- `late_all`: attention/MLP13–17 (10)
- `early_mlp`: MLP8–12 (5)
- `late_mlp`: MLP13–17 (5)
- `early_attention`: attention9–12 (4)
- `late_attention`: attention13–17 (5)

The groups are fixed type × depth partitions, not unions chosen from singleton outcomes. A candidate passes DISCOVERY only if every cell has mean correct-answer CE damage at most .10, correct fraction at least .75, and at least 25% median full-vocabulary RMS reduction relative to the live joint edit. Select the eligible candidate with the fewest restored modules, then largest worst-cell reduction, then the fixed order above. Open CONFIRM only for that global selection; no fallback.

`pred_a_instrument` requires exact self reproduction, active producer edits, active restoration in every candidate, and exactly 30 forwards / 960 sequences. `pred_b_confirm_typed_group` requires the selected group to pass every CONFIRM cell. `pred_c_compact_group` additionally requires at most five restored modules. If no DISCOVERY group passes, or the selected group fails CONFIRM, the typed multi-module grammar is a valid null. Restoring native complete writes is an oracle mediation test, not an extracted consumer or executable compressor. No ranks, gains, individual modules, SELECT/FINAL/OOD rows, or thresholds are opened.
