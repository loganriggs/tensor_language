# Numbered-list cached-term head-source factorial

## Scope

This is a basic causal screen of the already exact and necessary final-label cached-value term

`T = T3 + T7`, where `Th = p8[h,q,k] WO8[h](lambda8 WV0[h] z0[k])`.

It is not a rank, reconstruction, variance, compression, or activation-energy experiment. It does not refit or search for a site. `FINAL_TEST` and `OOD` remain closed.

## Frozen rows and interventions

Use every `SELECT` group in `list_two_line_state_shift`, `list_three_line_state_shift`, `list_repeated_index_control`, and `sequence_word_copy_control` from the frozen R567 authority, with both base and donor endpoints. There are 32 unique frozen `group_id` values: 16 list leakage groups, each reused across the paired two-line, three-line, and repeated-list families, plus 16 separate word-copy groups. Family reuse therefore gives 64 family rows and 128 endpoint prompts; it does not create 64 independent groups.

Run five model conditions on every prompt: `native_direct`, `native_factor_replay`, zero `T3`, zero `T7`, and zero `T3+T7`. The first two form the replay instrument pair; the last three are the causal removal corners. Only the exact final-source contribution at the registered final query position is removed; this is not whole-head ablation. The joint corner must reproduce R576's exact whole-term removal construction.

## Registered statistics

For each row and zeroing condition record correct-answer margin damage, cross-entropy increase, full-vocabulary logit RMS, and removed-term norm. Define `I = d37 - d3 - d7`. The interaction bootstrap uses only target rows: for each of the 16 shared list `group_id` values, average `I` across both target families and both endpoints, then resample those 16 independent group means. Controls are excluded from the interaction statistic. Target necessity bootstraps each family/endpoint cell over its 16 group rows; collateral gates use their registered family/endpoint summaries.

Instrument gates: native replay relative squared error at most `1e-12`; `T3+T7` versus the frozen R576 `T` relative squared error at most `1e-10`; all values finite and all registered term norms nonzero.

An individual head source is selectively necessary only if, in both target families and both endpoints, margin-damage positive fraction is at least `.75` and the bootstrap lower mean margin damage and CE increase are positive, while both active copy controls retain the unchanged R576 preservation bars: answer-preserved fraction at least `.75`, mean CE increase at most `.1` nat, median absolute margin change and logit RMS at most `.25` of the frozen FIT target scales, and median removed-term norm at least `.10` of the frozen FIT target scale.

## Opposing predictions and terminal

- `pred_a`: the instrument gates hold.
- `pred_b`: at least one of `T3` or `T7` is selectively necessary under every frozen target and collateral gate.
- `pred_c`: cooperative service if neither singleton is selectively necessary but the joint is target-necessary and the group-bootstrap lower bound for `I` is positive.
- `pred_d`: redundant service if the group-bootstrap upper bound for `I` is negative.

If `pred_b` holds, this screen licenses a finer source boundary for later confirmation. Otherwise the result is an honest native-head-source split null or an interaction characterization; it does not license post-hoc head selection. No result licenses opening `FINAL_TEST` or `OOD`.

## Price and execution

Batch by equal token length with a maximum batch size of 32. The CPU compiler records the exact call count; maximum retained evidence is four float64 values per prompt per removal corner plus the native margin. Zero backwards and zero model updates. Execution is create-only through the managed science queue after preregistration; this task performs only CPU compilation and dry-run.
