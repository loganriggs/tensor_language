# Regional spelling: prospective screen of the frozen source block

The spelling hypothesis comes from post-hoc largest-logit inspection in a previous
FineWeb screen. This new test uses32frozen prompts:8UK/US spelling pairs, British
versus American cue, and2sentence templates. No native score was used to choose
these rows. Semantic prior-art search found no earlier registered regional test;
head17.2exclamation/capitalization roles are known, not assumed here.

Keep the saved common-quadratic source readers and original16feature dictionary
fixed. At the last query position, compile private query writers using actual
rotary positions; include source0 and immediately preceding source only. This
extends the fixed9-token discovery geometry without reader fitting. Actual QK
normalization and first-layer value mixture remain private native dependencies.

For each spelling contrast, margin is UK-token minus US-token logit. Native cue
effect is British-context margin minus American-context margin. Deletion reduction
is this native difference minus the difference after block deletion. Delete both
children together. Control swaps the block's write direction between paired cue
contexts and rescales it to the receiving context's original block-write norm.
This controls output direction/size reuse, not a complete semantic null model.

agree<=.1 relative; EACHfamily native cue effect mean>=.1nat and>=5/8positive.
B: A plus EACHfamily mean deletion reduction>=10%of native cue effect, with>=5/8
positive reductions. C: A plus EACHfamily actual reduction exceeds the paired
norm-matched control by>=5%of native cue effect, while mean absolute change in
unrelated token-contrast cue effects<=.5times that in regional contrasts.
Do not conditionally drop concepts, flip signs, select rows or repair these bars.
Capability failures invalidate a strong mechanism inference for that family;
report instrument and capability separately so a valid null is not called a bug.
