# What the late blocks' "tail" is for: a novel-token identity channel (2026-09-04, Claude lane, §2790–§2801)

Plain-language chapter expanding project shorthand. Sign convention (§2135): every cross-entropy (CE) number below is CE ADDED
ABOVE THE REAL MODEL on 64 held-out documents (docs 0–63 of the fixed natural-text set, 256 positions each, 16,384 predicted
tokens) — LOWER IS BETTER. Nothing in this chapter changes the strict explained fraction (5.348% / 10.923% / 4.727 nat / 0 of 68
installed tail items) or the §312 frontier; it is a description of one channel, with its predictions and misses.

## Terms

- **Residual stream**: the 1152-dimensional vector each block reads from and adds to. **Late blocks**: blocks 8–17 of 18.
- **Core / tail**: the earlier chapter (01:37) found that the late blocks' feed-forward parts (MLPs) all read the stream through
  one shared 768-dimensional frame — the **core** — obtained as the top eigenvectors of the average covariance of their
  (normalised) inputs. The remaining 384 dimensions are the **tail**. "The late tail write" = the part of each late MLP's
  output that lands in those 384 dimensions, with its average removed, accumulated block to block exactly as the model's own
  block-entry scaling (λ₀) carries it.
- **Withholding from a consumer**: the model runs unchanged, but one named reader (the later MLPs, the later attention, or the
  final readout = the unembedding matrix W_U that turns the stream into logits) is shown the stream MINUS the accumulated late
  tail write. The CE it adds is that consumer's use of the channel.
- **Target classes** (from Codex's audited `ops/target_token_classes.py`): at a position, the next token is **induction** if
  some earlier position had the same current token followed by the same next token; **repeat** if the next token occurs in the
  context but not as an induction match; **novel** if it does not occur in the context at all.

## What was measured, in order

1. **Who writes it** (§2796): the late MLPs themselves, from their core input — 73% of the tail write is the MLP evaluated on
   the core alone; it accumulates rather than being wired block to block (§2790).
2. **Who reads it** (§2797): withholding it from every consumer costs .1459; from the final readout alone .1130; from the later
   MLPs alone .0523; from later attention alone .0031. The readout is the majority consumer (marginal share .60). Blocks 15–17
   write 70% of what the readout uses.
3. **How many dimensions the readout uses** (§2798): many. Keeping only the top 8 / 32 / 128 of the tail's own principal
   directions recovers .18 / .32 / .62 of the .1130; the unembedding's own top directions do worse (.11 / .19 / .49). The
   effective rank is ~261. My preregistered "small interface" predictions (four of them) were falsified.
4. **How the late MLPs select it** (§2799): the tail is read through a gate that depends linearly on the 768 core coordinates;
   the exact weight-side operator family has effective rank ~600 of 768, and using only the top 64 / 128 / 256 gate modes
   leaves .089 / .063 / .033 of damage. No small gate exists.
5. **Which tokens pay** (§2800, this hour): 98% of the .1130 falls on NOVEL targets (per token: novel .188, induction .047,
   repeat −.009 — repeats get slightly BETTER without the channel). By frequency in a 24.6k-token reference corpus, the damage is
   monotone across all ten bins: targets never seen there pay .285 per token (31% of tokens, 78% of the damage), the most
   frequent targets GAIN .063 per token. It is not selective on the model's confidence (r = −.03 with the token's own baseline
   loss), and early positions pay slightly more, not less (a confound with class: fewer context tokens means more novel targets).
6. **Frequency signal or token identity?** (§2801): the one tail direction that most moves logits along "rare vs frequent"
   is worth 7–8% of the channel whichever way it is measured (keep only it: .071 recovered; deny only it: 8.1% lost; additive to
   .99). It is the unembedding's own leading tail direction (cosine .977). The other 92% needs the remaining 383 dimensions.
   Without the channel the model's predictions are flatter (mean entropy +.073 nat), not over-confident.

## The picture

The late blocks split their computation: a shared 768-dimensional quadratic core, plus a 384-dimensional output channel through
which they tell the unembedding WHICH out-of-context, infrequent token is coming. That is why the channel is high-rank in every
frame (token identity for a long vocabulary tail is not a few directions), why it has no small gate, and why withholding it helps
in-context and frequent targets (their rare competitors lose evidence). The three largest writers (blocks 15, 16, 17) all put their
value on novel targets, but on different tokens (token-level correlation .13–.25): three writers of the same kind of evidence,
not one shared circuit token by token.

## What this does and does not buy

It is a diagnostic attribution, not an executable compression: no parameter is saved, nothing installs into the frontier, and the
"rare-token gain" program item the last rung tested turned out to be worth 8%. What it buys is a functional label for 384 of the
late blocks' 1152 dimensions and a closed question: the search for a small dictionary or interface there is over, for a
mechanistic reason.

## Misses and process, preserved

Of 19 preregistered predictions in §2798–§2801, 11 were falsified. Three of the misses were errors of registration FORM (an
effective rank on an uncentred moment; a ratio whose denominator changed sign; an inequality written the wrong way for the arm as
defined); each is scored as written and the substance recorded separately. From the next preregistration on, every prediction
carries a worked-example line giving the value the arm takes if the hypothesis holds. One rung was briefly registered under an
existing rung's name and overwrote its files; they were restored bit-exact from git and `ops/derive.py` now refuses such
collisions.
