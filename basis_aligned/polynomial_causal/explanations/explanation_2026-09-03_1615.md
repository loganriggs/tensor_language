## What we are trying to build

The target is a smaller executable account of the model whose circuit units have all of the following properties:

- a clear computation: what is read, what operation is performed, what is written, and which later computation uses
  it;
- grouping across native modules when two pieces perform the same role, and splitting within one head or MLP when
  its pieces do different jobs;
- prediction on held-out and shifted inputs;
- sufficiency: the isolated computation reproduces its intended causal effect;
- selective manipulation: removal or interchange changes the intended behavior while preserving unrelated ones;
- predictable composition with other circuits;
- stable identity across datasets, fitting restarts, and harmless changes of basis.

Fewer dimensions, lower reconstruction error, and lower storage are not evidence for these properties by
themselves. They become useful engineering measurements only after a circuit has a task-defined causal identity.

## The exact fresh confirmation

R545 froze 180 semantic groups before loading the model. Each group has five paired prompt constructions:

1. directly substitute the pending delimiter type, changing the correct answer;
2. complete one delimiter and reopen another in a different order, also changing the answer;
3. rewrite the surface wording while preserving the pending delimiter;
4. change the distance to the opener while preserving it;
5. change irrelevant punctuation while preserving it.

The dataset contains 900 unique prompt pairs and 1,800 unique token sequences. Parenthesis, square bracket, and quote
produce six ordered changes. Each ordered change has 12 FIT groups and 6 groups in each of SELECT, FINAL_TEST, and
OOD. R546 opened only FIT and SELECT.

For the correct closer $a$ among the three possibilities, native capability used

$$
m_a=\operatorname{logit}(a)-\frac{1}{2}\sum_{b\ne a}\operatorname{logit}(b).
$$

A prompt counts as correct when $m_a>0$. Every one of the 24 split-by-construction-by-ordered-pair cells had 100%
correct base prompts and 100% correct donor prompts.

At the final token, R546 then took the complete 128-dimensional output of L13H8 from a donor prompt and inserted it
into the base prompt, and also ran the reverse swap. The remainder of the real model was left unchanged. Across the
two answer-changing constructions, two splits, and two directions, all 8 pooled cells had 100% of rows move the
requested closer contrast in the donor's direction. The weakest 95% bootstrap lower bound on the mean change was
$+5.214$ logits.

For the three answer-preserving constructions, a complete-head swap is not expected to be selective—the head can
contain wording and position information in addition to the proposed variable. Instead, this step asks whether the
control can detect leakage later. All 12 control cells were live. The weakest 95% lower bound on the absolute
correct-closer margin change was $0.0501$ logits, above the frozen $0.03$ threshold; the weakest full-vocabulary logit
root-mean-square change was $0.0178$, above the $0.01$ threshold.

The run used exactly 204 forward passes and zero backward passes. It did not update model weights. R548 then
independently rebuilt every cell and bootstrap statistic from the saved row-level values, checked one-to-one row
coverage and hashes, and reproduced the complete verdict. FINAL_TEST and OOD remain unopened.

## Why the next experiment looks downstream

The failed R540 DAS optimized and tested essentially the same quantity: the difference between closer-token logits.
A direction can pass such a test by directly steering that output difference, without representing the causal
variable we intended. Cross-family prompt transfer alone did not prevent this shortcut.

R549 therefore asks for a second consequence inside the network. For a later component output $y_j$, a base prompt
$b$, a donor $d$, and the base run receiving the donor's complete L13H8 state, define

$$
p_j^{b\rightarrow d}=y_j(b\leftarrow h_d)-y_j(b),
$$

and compare it with the natural prompt difference

$$
n_j^{b\rightarrow d}=y_j(d)-y_j(b).
$$

$p_j$ is the exact causal response of that later component to the head swap. R549 records it for 41 candidates:
every MLP write from layers 13 through 17 and each individual attention-head output from layers 14 through 17.

On FIT, the experiment averages responses for each of the six ordered delimiter changes. These six vectors act as
templates. A later component is useful only if templates obtained from direct substitutions classify the ordered
change in completed-then-reopened examples, and vice versa. Chance accuracy is $1/6$; both directions must reach at
least 50%. Responses to answer-preserving edits must also have low alignment with all six templates.

Only FIT can select a candidate. SELECT then independently tests the same cross-construction classification and
control-separation rules. The causal response must also be at least 5% as large as the full natural response, which
rejects numerically tiny but accidentally classifiable changes. All candidates are reported, but SELECT cannot swap
the winner.

For each candidate, R549 also reports alignment with closer-token output directions. For an attention head, the
closer directions are mapped backward through that head's output-projection slice before taking the cosine. This
diagnoses another copied answer readout, but cannot influence candidate selection.

This atlas is not rank reduction. Its decision is whether a later computation supplies a reproducible, causally
linked response to the proposed variable that is distinct from the answer-preserving edits. If one validates, the
next DAS must match both the endpoint and this later response. If none validates, we preserve that null and do not
pretend the endpoint-only intervention has an independently established downstream meaning.

## Organization that prevents repeated work

There are 75 canonical records: four task-defined behavior circuits, one shared subroutine, and 70 historical census
regions. The census regions are not automatically counted as clear circuits.

Three generated views now serve different purposes:

- `CIRCUITS_INDEX.md` gives each stable identity, current claim, status, latest evidence, and exact missing step.
- `CIRCUIT_COVERAGE.md` shows which of eight circuit criteria have held, failed, or remain missing.
- `CIRCUIT_EXPERIMENT_INDEX.md` lists every preregistration and result with a scientific protocol hash and an exact
  execution hash.

The protocol hash ignores filenames, claim revision numbers, seeds, and dataset execution details. It therefore
detects when a supposedly new run asks the same scientific question. The execution hash additionally binds the
split, seed, checkpoint, and artifact hashes. A repeated protocol must explicitly say that it supersedes an old test
or deliberately replicates it.

At this update the experiment index contains 33 evidence events, 28 scientific protocols, and 33 distinct exact
executions. R549 is the only open preregistration. There are no duplicate execution hashes and no repeated protocols
currently lacking a declared supersession or replication link.
