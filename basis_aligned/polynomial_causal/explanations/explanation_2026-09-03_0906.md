## What “invalid optimizer” means here

Each learned object is a four-dimensional space inside attention8's 1,152-dimensional output. The four columns of
`Q` remained orthonormal, so `P=QQ^T` continued to be a valid projector, and the projectors moved substantially from
their initial values. The problem was the path used to learn them.

The fitting loss on a circuit member was

`mean((projected effect - full attention8 effect)^2) / mean(full attention8 effect^2)`

plus 24 times the corresponding projected effect on a matched non-member. The denominator was computed from one
selected member row on each update. Across all 20,600 updates, 379 losses exceeded 100 and the maximum reached
270,121,856. These rare events prevented reliable convergence.

Because convergence was a prerequisite, the saved VALIDATION response measurements cannot be used as a scientific
failure of the circuit. A healthy optimizer followed by weak held-out selectivity would be a circuit-relevant null;
this run did not reach that condition.

## Correction to the first post-hoc diagnosis

The first scheduler analysis found many exact target/member/control/donor patterns that spiked in several fitted
objectives. A stricter audit shows that those recurrences all share the same random seed, which also means they share
the initial projector and row ordering.

There are 13,668 unique exact patterns. Only 43 occur under two seeds, none under more than two, and only two
spike-producing patterns have a cross-seed comparison opportunity. Neither repeats its spike. This cross-seed zero
has almost no power, so it does not identify the denominator or the learning rate as the cause.

Rung 523 is now running through the managed GPU service. It uses only FIT and VALIDATION and cannot access TEST. It

The failed one-row/`.03` condition is read from the immutable rung-522 archive rather than rerun.

The fixed scale is the mean squared complete-attention8 effect over every eligible FIT member position for a given
circuit and donor map. It is computed once and does not depend on the learned projector or VALIDATION data. Every
candidate is judged with the same fixed-scale VALIDATION score, so one method cannot win by reporting itself in
smaller units.

Every candidate cell contains the same 15 leave-one-circuit-out fits, rank four, intervention, member/control pairs,
donors, random seeds, row schedules, control weight, and 200 updates. A candidate passes only if all 15 fits improve
in training and VALIDATION, remain valid projectors, have no loss above 1,000, and have at most 3/3,000 losses above
100.

The result distinguishes four cases:

- fixed scale at `.03` works: changing the normalization is sufficient;
- one-row scale at `.003` works: lowering the step size is sufficient;
- only fixed scale at `.003` works: both changes are required; or
- none works: stop tuning Adam-through-QR and use a direct optimizer for subspaces.

Passing rung 523 would license a new sealed run of the original circuit experiment with its scientific thresholds
unchanged. Rung 523 itself is only an instrument calibration and cannot establish a low-dimensional circuit.
