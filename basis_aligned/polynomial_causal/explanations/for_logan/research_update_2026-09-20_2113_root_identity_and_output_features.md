# Primitive identity fails replication; output-shared combinations are stable

2026-09-20 21:13 UTC

Six additional registered root fits expanded the replication to eight starts
and 28 pairwise comparisons. The selected ten-product program stayed frozen.
All centered function cosines exceed 0.99919, but the feature identity bars
fail: median worst-match cosine is 0.720, minimum is 0.137, and minimum matched
output-direction cosine is 0.340. The encouraging two-fit result did not hold.

The worst mismatched pair is not negligible: its components carry 8.27% and
14.85% of their fitted functions' energy. This disagreement therefore cannot
be dismissed as an unstable tiny residual. Objective gaps are saved alongside
all fits; neither this test nor similar losses prove a global optimum.

An explicit alternative basis is much more reproducible. For each fitted
function, diagonalize its centered output covariance under the declared
Gaussian law. The four resulting output directions define four scalar features,
each generally a linear combination of the existing quartic products. Across
all eight fits, minimum matched feature cosine is 0.98355 and minimum output
direction cosine is 0.99959. This is a post-hoc canonicalization result, not a
registered primitive-identity success.

For the selected saved program, the four modes carry 76.90%, 17.12%, 4.60% and
1.38% of centered output energy. Adjacent eigenvalue ratios exceed 3.3, helping
make the spectral basis stable. Its interpretation view replays the same
program to 7e-16. The deployed ten-product graph is unchanged; the extra
interpretation matrices are not counted as free deployed state.

This distinction matches the intended representation: a reusable output-shared
feature can combine several constituent conditions. It does not imply one
human-readable concept. The spectral rule fixes a basis using the chosen input
metric; it does not discover a privileged causal decomposition. Selectivity
and meaning still need independent evidence.

The next registered check changes the bank fit itself and refits roots on that
alternative, comparing functions through exact cross-moments. This tests whether
the canonical features survive variation in both hierarchy levels rather than
only root initialization.
