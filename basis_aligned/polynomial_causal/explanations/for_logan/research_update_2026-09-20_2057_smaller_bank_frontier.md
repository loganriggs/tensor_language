# Six shared bank products retain most predictive performance

2026-09-20 20:57 UTC

Sixteen random-start fits compared Adam/Muon, two rates and two seeds using the
corrected noncentral Gaussian function metric. Selection used weights and
calibration input moments; composed predictions were scored afterward.

The six-product bank passed prediction and export bars. Prices include bank
writers and root combinations, excluding the fixed vocabulary frame. Panels
fresh for the original frozen validation are now reused diagnostics; this is
not another untouched evaluation or a full-model substitution.

Smaller dictionaries did not resolve feature identity. Across the two
best-rate Muon six-product fits, centered bank function cosine is 0.9985,
but the worst matched primitive feature cosine is 0.594. Comparisons across
all rates are worse but include underfit arms. These results do not establish
unique semantic variables.

A descriptive atlas records high/low contexts for each frozen primitive,
using distinct documents and reporting position dependence. It assigns no
semantic labels. A primitive's output effect depends on other bank features
through the quartic root; it is not a fixed vocabulary-output direction.

The next target is the ten root products of four bank features. An exact
functional metric requires fourth moments of those quadratic features,
equivalently eighth-order Gaussian input moments. The plan uses quadratic-form
cumulants and polarization, with an independent small oracle and rank ceilings
before choosing new root product counts.
