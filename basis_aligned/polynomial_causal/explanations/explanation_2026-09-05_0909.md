# Circuit-program update — 2026-09-05 09:09 UTC

## Goal and current strategy

The goal is to build a reusable codebase and evidence base containing hundreds of high-quality causal circuits, then use repeated structure across those circuits to discover the model's natural computational decomposition.

A useful circuit is not just a component with a large activation or a low-rank approximation. It should eventually have:

- a meaningful counterfactual dataset;
- prediction on held-out or out-of-distribution examples;
- an extractable causal computation;
- selective removal or interchange that changes the intended behavior without damaging unrelated behavior;
- evidence about reuse or composition when the same computation participates in several tasks.

The current screens use answer-logit margins and CE loss because those are task outcomes. Activation reconstruction, activation variance, quantization, and rank reduction are not evidence for these properties and are not being pursued.

## One bracket circuit is now explicit through the output weights

The previous update ended while testing how an exact semantic vector written by layer-13 attention head 8 reaches the answer logits in a bracket/quotation task. The vector had already been causally separated into a shared opener component $\mu$ and a construction-specific component $\delta$.

The fixed final readout is

$$
\operatorname{logits}(x)
=30\tanh\!\left(\frac{W_U\operatorname{RMSNorm}(x)}{30}\right),
$$

where $x\in\mathbb{R}^{1152}$ is the final residual-stream vector and $W_U$ maps that vector to vocabulary logits. The experiment inserted the exact $\mu$ or $\delta$ change into the final residual state while holding later module writes fixed. It then separated the resulting logit change into:

1. the direct fixed-weight contraction through $W_U$;
2. the change caused by RMS normalization;
3. the correction caused by the final $\tanh$ soft cap.

The first run was correctly marked invalid because its full-vocabulary numerical replay tolerance, $2\times10^{-5}$, was below the measured float32 floor of $3.05\times10^{-5}$. An instrument-only repair set the tolerance to $4\times10^{-5}$ without changing any scientific criterion.

In the valid result, the direct unembedding contraction explained 98.9%–111.5% of the centered closer-token effect across constructions. RMS scaling contributed roughly 0.1%–1.0%, and the output soft-cap correction contributed 6.5%–11.3%. Values above 100% mean that one correction partially opposes the direct contribution; they are not probabilities.

This is an extracted weight-level circuit: the bilinear attention computation selects an opener value, the head's output matrix writes it into the residual stream, and fixed output weights read that vector as evidence for particular closer tokens.

## Moving below an attention-head basis in the agreement circuit

The main new work concerns the subject–verb agreement circuit in layer-11 attention head 3. Treating the entire head as one unit was not enough, so the code now exposes each exact source-token contribution.

For final query position $i$ and source position $k$, this model's attention head contributes

$$
p_{ik}u_k,
$$

where

$$
p_{ik}
=\left(\frac{q_i^\top k_k}{128}\right)
 \left(\frac{{q'_i}^\top k'_k}{128}\right)
$$

is the model's bilinear attention score, and

$$
u_k=W_Ov_k\in\mathbb{R}^{1152}
$$

is the source token's value after the head's output matrix. The complete head write is exactly

$$
h_i=\sum_k p_{ik}u_k.
$$

Here “score” means the scalar deciding how strongly source $k$ contributes at query $i$. “Projected value” means the actual 1152-dimensional vector that the source writes into the residual stream after the head's output matrix. This factorization lets us replace the score or value separately and then run the real remaining model.

## Result 1: the subject token carries a number-specific value

The first 64-row screen separately changed the score and projected value at the grammatical subject and at the distracting noun.

- Replacing only the subject's projected value recovered 41.6% of the complete-head donor-directed margin change and 51.4% of its CE improvement.
- The margin moved in the intended direction on all 64 examples.
- Replacing only the subject score recovered 1.6%.
- Every distractor-noun condition was near zero or slightly harmful.

This means a substantial part of the head's agreement computation is a value attached to the grammatical subject, not to the nearby distractor noun. It does not complete the head's decomposition: about half of the complete-head causal effect remains in other source positions.

A separate SELECT control changed noun identity while either preserving or reversing grammatical number. The opposite-number value reproduced the parent effect and improved donor-answer CE by 1.819 nats. A different noun with the same number produced only 5.44% as much margin change and 3.10% as much CE change. Thus the value is substantially specific to grammatical number rather than noun identity.

Because the source is token position 1, causal masking prevents its value from seeing the later prepositional-phrase or relative-clause syntax. Syntax can affect how the final query reads the value, but it cannot already be stored in that source value.

## Result 2: TEST transfer is real but incomplete

On the reused TEST text, the subject-value intervention moved every example in the correct answer direction, but it did not meet the registered requirement of at least 25% complete-head margin recovery in every syntax-by-number cell.

The four cell recoveries were approximately:

| Recipient context | Complete-head margin recovered |
|---|---:|
| PP, plural subject | 18.67% |
| PP, singular subject | 36.35% |
| Relative clause, plural subject | 31.24% |
| Relative clause, singular subject | 28.96% |

The PP-plural weakness was broad across its 16 examples rather than caused by one outlier. The result was therefore preserved as a null for uniform transfer, not described as a full success.

Changing the donor back to the recipient's own noun lemma did not repair this cell: same-lemma and cross-noun recovery were 18.31% and 18.67%. Differences in the other cells were below 0.4 percentage points. Noun identity is therefore not the missing variable.

## Result 3: the natural context-dependent score does not explain the weak cell

The next experiment tested whether PP versus relative-clause context changes the score applied to the same subject-number value. It used a $2\times2$ factorial:

- native or opposite-syntax subject score;
- native or opposite-number subject value.

Let $m_{ab}$ be the donor-directed answer margin, where $a$ selects the score and $b$ selects the value. The causal effect of changing the value at native score is

$$
E_0=m_{01}-m_{00},
$$

and its effect at the alternate score is

$$
E_1=m_{11}-m_{10}.
$$

The score-by-value interaction is therefore

$$
I=E_1-E_0=(m_{11}-m_{10})-(m_{01}-m_{00}).
$$

This difference-in-differences is important. Comparing only $m_{11}$ with $m_{01}$ would confuse a score-only baseline shift with a change in how the score gates the donor value.

The first execution was preserved as invalid because a newly registered numerical liveness test required 12/16 weak-cell examples to change their score by more than 10%, while 11/16 did. We did not lower the threshold after seeing the result. Instead, a second runner added a task-level capability test in the same forward: set the score to zero or twice its native value while holding the donor value fixed.

That causal capability test passed. In the weak PP-plural cell, zero-to-double score changed the answer margin by 0.634 logits, or 16.62% of the complete-head effect, in the expected direction on 15/16 examples. It also improved donor-answer CE by 0.611 nat.

Despite that live causal control, the natural opposite-syntax score did not rescue the value:

$$
E_{\text{native PP}}/H=18.67\%,
$$

$$
E_{\text{relative score}}/H=17.14\%,
$$

$$
I/H=-1.53\%,
$$

where $H$ is the complete-head donor effect in that cell. The corresponding CE interaction was -2.12% of the complete-head CE improvement.

This is a narrow, valid null: replacing the native PP score with this naturally occurring relative-clause score does not explain the PP-plural weakness. It does not prove that QK never gates agreement, nor does it test every possible score feature or OOD context.

There is also a consistent descriptive fact. In reciprocal pairs, the PP-derived score made the donor-value effect stronger than the relative-clause-derived score in 15/16 plural groups and 16/16 singular groups. Thus the score genuinely modulates the same value, but the weak PP-plural case already has the stronger of these two scores.

## What this says about the computation

The evidence now supports the following partial decomposition:

$$
\text{L11H3 agreement effect}
=\text{subject-number value read by a context-dependent score}
+\text{other source terms}
+\text{downstream interactions}.
$$

The subject value generalizes across nouns and contributes causally across all tested syntax/direction cells. The PP/relative score changes how strongly that value matters, but does not explain why subject-only interchange captures less of the complete head in the PP-plural cell. The leading unresolved explanation is that other source terms carry additional or transformed copies of the number information, possibly interacting downstream.

## Next experiment already in progress

The claimed all-source atlas uses a same-lemma, same-syntax, opposite-number donor. Recipient and donor prompts have equal length and differ only at the subject token. For every causally available source position $k$, it will run

$$
h_i^{(k)}
=h_i-p_{ik}u_k^{\text{native}}+p_{ik}u_k^{\text{donor}},
$$

then measure the real answer-margin and CE change after the rest of the model runs.

This preserves the recipient score and changes exactly one projected value. Equal prompt lengths make positions align exactly, while later positions are allowed to contain transformations of the changed subject number. The subject position must reproduce the established subject-value effect; the complete same-syntax donor head supplies a live ceiling.

The experiment should tell us whether the missing half of the head effect is concentrated in a few semantically identifiable later tokens, distributed across many sources, or only present through interactions among source terms. It remains a BASIC TEST-reuse decomposition screen. OOD prediction, selective removal, and completeness will be tested only after a source-level signal exists.

## Pre-outcome correction to the atlas plan

An independent novelty audit found that source position 1 is not new: it is exactly the same TEST same-lemma subject-value intervention used in the lemma-direction experiment. The first atlas claim was abandoned before any GPU outcome, and a corrected claim now treats position 1 only as a required reproduction control. The novel part is the scan over every other exact source value.

The audit also identified a necessary joint condition. Individual source replacements can locate sources that are sufficient on their own, but their task effects need not add after the nonlinear downstream model. The corrected experiment therefore includes

$$
h_i^{\mathrm{joint}}
=\sum_k p_{ik}^{\mathrm{native}}u_k^{\mathrm{donor}},
$$

as well as the complete donor head

$$
h_i^{\mathrm{donor}}
=\sum_k p_{ik}^{\mathrm{donor}}u_k^{\mathrm{donor}}.
$$

The joint-value arm asks whether all donor values under recipient scores recover the distributed value computation. The difference between the complete donor head and the joint-value arm broadly captures score changes and score-by-value interactions; it does not uniquely assign them to one QK branch.

For answer margin $M$, downstream nonadditivity will be reported as

$$
A_M
=\left(M_{\mathrm{joint}}-M_{\mathrm{native}}\right)
-\sum_k\left(M_k-M_{\mathrm{native}}\right).
$$

If $A_M$ is material, singleton recovery percentages cannot be interpreted as unique shares. The next justified experiment would be a small factorial over the strongest semantic source groups, not a full powerset. The dataset contains 32 noun groups crossed with two syntaxes, so the 64 rows are not described as 64 independent lexical contrasts.

## Atlas result and the next interaction test

The corrected atlas completed after this document was first written. All instrument checks passed, including exact source-sum identity, a source-0 no-op, and reproduction of the previously known subject intervention.

Replacing all donor values jointly while retaining the recipient's native scores recovered between 89.39% and 105.01% of the complete same-syntax donor-head margin across the four cells. This is strong evidence that the same-syntax number flip is carried almost entirely by distributed source values rather than by changing the attention scores.

The most important new singleton was consistently the first token after the subject:

| Recipient syntax and number | Source token | Complete-head margin recovered |
|---|---|---:|
| PP, plural | `in` | 21.42% |
| PP, singular | `in` | 47.49% |
| Relative clause, plural | `that` | 27.51% |
| Relative clause, singular | `that` | 42.57% |

Later bridge or preposition values also mattered in some cells. The attractor noun itself was slightly anti-causal, between -0.64% and -2.01% of the complete-head margin. Since the paired prompts differ only at the subject token, these later value differences mean that L11H3 reads subject-conditioned information at those later positions. They do not show that L11H3 created that information; upstream layers produced the value states.

The downstream response is substantially nonadditive. Joint-minus-summed-singleton margin ranged from -0.664 to +2.207 logits across cells. Consequently, the singleton percentages cannot be called unique shares of the circuit.

The next experiment is already claimed and being implemented. It evaluates all 16 subsets of four semantic source-value groups under fixed recipient scores:

- $S$: the grammatical subject;
- $I$: the first token after the subject (`in` or `that`);
- $B$: the remaining tokens connecting the subject phrase to the attractor;
- $A$: the attractor determiner and noun.

This exact factorial will show whether $S+I$ is sufficient within this intervention game, whether the remaining bridge adds a material effect where $S+I$ falls short, and how the groups combine. Sufficiency does not by itself prove that $S+I$ is compact, necessary, or exclusive. It is a direct causal grouping test, not rank reduction or activation reconstruction.

Before GPU execution, a red-team review removed a multiple-comparison trap from the plan. Rather than searching all 44 cell-by-interaction combinations and declaring success when any one is large, the corrected claim tests the named $S\times I$ Möbius term and requires a common sign across cells and both deterministic noun-group halves. Möbius reconstruction and Shapley efficiency are exact instrument checks. Attractor effects and the largest other interaction are reported descriptively. The 70% and 80% subset thresholds were motivated by singleton results on these same reused TEST rows, so they characterize this intervention game and will require new nouns or constructions for confirmation.

## Group-factorial result

The first execution was preserved invalid because the empty-subset full-vocabulary replay error was $6.366\times10^{-5}$, just above its $5\times10^{-5}$ float32 tolerance in a 1,088-example patch batch. A create-only repair changed that numerical tolerance to $7\times10^{-5}$; no dataset, factor, causal outcome, or scientific threshold changed.

The repaired result passed every instrument check. Its main finding is that $S+I$ is not sufficient in the PP-plural cell:

| Cell | $S+I$ / all donor values | $S+I+B$ / all donor values | Conditional bridge addition |
|---|---:|---:|---:|
| PP, plural recipient | 60.20% | 102.26% | 42.05% |
| PP, singular recipient | 78.29% | 100.52% | 22.23% |
| Relative, plural recipient | 75.30% | 99.52% | 24.22% |
| Relative, singular recipient | 81.26% | 98.61% | 17.35% |

In the registered failed cell, adding the bridge moved all 16 examples in the donor direction and supplied 0.965 nat of CE benefit. The attractor phrase then changed joint margin by only -2.26% to +1.39% across cells. Thus, within this intervention game, the causal value computation is well described as subject value plus an immediate syntax relay plus the remaining grammatical bridge. The distracting noun phrase is not an important positive part of the value circuit.

The named $S\times I$ interaction was not shared across all conditions. It was positive for plural recipients and negative for singular recipients in both syntax families, and each sign repeated in both lexical halves. This is a structured result, but it failed the registered shared-interaction claim. The next independent test should ask whether interaction sign genuinely tracks number direction.

The active next screen moves to the already-open OOD texts with a new below-head intervention. In the fronted construction, the grammatical subject is the final source token; causal masking makes every earlier donor value an exact no-op when only that subject changes. In the two-attractor relative clause, the subject remains early and later tokens can carry relayed number information. The OOD atlas will test whether joint value sufficiency transports, whether the final subject value alone suffices in the fronted construction, and whether later relays recur with two attractors. Because those OOD texts and whole-head outcomes were opened previously, this is labeled OOD-text reuse with a new intervention rather than pristine OOD confirmation.
