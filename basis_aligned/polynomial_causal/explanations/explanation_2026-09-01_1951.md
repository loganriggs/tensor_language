# Continuous attention-edge update — 2026-09-01 19:51 UTC

## Goal and current answer

Our goal is to replace bilin18 with a smaller, understandable tensor program that still predicts held-out text and
preserves the effects of causal interventions. For attention0, the immediate question is whether the nine
architectural heads are the right explanatory units, or whether their complete computations can be rewritten using
a smaller set of input and output modes.

The latest result is a strong positive identification result. On held-out natural text, six continuous modes for
each of the two attention-score branches and 32 modes for the combined head-by-output payload preserve 98.5% of the
task-relevant attention0 write and about 99.3% of every tested immediate downstream response. A control that keeps
the same modes but pairs the wrong score branches destroys the signal. Thus the useful unit is not an isolated head:
it is a coupled continuous block spanning both QK branches and the output payload.

This is not yet compression. The screen still computes every native query, key, value, and output map before
projecting their realized values. The next step is to generate the six, six, and 32 modes directly from the model
state at a literal parameter price.

The requested old-work audit is already present as section 14 of
`explanation_2026-09-01_1807.md`. It establishes that the earliest sparse-autoencoder work learned per-head
`(key branch 1, key branch 2, value)` triplets and then applied a CP decomposition to their sparse third-moment
core. It did not learn one shared Tucker decomposition across heads. The new result is the first held-out,
downstream-scored continuous version of the complete product.

## 1. What was computed

For document edge `n`, head `h`, and a coordinate `c` in a task-relevant 16-dimensional output space, define

`e[n,h,c] = s1[n,h] * s2[n,h] * p[n,h,c]`.

- `s1` is the exact first rotary query-key score.
- `s2` is the exact second rotary query-key score.
- `p` is the exact value-and-output payload, projected into the 16 output directions that the next computations use.

The product is the contribution made by one source token through one head before contributions are summed across
heads and source positions. “Rotary” means that query and key vectors are rotated by their relative token positions
before their dot product. “Payload” means what will be written if that source is selected; computationally it is the
source state multiplied by the head's value map and output map.

The 16 output directions were not chosen to make this experiment win. They reproduce the earlier rung-419
downstream interface, whose usefulness was independently replicated on 96 completely different documents in rung
421. On those fresh rows, the shared payload approximation retained 69.1% of the routed signal and beat an
equal-budget private-per-head approximation by 5.7 percentage points. That replication licenses using the interface
as a measurement device, not as a compressed model.

## 2. The three equal-size models

All three models use exactly the same sizes:

- six modes across the nine head values of `s1`;
- six modes across the nine head values of `s2`;
- 32 modes across the `9 heads × 16 output coordinates = 144` payload values.

An affine projection subtracts the average vector, projects the centered vector into a lower-dimensional subspace,
and then restores the average. If `B` has orthonormal columns, the computation is

`reconstruct(x) = mean + (x - mean) B B^T`.

The three arms were:

1. **Marginal PCA:** choose each subspace separately to reconstruct its own inputs. PCA, or principal-component
   analysis, selects directions with the largest squared variation.
2. **Joint block model:** start from those same subspaces, then optimize them together to reconstruct the complete
   product `s1*s2*p`, including the head-summed output measured by downstream response.
3. **Wrong-pairing control:** keep the fitted vectors, ranks, spectra, and parameter count, but pair score branch 2
   from head `h+4` with branch 1 and the payload from head `h`. This asks whether the correct contraction matters.

The screen stores 23,310 numbers: 18,432 for the 1,152-by-16 output interface and 4,878 for means and bases. Because
the native generators are still present, its net saving is zero.

The fit used 96 documents and the reported measurements used 96 disjoint documents. Every causal source position
was included for query positions 16, 32, ..., 240. The unopened FINAL split remained unopened.

## 3. Held-out result

Here `relative MSE` is squared reconstruction error divided by the exact target's squared magnitude, measured after
the downstream response weighting. Lower is better. `R²` is `1 - error/target magnitude`; 100% is exact, 0% is no
better than writing zero, and a negative value is worse than writing zero. `CE damage` is the increase in
cross-entropy loss in natural-log units; lower is better.

| held-out measurement | separate PCA | jointly fitted | wrong pairing |
|---|---:|---:|---:|
| summed-edge relative MSE | 31.675% | **0.972%** | 162.977% |
| routed 16-mode R² | 70.787% | **98.525%** | -71.812% |
| mean downstream-response R² | 75.874% | **99.285%** | -48.856% |
| CE damage | +0.004356 nat | **+0.000200 nat** | +0.550677 nat |

Joint fitting reduces held-out summed-edge error by 96.93% relative to fitting the three factors separately. It also
improves routed R² by 27.74 percentage points and mean downstream-response R² by 23.41 points.

Every individual reader is retained, not merely the average:

| downstream reader | joint R² |
|---|---:|
| MLP0 | 99.278% |
| attention1 query branch 1 | 99.445% |
| attention1 key branch 1 | 99.284% |
| attention1 query branch 2 | 99.299% |

The correct pairing is essential. The wrong-pairing control has the same parameter count and individual mode
values, yet it produces negative R² and more than half a nat of language-model damage. This rules out the idea that
the win comes merely from retaining high-variance score and payload directions.

## 5. What this says about heads, shared inputs, and shared outputs

The result directly supports the user's proposed viewpoint: an architectural head is an implementation index, not
necessarily a mechanism basis. The useful decomposition has to preserve a three-way relation:

`first score feature × second score feature × output feature`.

Two computations can share either score feature while using different partners or outputs. Conversely, different
score pairs can lead to the same downstream output mode. The jointly fitted block can express both cases; a whole-
head clustering cannot.

Rungs 422 and 423 add useful structure:

- The shared QK token geometry has no sharp rank cutoff: its unexplained overlap falls almost linearly as rank rises
  from 24 to 104. It is broad rather than one small global carrier.
- Task-relevant OV payloads genuinely occupy this QK token geometry at about 90–370 times the random/permuted
  control overlap.
- Heads 3 and 7 are strongest users of that shared input geometry, while head 6 is the outsider. Head 3 can still be
  output-private: sharing an input vocabulary does not imply that downstream readers treat the resulting output as
  redundant.

This resolves the apparent gauge problem at the screen level. We never interpret a private coordinate inside one
head. We compare complete functions on tokens, complete realized products, and downstream effects, all of which are
unchanged by invertible rotations of an internal head coordinate system.

## 6. Next physical test

The screen's success licenses one specific next experiment: replace the native generators of the retained modes.
For each learned score mode, fold its head loadings into the exact QK bilinear matrices and factor the resulting
composite bilinear form into directly executable query and key maps. For the 32 payload modes, fold the payload basis
through the exact OV maps and test a directly executable token-to-payload factorization.

The controls must compare equal literal parameter prices:

- joint composite bilinear factors;
- independent per-head factors;
- ordinary QK rank purchased at the same price;
- a factor with the correct spectra but wrong QK-to-payload coupling.

The first gate is algebraic: the direct generators must reproduce the successful realized projection. The second is
economic: at a fixed number of stored values, they must beat ordinary rank reduction. The third is causal: the
held-out downstream R² and CE advantage must survive without computing the native generators. Only that sequence
would turn today's mechanism identification into compression or adoption.
