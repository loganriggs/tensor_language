# Robust-circuit update — 2026-09-03 19:30 UTC

## Main result

The broad “increment” idea has now been split into two counterfactually supported behaviors:

1. **Numbered-list index successor:** read the final visible list label and predict the next integer label.
2. **Numeric-sequence continuation:** read a comma-separated numeric sequence and its relation, with transfer between
   digits and number words.

This split is behavioral rather than architectural. We have not assumed that an attention head or MLP is the true
unit. The old broad increment dossier is closed as a split parent, and each child has its own canonical record, data,
evidence, and next experiment.

## Fresh counterfactual data

R567 contains 1,200 unique prompt pairs in 160 semantic groups. Eighty groups belong to each behavior. Within each
behavior, FIT, SELECT, FINAL_TEST, and OOD contain 32, 16, 16, and 16 whole groups. All variants derived from one group
remain in one split. None of the 1,609 unique token sequences overlaps the R566 development screen.

The list data contains two- and three-line state shifts, noun changes, an earlier-middle-label edit, repeated labels,
and a conflict between arithmetic `+2` and “final visible label + 1.” The sequence data contains digit, number-word,
and cross-format shifts; surface changes; copy controls; a middle-value edit; and a `+2` diagnostic.

A pre-model review corrected one semantic label. Editing an earlier list label while holding the final label and answer
fixed is an **invariance** test for a final-label successor circuit, not a necessity test. The exact prompts and splits
did not change. The sequence middle-value edit remains a necessity test because that separate claim says the relation
is read.

## Native model gates

For an answer token $a$ and representation-matched numeric candidate set $N$, the basic measurement was

$$
m(x,a)=z_a(x)-\max_{b\in N,\ b\ne a}z_b(x).
$$

Each normal cell required at least 75% positive margins and a positive lower bound from 2,000 group bootstrap samples.
FIT and SELECT were decided independently for each behavior. Both passed.

![Fresh numbered-list and numeric-sequence gates](rung569_570_native_gates.svg)

For numbered lists, every two- and three-line state-shift endpoint was 100% accurate. Every noun and middle-label
invariance endpoint was also 100%. The weakest cell was one SELECT repeated-label surface endpoint at exactly 75%,
with a positive bootstrap lower mean margin of 0.273 logits. On the `+2` conflict, “final label + 1” beat arithmetic
continuation on every one of 64 FIT and 32 SELECT endpoints.

For numeric sequences, every digit, number-word, cross-format, surface, and copy endpoint was 100% accurate. More
importantly, changing only the middle value reduced the registered `+1` answer margin in every group. The bootstrap
lower mean reduction was 1.197 logits on FIT and 1.011 on SELECT. Thus the model is not merely applying successor to
the last value; it uses evidence from the preceding relation under these prompts.

The `+2` sequence diagnostic was deliberately not a pass/fail gate. Arithmetic `+2` beat last-value successor on
46.9% of FIT endpoints and 18.8% of SELECT endpoints, so this behavior is not stable enough to name as a `+2` circuit.
It remains valuable as a later selectivity control.

R571 independently recomputed 1,344 saved endpoint margins, 50 cells, the middle-value paired effects, hashes, and
conditional split openings. It was written without reading the result, but the result file landed before the audit was
durably frozen, so it is correctly labeled a post-result structural audit. R572 then separately reevaluated and saved
all 96 list-conflict endpoint margins. Its aggregates matched R569 within $8.1\times10^{-7}$.

## Activation-level work now underway

R573 asks whether the list state is transported specifically by the final label's value contribution in L8H7/L8H3,
rather than treating those heads as indivisible units. At final query position $q$, head $h$, and source $k$, the exact
term is

$$
t_{h,k}=p_{h,q,k}W_O^{(h)}v_{h,k}.
$$

The experiment will separately transplant the attention score $p$, the projected value $W_Ov$, and their joint term;
it will compare the final label with all label positions and split the layer-8 value into its own-layer part and its
cached layer-0 value part. The complete L8H7/L8H3 output is only a positive ceiling.

The CPU coordinate audit has already mapped all 288 eligible FIT/SELECT rows. Every label is a single semantic token,
every query is the final newline, and two- versus three-line prompts are aligned by line identity rather than fixed
absolute position. The target state shifts and all four answer-preserving controls enter the same selection decision.
There is no rank sweep or learned subspace.
