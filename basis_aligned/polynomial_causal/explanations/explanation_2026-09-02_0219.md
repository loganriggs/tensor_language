The old plan tried to predict whether lower-rank approximations preserved one ablation and one two-edit interaction.
Those are useful robustness checks after a decomposition has been chosen, but they do not discover circuits. That

The first concrete target is a known equality/copy computation spanning four attention heads: L5H5, L7H3, L8H3, and

backgrounds, measures their finite interactions, and tracks which later attention and MLP modules respond.

The mathematical analysis, grouping statistic, and pre-run audit checklist now exist and pass synthetic software
checks. The factorial itself has not been preregistered or run, so there is not yet evidence about which heads group
together or which MLPs consume their writes.

## The interpretability goals now enforced in the hourly review

Every proposed experiment must say which of these properties it advances:

1. **Computational specification:** what information is read, what operation is performed, what is written, and what
   later computation uses it.
2. **Correct boundaries:** group pieces across native heads/MLPs when they implement one variable, and split a native
   module when its pieces implement different tasks.
3. **Held-out and OOD prediction:** predict activations and behavioral effects on unseen contexts, task variations,
   and shifted data.
4. **Extraction or sufficiency:** isolate an executable computation, or a precisely stated interface plus background,
   that reproduces the target effect.
5. **Selective manipulation:** remove, swap, or edit the target computation without substantially changing unrelated
   behavior, including tests for redundancy and interactions.
6. **Composition and reuse:** identify shared computations and predict how they combine with task-specific branches.
7. **Stable identification:** recover the same operational units across document/corpus splits, fitting restarts, and
   equivalent parameter gauges.

Lower rank, fewer parameters, lower reconstruction error, and better CE are not circuit results by themselves. They
may be matched-capacity controls, mathematical bounds, or later implementation costs after a circuit has been
identified.

## Why the general 62-behavior battery is not enough here

The earlier proposal was to use each candidate piece's 62-dimensional downstream response as its identity. The audit
found that this cannot be the sole signal for the first task decomposition:

- the battery's stored census explicitly says the induction band is absent; and
- its behavior tags contain no named copy, induction, previous-token, or ordered-successor task.

The battery remains useful for broad collateral measurements. Dedicated copy/induction conditions are required to
distinguish the particular computations we want to group. These should include induction positives, generic copying,
repeat positions where copying would be wrong, nonrepeat text, repeat distance, distractors, number of matches, and
payload identity.

## The exact four-head computation already available

For query position `q`, source position `k`, and head `h`, define the shared equality support

`M[q,k] = 1[token[q] = token[k-1]] × 1[1 <= k <= q]`.

The exact equality-edge contribution from one head is

`e_h(q) = O_h sum_k M[q,k] score1_h(q,k) score2_h(q,k) value_h(k)`.

The four heads share `M`, but retain their own two continuous attention-score branches, value features, output map,
and layer. This is a proposed shared input relation with four possibly different output/use branches. It does not yet
show that the four branches are interchangeable.

Existing all-four-head results establish that the combined object is real:

| Measurement | Result | Interpretation |
|---|---:|---|
| Remove all four equality terms on the discovery set | `+.51225 nat` on induction positives | the combined equality computation is necessary there |
| Restore only equality terms after deleting the four heads | `.97397` recovery | the equality terms nearly reproduce the deleted heads' positive-cell effect |
| Token-permuted equality relation | `-.00216` recovery | correct token identity, not merely a similarly sized edge set, matters |
| Discovery off-target damage | `+.006264 nat` | selective on that dataset |
| New natural-text extraction recovery | `.90851` | extraction transfers well |
| Repository-disjoint code extraction recovery | `1.01041` | extraction also transfers to code positives |
| Code off-target damage | `+.13831 nat` | the service is not induction-specific |

The final natural and code runs both failed their collateral guarantees. This is not evidence that the equality
computation is false. It says equality copying is a broad reusable service. The next decomposition should share the
matcher while separating the output or downstream use that makes one path induction-specific.

At L8H3/H4, earlier work already gives a finer split. At a repeated token, `95.4%` of the matched full-head effect
comes from the edge to the token following the earlier occurrence. Most of its payload comes through the shared
block-0 value bus: removing that part adds `.11692 nat`, while removing the fresh contextual value adds only
`.00544 nat`. But replacing the native contextual attention strength with an old static matcher or distance bins
recovers only `38.7%` or `30.0%`. Thus source relation, continuous QK strength, and payload are distinct pieces.

## The proposed 16-subset experiment

Let

`H = {L5H5, L7H3, L8H3, L8H4}`.

For every subset `S` of these four heads, run two configurations:

1. **Removal:** begin with the native model and subtract `e_h` for every `h` in `S`.
2. **Extraction:** delete the four complete head writes and restore `e_h` only for heads in `S`.

There are `2^4 = 16` subsets, so this gives 16 removal and 16 extraction configurations. The empty and complete
subsets provide the native/head-deleted and all-removed/all-restored endpoints.

For task condition `c`, define the recovered effect of an extraction subset as

`y_c(S) = CE(heads deleted, c) - CE(restore subset S, c)`.

Larger `y_c(S)` means that subset restores more of the task effect. The complete table has a unique finite
interaction decomposition. For head set `T`, its interaction is

`d_c(T) = sum_{S subseteq T} (-1)^(|T|-|S|) y_c(S)`.

For two heads:

- `d < 0` means redundancy: each alone provides overlapping benefit;
- `d > 0` means complementarity: the pair provides benefit that neither supplies alone; and
- `d approximately 0` means their recovered effects add independently.

The analysis utility also assigns each head a Shapley value by sharing every interaction equally among the heads that
participate in it. This is simply a fair accounting of the complete subset table, not evidence that a head is the
true semantic unit.

## Where interactions can occur

The local equality writes are exactly additive. Each `e_h` occupies its own head slot, and the output projection is
linear. Therefore every interaction of order two or higher is zero in the immediate write itself, apart from floating
point rounding.

Any nonzero interaction in CE, logits, or later module outputs must arise after these writes enter the residual
stream—through later normalization, attention, MLPs, and the nonlinear conversion from logits to CE. The factorial
therefore measures how downstream computation combines four additive inputs. It does not discover a mysterious
interaction inside the output projection.

## Interaction uncertainty

The new subset-analysis utility implements the equation above and exactly reconstructs arbitrary 16-cell synthetic
tables. If each measured subset outcome has independent numerical noise with standard deviation `sigma`, an
order-`k` interaction has noise

`sigma_interaction = 2^(k/2) sigma`.

Using the project's approximate GPU wobble `sigma = .003`, the suggested minimum resolvable magnitudes are:

| Interaction order | Approximate numerical floor |
|---:|---:|
| 2 | `.006` |
| 3 | `.0085` |
| 4 | `.012` |

These are pre-run recommendations, not measured factorial results. The actual registration should estimate the
relevant repeatability and require any claimed interaction to clear it.

## How a proposed group will be tested

Similar response vectors are only a grouping proposal. The stronger test is interchange:

- swap naturally occurring instances of two terms proposed to be in the same group;
- measure the resulting change in the registered task effects; and
- compare it with swaps between proposed groups.

Define

`separation = mean absolute between-group change / mean absolute within-group change`.

A valid group should have small within-group changes and materially larger between-group changes. A label-permutation
test asks whether the observed separation could arise without the proposed grouping.

The new utility passes synthetic checks: a planted valid grouping gives separation `76.6` with permutation
`p=.0001`, while identical within/between distributions give `1.02` with `p=.35`. These values validate the analysis
code only. No model grouping has been tested.

## Connecting the heads to downstream attention and MLPs

For each equality-term intervention and later component `j`, capture

`Delta y_j(h,x) = write_j(model with e_h changed, x) - write_j(native, x)`.

This identifies candidate consumers. A later component should only be called a consumer after a finite patch test:
insert its intervention-induced write change into the relevant removal run and ask whether this predicts or repairs
the task effect on held-out examples.

If a bilinear MLP is selected, its native product channel `k` contributes

`write_k(x) = Down[:,k] × (Left[k] x) × (Right[k] x)`.

Those native channels are candidate terms, not assumed circuits; previous MLP2 work showed strong cancellation among
them. The MLP should be split by groups or learned mixtures whose task responses and patch repairs differ reliably.
This is the step that can turn “these four heads share an equality relation” into “this MLP subcomputation uses that
relation for induction, while another branch uses it for generic copying.”
