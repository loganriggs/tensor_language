## The goal

We want an executable account of the model in which a circuit tells us:

- what information it reads;
- what operation it performs;
- what it writes and which later computation reads it;
- how its behavior changes on unseen and shifted inputs;
- whether it can be isolated or extracted;
- whether it can be removed, swapped, or edited without changing unrelated behavior; and
- whether parts should be grouped across native heads/MLPs or split within one native module.

Only after a circuit is identified this way does it make sense to ask whether it has a smaller implementation. Lower
rank, fewer bytes, reconstruction error, or aggregate CE alone do not discover the circuit.

## Exact computation being changed

At a query position `q`, the equality relation selects a source position `k` when the query token equals the token
immediately before `k`:

`M[q,k] = 1[token[q] = token[k-1]] 1[1 <= k <= q]`.

For head `h`, the selected contribution is

`e_h(q) = O_h sum_k M[q,k] score1_h(q,k) score2_h(q,k) value_h(k)`.

In ordinary terms, the relation finds an earlier occurrence of the current token and routes information from what
came after that occurrence. The two attention scores decide the continuous strength of the route. `value_h(k)` is
the information carried from the source, and `O_h` maps that head's 128-dimensional value into the model's
1,152-dimensional residual stream.

The four terms share the token-equality relation but retain different scores, carried values, output maps, and layer
positions. Sharing the relation therefore does not imply that they are the same circuit.

## The 32 interventions

For each of the `2^4 = 16` head subsets `S`, run two backgrounds:

- **Removal:** start from the native selected heads and subtract the equality term for every head in `S`.
- **Extraction:** delete all four selected head writes and restore the equality term only for heads in `S`.

Removal tests necessity in the full model. Extraction tests how much of the behavior the selected terms can reproduce
without the other parts of those four heads. Using both backgrounds matters because two terms can look individually
unnecessary in the full model due to redundancy while each remains sufficient when extracted.

The model is replayed sequentially. If layer 5 is changed, layers 6 onward receive the changed residual stream. At the
point where the four writes enter the residual stream, they add linearly. Therefore any measured interaction comes
from later normalization, attention, MLPs, logits, or the nonlinear CE calculation—not from the four output vectors
mysteriously colliding inside the local output projection.

## Task conditions

The natural-text role contains these frozen conditions:

| Condition | What it means | Tokens | Documents |
|---|---|---:|---:|
| matched positive | an earlier equal token is followed by the correct current target, balanced against a negative | 225 | 121 |
| matched negative | similar position, distance, frequency, and repeat count, but the earlier token has a different successor | 225 | 131 |
| all positive | every scored position satisfying the nearest-successor copy relation | 3,084 | 191 |
| near positive | the nearest earlier equal token is at most 16 positions away | 719 | 160 |
| far positive | it is more than 16 positions away | 2,365 | 191 |
| one previous match | the query token appeared exactly once earlier | 1,366 | 190 |
| multiple previous matches | it appeared at least twice earlier | 1,718 | 185 |
| off target | scored positions outside the positive relation and matched negatives | 33,555 | 192 |

The distance conditions partition all positives, as do the one-versus-multiple-match conditions. They are derived
only from frozen token IDs, before any subset model outcome is seen.

These conditions address an important ambiguity. Two head terms might look redundant after averaging all positives
but separate cleanly because one handles nearby repeats and another handles distant repeats, or because one becomes
important only when several earlier matches compete.

## How redundancy and complementarity are computed

For extraction subset `S` and task condition `c`, define recovered effect

`y_c(S) = CE(all four heads deleted, c) - CE(restore S, c)`.

A larger positive value means that subset restores more predictive performance. For two terms `a` and `b`, their
interaction is

`d_c({a,b}) = y_c({a,b}) - y_c({a}) - y_c({b}) + y_c(empty)`.

- A negative value means redundancy: each term alone restores overlapping benefit.
- A positive value means complementarity: later computation gains extra benefit when both are present.
- A value near zero means their effects add independently, or the experiment cannot resolve the interaction.

The primary pair is L8H3 with L8H4. A second comparison treats L5H5+L7H3 as an early block and L8H3+L8H4 as a
layer-8 block. That asks whether the two depths are alternative providers or successive contributors used together by
later computation.

The approximate pre-run numerical floor is `.006 nat` for a two-term interaction, `.0085 nat` for three terms, and
`.012 nat` for four. The run will also use a 20,000-draw document bootstrap and simultaneous 95% intervals. We will
not label an interaction when it fails to clear both statistical uncertainty and the numerical floor.

## What would count as progress

A natural-text grouping can advance to code confirmation only if:

- the redundancy/complementarity classification agrees in two fixed 96-document halves;
- the effect clears the numerical floor in both halves;
- the relative allocation across the four terms is stable between halves; and
- its full effects on matched negatives and off-target positions are reported rather than hidden by the positive
  average.

Even then it is a proposed grouping, not an adopted circuit. The next gates are:

1. reproduce the frozen classification on the still-unopened code subsets;
2. show that swapping naturally occurring instances within a proposed group changes behavior much less than swapping
   between groups; and
3. identify a later attention or MLP computation whose patched response explains or repairs the task effect.

That third step is how this work will move from “these head terms behave similarly” to “this later computation reads
them as the same variable” or “they feed different branches and should not be merged.”

## Failure outcomes that remain useful

The experiment is a null if the subset differences are below noise, the signs change across document halves, or the
instrument/replay checks fail. A clean null would mean the four equality terms are still the wrong units. The next
decomposition should then go below them—shared Q or K features across heads, distinct value features, or equivalence
defined by downstream readers—rather than trying another rank sweep over the same native boundaries.
