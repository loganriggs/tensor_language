The replacement behavior is a much cheaper local repetition task.  Its complete four-phase dataset and FIT-only

## 1. The strict positional-list task failed native capability

Task 17 asked the model to retrieve an item at a named position, for example

```text
Items: red, blue, green, black. Item 2:  ->  blue
```

Before looking for a circuit, the model had to solve four registered transformations of the same underlying list:

- A1 changes the queried position, so the answer must change;
- A2 changes which value is stored at the queried position, so the answer must change;
- P changes an unqueried value, so the answer must stay the same; and
- C changes the queried position between two copies of the same target, so the answer stays the same even though the
  internal selection should change.

“Base” and “donor” are the two sides of each matched comparison.  Forced-choice accuracy means

$$
\mathbf 1\!\left[\ell_{\text{answer}}>\max_{f\in\text{registered foils}}\ell_f\right],
$$

where $\ell$ is the model's next-token logit.  This is not full-vocabulary top-1 accuracy: it asks whether the answer
beats the alternatives explicitly registered for that row.

The frozen gate required at least 80% accuracy on each side, at least 75% in every transformation-by-side cell, and
positive mean answer margins.  The model achieved only 43.75% on base prompts and 40.63% on donor prompts.  The worst
cell was 29.17%, and both mean margins were negative.

![Task 17 capability compared with its thresholds](assets/task17_capability_gate.svg)

The run used exactly eight forward calls, 192 prompt-side evaluations, and 1,536 raw numeric bytes.  Every provenance
and phase-closure check passed.  Therefore this is a scientific capability failure, not a broken program: all circuit
outputs are null and SELECT, TEST, and out-of-distribution data remain unopened.  The exact audit is
[here](../CIRCUIT_BATTERY_TASK17_CAPABILITY_FIT_POSTEXECUTION_AUDIT_2026-09-04.md).

## 2. Task 21 is local previous-token repetition

The next authority uses the established behavior `verbatim_repeat.copy`.  A schematic prompt is

```text
... cedar cedar  ->  cedar
```

The correct answer is always the immediately preceding token.  That makes this a good low-risk test of the strict
pipeline, but it is crucial not to rename it “induction” or “remote copying.”  The current token embedding can carry
the answer directly through the residual stream without any attention head retrieving an earlier occurrence.

Each of four phases has 21 independent token groups and four linked transformations:

- A1 replaces the whole repeated run and changes the answer;
- A2 replaces only the newest run while leaving an older conflicting target visible;
- P changes a novel leading filler and preserves the answer; and
- C adds one more copy of the same target and preserves the answer.

The complete authority contains

$$
4\text{ phases}\times21\text{ groups}\times4\text{ transformations}=336\text{ rows}.
$$

Within every phase, every one-token word appears exactly once as the target, alternative, control replacement, and in
each filler position.  The phase vocabularies are disjoint.  This exact balancing prevents an easy token from appearing
mostly in one transformation and making that transformation look artificially capable.

The FIT capability screen costs eight model forwards: four 21-row base batches followed by four 21-row donor batches.
That is 168 row-side evaluations.  It saves two 32-bit numbers per side—the answer logit and largest registered-foil
logit—for

$$
168\times2\times4=1{,}344\text{ raw bytes}.
$$

It passes only if both sides reach 90%, every one of eight transformation-by-side cells reaches 85% (at least 18 of 21
rows), and both mean margins are positive.  A failure closes the task with all circuit fields null.  A pass reports
native capability only; it cannot select a layer, head, or subspace.

Independent review reproduced all 336 rows, token-role balance, prompt and answer tokenization, exact call/byte price,
phase isolation, and fail-closed mutations.  The approved object is commit `9ebab946…`; the review explicitly does not
authorize execution.  See the
[authority/compiler review](../TASK21_VERBATIM_COPY_AUTHORITY_COMPILER_REPRODUCIBILITY_REVIEW_2026-09-04.md).

## 3. A state defined by downstream behavior

The previous 768-dimensional analysis retained leading covariance eigenvectors.  There was no eigenvalue gap at 768:
it was a convenient two-thirds-of-1152 operating point with tolerable CE damage.  That is why the width was useful for
an approximation experiment and why it was not a semantic cutoff.

The new construction starts from a computation.  Let $u$ be a prompt and let $t$ be a registered future continuation
or intervention.  Write $F(u,t)$ for the resulting observable response.  We call two prompt states equivalent when

$$
u\sim v\quad\Longleftrightarrow\quad F(u,t)=F(v,t)
\quad\text{for every registered }t.
$$

This can group pieces from different heads if no later computation distinguishes them, and split one head if two of
its directions behave differently.  It is related to predictive-state representations and Hankel minimal realization,
but here the practical requirement is simple: a proposed state must predict held-out responses and survive physical
interchange tests.

For task 21, a future localization stage should retain every candidate token's logit, not just the answer and largest
foil.  Removing a shared offset gives the 21-number response

$$
r_a=\ell_a-\frac{1}{21}\sum_{b=1}^{21}\ell_b.
$$

An ideal copier has 21 discrete answer identities.  Their mean-centered response vectors span 20 dimensions because
the 21 entries sum to zero.  These are derived properties of the declared task, not widths chosen from a smooth
spectrum.  C then asks whether repeat count merely changes confidence along the token-identity pattern or supplies an
additional variable that later readers can distinguish.

The full response would cost only

$$
168\times21\times4=14{,}112\text{ raw bytes}.
$$

That is a requirement for a future localization experiment, not a change to the frozen capability run.  The complete
derivation and its connection to tensor-train/weighted-automaton mathematics are in the
[06:30 mathematical review](../THREE_HOURLY_MATHEMATICAL_REVIEW_2026-09-04_0630.md), with the operational checklist in
[the task-21 predictive-state requirements](../TASK21_PREDICTIVE_STATE_LOCALIZATION_REQUIREMENTS_2026-09-04.md).

## 4. How this becomes a weight-level circuit

If task 21 passes capability, we will test a proposed residual subspace $P$ with a donor interchange:

$$
Pz(x)\leftarrow Pz(y).
$$

The entire 21-candidate response should move toward donor $y$, across several valid donors expressing the same token
change.  We then test necessity by clamping that state back to the recipient value and sufficiency by injecting it
without changing the upstream prompt.  P and C provide answer-preserving controls, and unrelated behaviors test
selectivity.  The direct final-token residual path is a required competing explanation.

When a later bilinear MLP reads the state, its exact change can be written in the weights.  For normalized recipient
input $\bar z_0$ and changed input $\bar z_1=\bar z_0+\delta$,

$$
\begin{aligned}
M(\bar z_1)-M(\bar z_0)=W_D\big[&
(W_L\delta)\odot(W_R\bar z_0)
+(W_L\bar z_0)\odot(W_R\delta)\\
&+(W_L\delta)\odot(W_R\delta)\big].
\end{aligned}
$$

The three terms are the changed left input, changed right input, and their finite interaction.  They exactly reconstruct
the MLP write difference; no local Taylor approximation or low-rank truncation is involved.  This connects a
counterfactually meaningful state to physical quadratic weights.

## 5. A separate diagnostic found an entangled numeric feature

A parallel exploratory line found a sharp hypothesis about numeric runs.  With step size ten, multiples of ten were
continued by the step on 6/6 examples, while non-round starts never used the step on 48 examples and sometimes used
“last value plus one” instead.  Patching attention 8 recovered 58.9% of the step-versus-plus-one decision and ranked
first among 36 modules in both tested surface formats.

Within attention 8, heads 3 and 7 carried 92.5% of the positive head-level recovery.  A single direction fitted in
head 3 on one half of the pairs reproduced 87.4% of that head's held-out effect; independently fitted directions on
percentage and bare-number formats had absolute cosine similarity 0.974.  A matched random direction recovered
approximately zero.

However, the direction also had absolute cosine 0.819 with the head's ordinary mean output, missing the registered
separation bar.  In plain terms, “roundness” is not cleanly orthogonal to the bulk item-identity write.  Heads 3 and 7
appear to carry both the last item and an attribute that affects which arithmetic is used downstream.  This is exactly
why head boundaries are too coarse.

These runs are useful diagnostic evidence, not an adopted circuit: they use narrow hand-built pairs, not the strict
four-phase authority; they do not yet establish selective removal, OOD generalization, or composition.  A causal
steering test is preregistered in that lane, but it must not be merged into task 21's strict evidence.

is real but small relative to experiment design and review time.
