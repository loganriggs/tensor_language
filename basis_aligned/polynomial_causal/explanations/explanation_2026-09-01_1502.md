# Plain-English MLP0 token/context decomposition — 2026-09-01 15:02 UTC

## Goal

The project goal is to replace bilin18 with a smaller tensor program that remains predictive on new and shifted
text, composes when several replacements are installed together, and preserves the model's responses to controlled
edits. For MLP0, the nearer goal is unusually ambitious: explain the entire layer as a token-only computation, a
token-by-context computation, and a context-only computation, while keeping exact token identity wherever no honest
shared code exists.

We have now made substantial progress on that nearer goal. The split is an exact algebraic identity, and its four
semantic parts have been measured through the rest of the model on separate fitting and held-out documents.

## The exact computation being split

Let `e` be the current token's residual-stream vector before attention0, and let `a` be the vector written by
attention0 from the available prefix. Thus the state entering MLP0's normalization is `e+a`. Let `z` be the actual
normalized state seen by MLP0.

The bias-free MLP0 write is a quadratic map

`T(z,z) = Down((Left z) * (Right z))`,

where `*` means coordinate-by-coordinate multiplication. More generally,

`T(u,v) = Down((Left u) * (Right v))`

is the corresponding bilinear map: linear in `u` when `v` is fixed and linear in `v` when `u` is fixed. `Left` and
`Right` each produce the product-feature coordinates; `Down` converts those products back into the model's
1,152-dimensional residual stream.

To separate token from context without relying on the accidental token/context pairings in a document, define

`G(e,a) = T(e+a,e+a)`

and average it over an independently crossed reference distribution of fitting tokens and fitting contexts. This
gives the exact centered functional ANOVA

`G(e,a) = mean + token-main(e) + context-main(a) + token-context(e,a)`.

The terms have ordinary computational meanings:

- `T`, the token main effect, is what changing the current token does on average across independently sampled
  contexts.
- `C`, the context main effect, is what changing attention0's continuous prefix summary does on average across
  tokens.
- `I`, the interaction, is the extra effect of a particular token and context occurring together after both main
  effects have been removed. This is the centered token-by-context computation.
- `S` is the modulation caused by RMSNorm's example-specific scalar gain. It says that the strengths of all three
  preceding computations vary slightly with the norm of the current state.

The actual normalized vector is not perfectly equal to one scalar times `e+a` in BF16 arithmetic. We therefore keep
the observed vector residual `r = z - s(e+a)` explicitly. Its exact quadratic contribution is

`R = T(s(e+a),r) + T(r,s(e+a)) + T(r,r)`.

`R` is retained in every intervention arm. It is numerical bookkeeping, not a proposed semantic feature or a
floating-point compression scheme. With it, the decomposition reconstructs the native MLP0 computation to relative
mean-squared error **2.89e-13** on held-out documents.

## Causal result on natural text

We physically evaluated all 16 subsets of `T`, `C`, `I`, and `S`, always retaining the mean, bias, and exact residual
`R`. A Shapley value here is the average reduction in next-token cross-entropy obtained by adding one term across
every possible ordering of the other terms. It is used because the model after MLP0 is nonlinear: the score of two
terms together need not equal the sum of their separate scores.

| MLP0 role | fitting documents | held-out selection documents | plain meaning |
|---|---:|---:|---|
| token×context interaction `I` | 1.501 nats | **1.538 nats** | the context changes the token-specific computation |
| token main `T` | 1.470 | **1.498** | the token's average write across contexts |
| context main `C` | 0.351 | **0.418** | an additive effect of the prefix summary |
| normalization modulation `S` | 0.054 | **0.067** | state norm changes the overall gain |

The signs and ordering reproduce on the disjoint document split. The three context-dependent roles together have
held-out Shapley value **2.023 nats**, exceeding the token main effect's **1.498 nats**. The largest single role is
the centered token×context interaction, not token identity by itself and not an additive context feature.

One preregistered prediction still failed and remains failed: we predicted that the standalone context main effect
would be at least 0.50 nat, but it was 0.418. This is informative. Context acts chiefly by changing the quadratic
processing of the current token, rather than by contributing a large token-independent write.

The first implementation missed its deliberately strict exactness bar because a scalar approximation to RMSNorm
left a tiny vector residual. We did not loosen the bar. We wrote that residual into the algebra, reran the same 16
arms, and obtained exactly the same cross-entropies and Shapley values while improving the identity error from about
1.5e-6 to 2.9e-13. The repaired result passed every registered repair and transport check; no final test set was
opened.

## How this connects to the token-only result

At sequence length one, attention0 can only attend to the current token, so its write is itself a deterministic
function of that token. The earlier `M + L + Q` analysis therefore described the complete token-fed boundary in that
special setting:

- `M` is a shared operating-point write;
- `L` is a compact token-label/control modulation, with some local shared semantic pairs;
- `Q` is a broad, correctly paired quadratic token correction that is mostly token-private.

That is not contradicted by the new `T/C/I/S` grammar. On natural text, `T` is the token effect averaged across
contexts; its internal token anatomy can still contain `M`, `L`, and `Q`. `I` is the new part that length-one data
cannot reveal: how attention0's prefix summary changes the quadratic action of a particular token.

This also sharpens why MLP0 writes token-specific information even though later layers retain the input token. It is
not merely copying the embedding. It prepares a nonlinear correction in coordinates used immediately by attention1
and MLP1. Attention1 reads one narrow direction of the private quadratic correction, while MLP1 reads a broad
spectrum. Exact token identity remains the simplest faithful account of that broad part. We found a few local
same-effect pairs—such as related adverbs, conjunctions, and years—but no global token grouping survived the matched
interchange controls.

## What is established, and what is not

Established at the identification level:

- MLP0 has an exact token/context/interaction/normalization grammar.
- On natural text, the token×context interaction is its largest causal role.
- Context-dependent computation in aggregate is at least as important as the token main effect.
- The result transports from fitting to held-out documents and survives an exact reconstruction repair.

Not yet established:

- This is not a compression or replacement. The diagnostic reuses all 15,926,400 native MLP0 weight values and adds
  only reference statistics for attribution.
- `I` is not yet semantically decoded. We know that it binds a continuous attention0 summary to the current token,
  but not yet which attention heads, source positions, or human-readable prefix features carry most of it.
- The token-only private correction still has no licensed sparse code. A simpler token grouping should only replace
  exact identity if physical downstream interchange validates it.

## Next direction

The next high-information object is `I`, selected prospectively because it was largest on both document splits. The
most direct interpretation is to exploit bilinearity again: attention0's context write is a sum of contributions
from heads and source positions, so the centered interaction is correspondingly additive in those contributions.
Before running anything, we will audit the attention0 and MLP0 dossiers for an existing equivalent result. If it is
new, the next registered experiment should decompose `I` by attention0 head and source position, then physically
remove or interchange the largest terms under fixed controls. That can turn “continuous context” into a small set of
named information routes—or falsify the hope that such a small set exists.

In parallel, a branch-resolved audit of the already adopted rank-448 MLP0 context projection can ask whether its
approximation error is concentrated in `I`, `T`, `C`, or `S`. That is the shortest bridge from this exact explanation
to an actually smaller executable program. Neither route will reopen token-only rank tuning.
