# Research update — 2026-09-01 17:43 UTC

## Goal

Our goal is to replace bilin18 with a smaller, transparent tensor program that still predicts new and
out-of-distribution text, composes when several replacements are installed together, preserves controlled causal
effects, and wins after the tensors actually retained by the program are counted.

Cross-entropy, abbreviated CE, is the average negative natural logarithm of the probability assigned to the correct
next token. Lower is better; one nat is its natural-logarithm unit.

## 1. Importance of the four MLP0 branches

Let t denote the centered current-token contribution to MLP0's input, c the centered context write from attention0,
and B(u,v) the learned bilinear map. The three main formulas are:

- token-only T = B(t,t);
- token-by-context I = B(t,c) + B(c,t);
- context-only C = B(c,c).

S is the remaining change caused by the example-specific normalization gain. We ran all16 subsets of T/C/I/S in
one exact physical factorial, so we can distinguish removing a branch from the complete computation from adding it
alone and from averaging its contribution over every background subset.

| branch | CE cost when removed from full | benefit when used alone | Shapley benefit | Shapley share |
|---|---:|---:|---:|---:|
| token T | 0.081710 nat | 3.343782 nat | 1.498335 nat | 42.55% |
| context C | 0.054333 nat | 1.180933 nat | 0.417729 nat | 11.86% |
| token-by-context I | **0.125540 nat** | **3.375897 nat** | **1.537530 nat** | **43.67%** |
| normalization S | 0.000774 nat | 0.354463 nat | 0.067493 nat | 1.92% |

The remembered values near one nat were not leave-one-out deletion costs. T and I are co-primary and strongly
overlap: each alone recovers more than3.3 nats, yet deleting either from the full computation costs much less.
C is secondary but real. S is the first branch to deprioritize.

## 2. Different formulas, but a shared output interface currently wins

The paths are different mathematical objects and should be allowed different internal descriptions:

- T is a finite token-conditioned quadratic function and can use exhaustive knowledge of all50,257 token inputs;
- I is a token-by-context bilinear operator;
- C is a symmetric quadratic function of context and contains within-mode and cross-mode products.

However, different formula does not imply separate output dictionary. At the same total64 output directions, a split
token-32 plus interaction-32 basis produced **+.005876 nat** held-out damage, while one joint T+I rank64 basis
produced **+.004838 nat**. A global total-error rank64 basis was slightly better again at **+.004769 nat**.

The present hypothesis is therefore separate path computations feeding a shared downstream output interface. Every
path-specific proposal must still face a global equal-price comparator.

## 4. Shared head-written subspaces and the exact gauge statement

For output-projected head writes a_h, context is c = sum_h a_h. Then I is additive across heads, while C expands into
nine within-head and36 cross-head quadratic terms. The earlier21-arm head assay measured every head alone and every
head removed, but not all512 head subsets, so it detected redundancy without assigning every pair or higher-order
interaction. The detailed percentage bar chart is in explanation_2026-09-01_1518.md.

There is gauge freedom inside a head: an orthogonal change on the private value/output bond can be undone by the
output projection; query/key changes are exact only when they commute with rotary positional rotations; heads can
also be permuted with all their parameters. Arbitrary continuous mixing between heads is not a symmetry because each
head has its own nonlinear attention pattern.

The appropriate shared object is therefore the actual1,152-dimensional output-projected writes, or the downstream
causal-response subspace that several heads span. A future assay should extract held-out shared modes, express I as
token-by-mode and C as mode-by-mode, compare them with head components at equal price, and require invariance under
the exact internal gauges and head permutation.

## 5. Document count is not the present bottleneck

The384-document,32-arm branch audit took about229 seconds of managed GPU time. Designing, validating, and interpreting
the instrument took much longer. So the user's diagnosis is correct: coding and reasoning are the bottleneck here.
Once an implementation is stable, confirmation should use roughly1,500 documents across additional source chunks and
out-of-distribution text, while keeping fitting, selection, confirmation, and FINAL roles disjoint.

## Literal byte-accounting correction and repair

A storage audit found that the previous43-certificate all-two-byte run physically stored QK factors in fp16 and
rounded native tensors to BF16, but retained the two generated MLP programs in float32. Its honest executed price was
**1,076,606,060 bytes**, not1,023,517,292. The CE and signed causal findings were still valid for that mixed-dtype
object.

We have now physically repaired and rerun it. All ten generated MLP tensors are BF16 on CPU:26,544,384 values occupy
exactly53,088,768 bytes. The complete artifact contains511,758,646 tensor values and occupies exactly
**1,023,517,292 bytes**. It retains43/62 behavioral certificates at **+.012331 nat** census damage. On an untouched
WikiText segment its mean/p95/max damage is **+.008688/.035301/.063097 nat**.

The original-native attention16 knockout gate also passes: signed-effect cosine **.986522**, normalized error
**.191608**, norm ratio **1.086071**, collateral circuit-ranking correlation **.995714**, and owned-effect median
ratio **1.085469**. Thus the literal1.0235GB tier is formally restored as predictive, OOD-checked, and manipulable
for that named intervention. BF16 here is only a storage encoding; computation explicitly dequantizes to float32.

## Outcome of the next physicalization

The first next direction has now run. The sub-500M composite is physically valid at **495,847,230 values and
991,694,460 bytes**, or **0.92359 GiB**. It retains17/62 certificates at +.052983 nat, composes almost exactly as
predicted, and passes the new shifted and fresh checks.

It is nevertheless not adopted. Before running, we required the maximum change in any saved per-position
cross-entropy value relative to the fp32-source parent to be at most0.100 nat. The measured maximum was0.117641,
although the mean change was only0.006527. That single frozen prediction failed. The strong null did not fire and the
artifact remains a useful physical screen, but the registration required every positive prediction before a signed
causal gate. We therefore stop this precision branch without relaxing the threshold and move to the mathematically
different layer17 current-harness screen.
