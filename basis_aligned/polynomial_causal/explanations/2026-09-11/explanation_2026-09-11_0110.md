# Overlapping token functions: results and remaining assumptions

*Started 11 September at 01:10 UTC; updated after the completed fit and CPU audits.*

Keeping the exact vocabulary-common function separate did not expose the proposed
independent blocks in the centered remainder. That native search converged in
34.09 seconds with FP64 verification, but again missed the registered near-null
and spectral-gap criteria. We are now testing a different assumption: tokens
may use sparse, overlapping combinations of learned quadratic functions even
when those functions do not belong to independent input blocks.

The new 512-function dictionary fit **converged locally in 95.65 seconds**, using
all 50,304 output-weight rows and no text or activation data. It captures 16.56%
of centered quadratic coefficient energy, with a median of six functions per
token. Refitting coefficients on exactly the same token/function links raises
capture to 20.72%. The strongest functions remain complicated input quadratics:
sparse usage did not automatically produce simple input computations.

This is a different structural assumption and an informative result, but it
misses the registered 30% capture screen. It is not an identified circuit or
evidence that the broader weights-first search is exhausted.

## Completed fit and negative-result checks

The fixed penalty was $\lambda=0.0927229$. Across 308 alternating cycles, capture
rose from 5.27% to 16.56%, with no outer objective increase. Final relative
stationarity was $8.24\times10^{-5}$ for the codes and $2.90\times10^{-5}$ for
the dictionary, checked against the original FP64 target. These satisfy the
registered local stopping criterion; they do not establish a global optimum.
There are 315,718 nonzero token/function coefficients, averaging 6.28 per token.
[Fit receipt](../../TOKEN_FUNCTION_DICTIONARY_V1_RESULT.json).

The strongest immediate alternative explanation was penalty shrinkage: the
absolute-value penalty pulls retained coefficients toward zero as well as
removing links. Holding every learned function and every token's allowed links
fixed, we solved the unpenalized least-squares coefficient problem exactly.
Capture rose by 4.15 percentage points to 20.72%, with the same 315,718 nonzero
links and median six. The worst solve residual was $2.86\times10^{-15}$ and
the largest support Gram condition number was 45.56; no solve was rank deficient.
Thus shrinkage explains part of the miss, but not all of it. This audit changes
the coefficient objective and does not make the original 30% screen pass.
[Debias audit](../../TOKEN_DICTIONARY_DEBIAS_V1_AUDIT.json).

We then inspected eight functions selected by their separate component energy,
$\sum_v A_{vj}^2\|H_j\|_F^2$. Because functions overlap, these component energies
are not additive explained energy. Each selected function was used by 644–2,617
tokens. Its best single real product captured only 10.6–21.1% of its own coefficient
energy; retaining 90% required 406–470 signed-square eigenmodes. These are dense
functions despite sparse token usage. The recovered norms agree with the exact
coordinate representation within $2.5\times10^{-15}$.
[Input-function spectra and exploratory token lists](../../TOKEN_DICTIONARY_FUNCTIONS_V1_AUDIT.json).

For a symmetric quadratic matrix $H$, a single real product has at most one
positive and one negative eigenvalue. Its exact best coefficient approximation
therefore retains the strongest eigenvalue of each sign:

$$
\mathrm{capture}_{\text{one product}}(H)=
\frac{\max(\lambda_{\max}(H),0)^2+
\min(\lambda_{\min}(H),0)^2}{\|H\|_F^2}.
$$

This calculation tests input simplicity of the returned functions. It does not
test whether a different dictionary with an explicit input-product constraint
would find simpler functions. That joint assumption remains a useful next step.
Token lists are exploratory descriptions, not semantic labels or causal tests.

## What the centered-block test ruled out

The four smallest nontrivial normalized eigenvalues were approximately
0.00005999, 0.00007304, 0.00007449 and 0.00007684. The second is about 4.21% of
the exact mean, above the registered 1% bar; the second/third ratio is about
0.981, above the required 0.10. The exact common function plus centered energy
replays the complete tensor energy within $2.3\times10^{-15}$.

Adding the common function back contributes 14.9–28.4% of the constraint cost
for these selected matrices. Thus the common channel matters, but separating
it does not rescue this particular block screen. This is not a proof against
all approximate partitions or overlapping computations.

## The new hypothesis

For token $v$, approximate its centered quadratic function by

$$
Q_v-\overline Q\approx\sum_{j=1}^{512} A_{vj}H_j.
$$

The functions $H_j$ are learned jointly. Coefficients $A_{vj}$ are signed and
encouraged to be sparse. One token can use several functions, and one function
can serve many overlapping token sets. We do not require orthogonal functions,
disjoint token clusters, or an independent input block for each function.

This differs from the earlier varimax experiment: varimax rotated an already
fixed rank-128 approximation without changing its reconstructed tensor. Here
the dictionary functions change during fitting, and approximation is part of
the objective. It also differs from native-product selection: these functions
are learned combinations, not selected native neurons.

## Exact coordinates for all token quadratic functions

Let $H$ denote the native product features, $G$ their coefficient Gram matrix,
$D$ the native down projection and $U$ the unembedding. Compute

$$
CC^\top=DGD^\top.
$$

Then the quadratic functions in the vector

$$
\Psi=C^{-1}DH
$$

are orthonormal under coefficient Frobenius inner products. Each centered token
function has the exact coordinate row

$$
X_v=(U_v-\overline U)C,
\qquad Q_v-\overline Q=X_v\Psi.
$$

The matrix $X$ has 50,304 rows and 1,152 columns. It preserves all pairwise
quadratic-function inner products; it is not an output-rank truncation. The
dimension is limited by the native residual output width. Dense synthetic
coefficient tensors verify the coordinate identity and dictionary-function
conversion within $5.3\times10^{-16}$.

A dictionary row $B_j$ represents $H_j=B_j\Psi$, so fitting $X\approx AB$ is
exactly a joint quadratic-function fitting problem in these coordinates. We
divide $X$ by one global RMS row norm to set the objective scale and retain
that scale for reconstruction. The common function remains explicit.

## Optimization and its assumptions

The objective is

$$
\frac{1}{2V}\|X-AB\|_F^2+
\frac{\lambda}{V}\sum_{v,j}|A_{vj}|,
\qquad \|B_j\|_2\leq1.
$$

The absolute-value penalty encourages zero coefficients. The atom norm bound
prevents a trivial rescaling that makes coefficients arbitrarily small. Signs
remain unrestricted. This is the standard sparse dictionary objective;
[Mairal and colleagues](https://www.di.ens.fr/~fbach/mairal_icml09.pdf) discuss
its representation and optimization. Our implementation is a batch alternating
solver, not their online algorithm, and does not inherit its convergence theorem.

For fixed functions, accelerated proximal steps solve the sparse coefficient
problem using soft thresholding. For fixed coefficients, projected accelerated
steps update the dictionary subject to the norm bounds. The code restarts
acceleration when necessary and explicitly records nondecreasing-step stops.
These steps use the [accelerated proximal approach](https://www.ceremade.dauphine.fr/~carlier/FISTA).

Conditional convergence is not joint convergence: updating functions can make
the preceding coefficients nonoptimal. The run checks both sets of stationarity
conditions after a complete update. A local-convergence declaration requires
two consecutive checks against the original FP64 target at relative stationarity
at most $10^{-4}$. A 540-second chunk is resumable; its expiry is not convergence.
The nonorthogonal sparse-code control also agrees with an independent constrained
solver to about $10^{-15}$ in objective.
[Controls](../../QUADRATIC_TOKEN_DICTIONARY_V1_CONTROL.json).

The initial dictionary consists of the top 512 spectral directions. The penalty
is then fixed by a deterministic weight-only calibration: the median ninth-largest
initial absolute coefficient across tokens. This starts near eight active
functions per token without using linguistic labels. It does not enforce that
count after learning. The registered quality screen requires at least 30%
centered coefficient-energy capture and median usage at most 16, after convergence.
[Registered protocol](../../TOKEN_FUNCTION_DICTIONARY_V1_PREREGISTRATION.md).

Several limitations remain. A 512-function dictionary still imposes an output-rank
cap; it is not overcomplete in the full 1,152-dimensional span. The penalty changes
the reconstruction tradeoff, and one initialization cannot establish global
optimality or stable factors. Most importantly, each learned quadratic function
may itself be complicated. Sparse token usage alone does not explain its input
computation. Its native product basis or equivalent explicit quadratic coefficients
remain charged until a simpler input implementation is found.

The current run tests overlapping function reuse, not the four circuit properties.
Prediction, extraction, selective removal and composition remain to be established
for any candidate that survives the structural and optimization checks.
