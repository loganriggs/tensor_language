# Frozen weight features: first FineWeb intervention validation

The source features found from attention weights now have a working intervention
formula on natural FineWeb inputs. We froze the features, removed their key/value
reads at one source position, and predicted the resulting attention and next-token
changes. The prediction was accurate. The behavioral effect was tiny, however,
so this establishes a useful local tool, not a newly identified semantic circuit.

Since the [03:10 update](explanation_2026-09-11_0310.md), we completed the full-value
predictor, one small managed GPU validation, an audit against predicting no change,
and a CPU check that source edits compose at the attention output. No features
were fitted or adjusted using text. The GPU run took 1.85 seconds; authoring and
checking the experiment took substantially longer. The 03:22 hourly review flags
that overhead and calls for reusing the existing executor.

## Weights-first remains the discovery route

FineWeb is the model's training corpus. Pile is a separate corpus-shift check;
the generic `bilin18_eval_tokens_large.pt` cache is Pile and was excluded here.
This experiment used 32 historically opened FineWeb sequences, with 128 input
tokens each. These are neither fresh document holdouts nor OOD evidence.

The [methods report](explanation_2026-09-11_0022.md) explains the representations,
optimizers, assumptions and bottlenecks. Subsequent weight-only work includes an
[overlapping token-function dictionary](explanation_2026-09-11_0110.md), a
[converged compact shared reader](explanation_2026-09-11_0226.md), and
[joint QK source spaces](explanation_2026-09-11_0310.md). The broad structural
search remains unfinished. This small validation is not a reason to expand the
million-token fitting campaign.

The main unresolved assumptions remain: a small global factorization may be too
restrictive; coefficient error need not rank natural behavioral importance;
different parameter counts and penalties are not a fair leaderboard; local
convergence is not global optimality; and stable subspaces do not guarantee
uniquely meaningful individual factors. Antipodal symmetry holds for every
homogeneous quadratic, including dense ones, so it does not itself guarantee
a small decomposition. Stronger solvers help with optimization failures but do
not repair a poorly chosen structural family.

## What was removed and predicted

Each of the nine heads in attention layer 17 has a frozen 17-dimensional source
space, represented by orthonormal columns of a matrix $E_h$. The earlier
weight-only calculation selected these spaces from the joint QK1 times QK2
numerator, averaging over positions. Both branches participate in each feature.

At source position 32, let $s$ be the already-normalized input to attention. Each
head's two key maps and current value map instead read

$$
s'_h=s-E_hE_h^\top s.
$$

Queries, other source positions and the first-layer base-value stream stay fixed.
This changes selected internal reads. It does not replace the upstream residual
state or recompute its input RMS normalization. Each edited key's own head RMS
normalization is recomputed.

For a fixed query at position 127, denote the two normalized, rotated QK scores
by $a_{1,h}$ and $a_{2,h}$. The source contribution to the head output is

$$
c_h=(a_{1,h}a_{2,h})v_h,
\qquad
v_h=(1-\lambda)V_hs+\lambda v_{\mathrm{base},h}.
$$

Here $V_h$ is the current-value weight map and the learned mixing coefficient at
this layer is $\lambda=-0.0888671875$. The predictor uses the unedited source,
query/key vectors and small precompiled maps such as $K_{1,h}E_h$, $K_{2,h}E_h$
and $V_hE_h$. It predicts the new scores including their changed normalization,
and the full 128-dimensional value vector. The [normalized-edit explanation](explanation_2026-09-11_0255.md)
gives the scalar score and norm formulas.

Writing the head output projection as $O_h$, the predicted residual change is

$$
\Delta y_{127}=\sum_{h=1}^{9}O_h(c'_h-c_h).
$$

We computed this prediction before running the physical edit. A separate model
run injected the predicted change at attention's output and replayed the native
remaining MLP, final normalization, unembedding and tanh. Thus the next-token
prediction retains the native downstream computation and full model background;
it is not an isolated small language model.

There were six arms: baseline, zero-edit control, physical and predicted edits
for the learned spaces, and physical and predicted edits for fixed random spaces.
Random spaces had the same rank inside each head's joint key-weight span.
Four batches gave 24 model-body forwards and 192 sequence evaluations, with
4,096 distinct input token positions. The zero-edit control matched exactly.

## Results and the weak-effect audit

CE, or cross-entropy, is minus the log probability of the actual next token.
Higher CE is damage. Prediction error compares the forecast with the physical
intervention; it is different from the intervention's effect on the model.

| Quantity | Learned spaces | Fixed random spaces |
|---|---:|---:|
| Mean physical CE change, nats | +0.0000745 | −0.0000576 |
| Mean absolute per-row CE effect, nats | 0.0004716 | 0.0001234 |
| Mean absolute CE prediction error, nats | 0.000000626 | 0.000000709 |
| Relative error in the full logit change, all rows | 0.0384% | 0.2062% |
| Attention change / original attention-output norm | 0.414% | 0.0891% |

All three registered numerical predictions passed. The largest per-batch learned
logit-change error was 0.0461%, below the 1% bar. These are conditional predictions
on natural states, not new semantic or OOD identification.

The absolute CE tolerance was too weak to stand alone: simply predicting no
change also achieves mean error below its 0.001-nat threshold. The saved-output
audit makes that explicit. Our learned-space prediction is nevertheless about
753 times more accurate in CE than that baseline, and the relative logit-change
error is 0.0384%, whereas predicting no change has 100% relative error.

This supports the formula despite the small effect. It does not establish that
the source features select a behavior. The learned projection also removes more
activation energy than the random projection, so their effect-size difference
cannot be read as semantic selectivity. No task-specific contrast was tested.

## Executed next consequence: composition across sources

To check whether the single-position restriction could be relaxed without a new
fit, we implemented and tested summation of the same predictor across sources.
This attention uses a signed product of two QK scores and has no softmax or
normalization across source positions. With query reads fixed,

$$
\Delta y_t=\sum_h O_h\sum_{s\le t}\Delta c_{h,t,s}.
$$

Disjoint source edits therefore add at this interface. A CPU control including
the self-position key/value read, signed base-value mixing and nontrivial edits
matched independent direct execution with relative error $5.71\times10^{-16}$;
disjoint-source composition error was $1.98\times10^{-16}$. The self-position
query role remained fixed. This is a read-edge intervention, not a simultaneous
edit of all roles of that token. Final CE changes need not add because downstream
computation is nonlinear.

The all-source native FineWeb run has not been performed or queued. It is a
bounded possible follow-up using the same frozen spaces and rows, without a
source-position search or refitting. The completed CPU consequence supplies its
arithmetic interface. More weight-only structural families still need attention.
