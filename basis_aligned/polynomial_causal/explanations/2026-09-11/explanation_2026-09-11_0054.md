# Full-weight block search: convergence, result and response audit

The nonorthogonal block search has now run on the entire unembedding folded into
MLP17, without token sampling or input/output-rank truncation. The first run
converged only three of four requested modes. An independent faster run completed
all four and passed the original FP64 verification threshold. The registered
near-zero and spectral-gap tests still failed. This is a narrow negative for
this block-discovery screen, not evidence that useful shared computations are absent.

A follow-up found that the leading algebraic matrix mainly probes a relatively
weak input direction. Its apparent shared response is partly explained by the
already-known vocabulary-common output component. No new circuit has been identified.
All calculations are weight-only; FineWeb and Pile were not used.

## The completed spectrum

The [preceding explanation](explanation_2026-09-11_0035.md) defines the matrices.
For every token's quadratic form$Q_v$, we seek matrices$Z$ approximately satisfying

$$
Q_vZ=Z^\top Q_v.
$$

Additional suitable solutions can expose shared blocks after a nonorthogonal
coordinate change. Identity always satisfies this equation, so it is removed.
The positive-semidefinite normal operator measures the sum of squared residuals
over all 50,304 outputs. We normalize by total coefficient energy. Its exact mean
eigenvalue after removing scalar identity is$2/(1152+1)$.

| Smallest nontrivial mode | Verified eigenvalue | Fraction of exact mean |
|---:|---:|---:|
| 1 | 0.0000579208 | 3.34% |
| 2 | 0.0000728304 | 4.20% |
| 3 | 0.0000739322 | 4.26% |
| 4 | 0.0000806219 | 4.65% |

The registered near-null bar requires the first two to be at most 1% of that mean.
The gap bar requires the second/third eigenvalue ratio to be at most0.10;
it is0.9851. Both fail. Eigenvalues are residual measures, not percentages of
model behavior preserved. These thresholds are choices for a structural screen;
they do not prove that every approximate block partition is unusable.

## The optimization repair worked

The full-FP64 run took479.91seconds and1540matrix-vector products. Its three
returned eigenpairs individually converged with tiny residuals, but the four-mode
request hit its iteration limit. That result remains partial convergence.

The second run used an independent start, a larger Krylov basis and FP32 search
operations. Every returned eigenpair was then checked against the original FP64
operator, retaining the original acceptance bar. All four passed: the largest
residual is$5.65\times10^{-8}$of the operator-norm bound, below$10^{-7}$.
The first three eigenvalues agree with the previous run within$1.6\times10^{-14}$;
the corresponding subspaces have principal cosines above0.99999999967.

Synchronized matrix-vector timing improved from0.292seconds to0.00889seconds,
about32.84×. The second entire run took52.50seconds. End-to-end settings differ,
so that comparison is not a controlled precision-only benchmark. Lower search
precision is an optimization improvement, not interpretability progress by itself.

## Why small algebraic residuals need further interpretation

Suppose a candidate has$Z=W\Lambda W^{-1}$, with distinct scalar labels for
different blocks. Let$\delta$be their minimum separation and$\kappa(W)$the
condition number of the coordinate change. A bound on deleting cross-block terms
and mapping back is

$$
\frac{\sum_v\|Q_v-\widehat Q_v\|_F^2}{\sum_v\|Q_v\|_F^2}
\leq\frac{\kappa(W)^4}{\delta^2}
\frac{\sum_v\|Q_vZ-Z^\top Q_v\|_F^2}{\sum_v\|Q_v\|_F^2}.
$$

Ill-conditioning or small block-label separation can amplify the error. The
derived bound and synthetic controls pass, but the bound can be loose: one noisy
example has actual relative squared error 0.195 and bound 25.14. Actual
original-coordinate error is therefore required for candidate evaluation.
Complex-conjugate invariant blocks require the corresponding Sylvester-map
separation, rather than a simple real label difference.
[Derivation and controls](../../CONGRUENCE_BLOCK_ERROR_TRANSFER_V1_MATH.md).

## What the returned matrices actually emphasize

The first three converged FP64 matrices have95.5–99.6%of their squared singular
value mass in one dyad$uv^\top$. They are far from symmetric projectors. For a
unit-length dyad, the algebraic residual is

$$
\sum_a\|Q_auv^\top-vu^\top Q_a\|_F^2
=2\operatorname{tr}(M_u)-2v^\top M_uv,
\qquad M_u=\sum_a(Q_au)(Q_au)^\top.
$$

Here $a$ indexes tokens, while $u$ and $v$ are input-space vectors.
The residual can be small because responses $Q_au$ are aligned, or because they
are weak overall. We computed$M_u$exactly through the full unembedding to
distinguish those explanations. These responses determine changes in each
quadratic function under an input perturbation:

$$
f_a(x+tu)-f_a(x)=2t(Q_au)^\top x+t^2u^\top Q_au.
$$

The leading direction has response energy only9.45%of the isotropic-direction
mean. Its best single response direction captures63.30%of that response energy.
However,47.82%of its response energy is the vocabulary-common component already
known from the dossier. After separating that component, the best alignment in
the centered response is32.19%. The other two directions have5.74–5.99%of mean
input response energy and centered best alignments14.10–17.34%.

Thus weak input directions and the known common channel contribute substantially
to the small algebraic residuals. The first alignment is not evidence of a newly
identified shared product or semantic circuit. The common component remains part
of the physical pre-tanh computation; this audit does not discard it.

The broader alternative is now explicit: retain the common function as a shared
channel, and seek structure in the centered remainder, rather than require every
quadratic function to respect the same independent blocks. Overlapping subsystems
also remain outside this screen. The response split is an executed first check
of that distinction; a centered native block-spectrum run has not been performed.
[Negative-result scope and executed checks](../../NATIVE_CONGRUENCE_MIXED_V1_AUDIT.json).

None of these numerical tests establishes OOD prediction, independent extraction,
selective removal, or composition. The full goal remains active. The improved
solver makes further weight-only block tests substantially cheaper.
