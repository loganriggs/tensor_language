# Better sparse inference helps; the spherical shortcut fails on FineWeb

Since the previous update, both overcomplete dictionary fits finished, and the
corrected sparse encoder was applied to their initial and learned features.
The resulting learned programs capture **53.60% / 53.61% of the full folded
coefficient tensor**, up from **43.77% / 43.78%** with the old encoder. This is
a substantial improvement from using the same features more effectively.
However, the dictionaries remain unconverged and the two complete functions
remain different. We have improved an approximation, not identified circuits.

A separate small FineWeb check rejected the hoped-for benefit of preserving
the exact radial term. The formula is correct, but the idealized spherical
distribution was a poor guide to natural-input behavior. A cached-state audit
shows why: two mathematically distinct pieces strongly cancel on these inputs.
This supports weight-first discovery followed by frozen validation; it does
not trigger another million-token discovery sweep.

The managed run started at10:20:52 and tests a coupled optimizer on both saved dictionaries.
It changes optimization while retaining the same structural assumption and
corrected encoder. The numerical control passed on two planted small problems;
native convergence and functional gains are still unknown.

## What changed in the factorization

An input reader is one row of the bilinear layer's Left or Right matrix: a
linear feature evaluated before multiplication. The overcomplete dictionary
has 2304 shared features in a 1152-dimensional input space. Each native reader
is represented using at most 128 of those features. Native Left/Right pairing
and the Down output matrix remain in place.

The old encoder first solved Lasso, which penalizes the absolute values of
coefficients, then selected 128 positions and refitted their values. When
Lasso used fewer than 128 features, zero-valued ties filled the remaining slots
arbitrarily. The repair keeps the nonzero support and fills the remaining slots
by orthogonal least squares (OLS): choose the feature giving the largest exact
one-step reduction in squared reconstruction error, conditional on the features
already selected. Finally refit all selected values. This is greedy selection,
not a globally optimal sparse representation.

All four dictionaries receive the same repair. "Initial" means sampled from
the trained model's native readers, not an untrained language model.

| Dictionary | Original full coefficient capture | Corrected capture | Historical test reader capture after correction |
|---|---:|---:|---:|
| Initial, seed 0 | 38.68% | 39.17% | 46.26% |
| Learned, seed 0 | 43.77% | 53.60% | 47.19% |
| Initial, seed 937 | 38.88% | 39.38% | 46.26% |
| Learned, seed 937 | 43.78% | 53.61% | 47.19% |

Full coefficient capture is

$$
1-\frac{\|T-\widehat T\|_F^2}{\|T\|_F^2},
$$

where each token's slice of the folded tensor is

$$
T_v=\sum_k(UD)_{vk}\operatorname{sym}(l_kr_k^\top),
\qquad \operatorname{sym}(A)=\frac{A+A^\top}{2}.
$$

Here U is the unembedding and D is Down. Exact contractions evaluate this norm
without constructing every dense token matrix. This score is neither token
accuracy nor percentage of the language model explained.

Historical test reader capture measures reconstruction of the native weight
rows excluded from dictionary fitting. Both learned dictionaries still miss
the registered two-percentage-point advantage over the stronger initial
dictionary. The split has now been inspected repeatedly, so it is not fresh
validation of the encoder choice. The two final folded functions have cosine
**0.698**, below the registered **0.9** stability bar. Comparing complete
functions removes simple feature permutation/sign ambiguity.

The corrected program keeps 9,142,272 matrix coefficients, 1,179,648 stored
support indices and 1152 bias values. Runtime sparse indices, U and all native
background computation also count. This dictionary is larger than the earlier
1152-feature dictionary; the 53.6% versus 33.2% comparison is not matched capacity.

## Why preserving the radial term did not help as expected

Write the bilinear output, excluding its bias, as a quadratic vector q(x).
Its trace vector m gives an exact decomposition

$$
m=D(L\odot R)\mathbf 1,
\qquad
q(x)=q_0(x)+\frac{\|x\|^2}{d}m,
\qquad d=1152.
$$

The first part q_0 has zero trace in each output coordinate; the second is
radial because it depends only on input length. Under a uniform spherical input
distribution the two parts are orthogonal on average. That does not make them
independent on actual model states.

The frozen check used 64 previously cached FineWeb sequences, 8192 prediction
positions, eight fixed alternatives and ten model body passes, with no fitting.
Physical model replacements agreed with the cached-interface calculation.

| Frozen program | KL before radial correction | KL after correction |
|---|---:|---:|
| Orthogonal dictionary, seed 0 | 0.0805 | 0.1138 |
| Orthogonal dictionary, seed 937 | 0.0777 | 0.1042 |
| Ordinary oblique dictionary, seed 0 | 0.0598 | 0.1383 |

KL is the mean divergence from the native next-token distribution to the
candidate distribution; lower is better. For both orthogonal programs, the
unembedding-weighted MLP squared error decreased while KL worsened. For the
oblique program both worsened. Radial-plus-bias alone also did worse than
bias-only: KL **1.1027 versus 0.7276**. Every registered improvement prediction
failed, while the execution checks passed.

The post-result CPU audit reuses those states and native outputs. With
\(\langle a,b\rangle_U=(Ua)^\top(Ub)\), the exact energy identity is

$$
\mathbb E\|Uq\|^2
=\mathbb E\|Uq_{\rm radial}\|^2
+\mathbb E\|Uq_0\|^2
+2\mathbb E\langle q_{\rm radial},q_0\rangle_U.
$$

Dividing each term by the observed native MLP output energy, the three terms
on the right are **0.211, 1.915, and −1.123**. Their cancellation leaves about
**1.003** for q, which excludes the small native bias. The mean radial and
traceless output vectors have metric cosine **−0.966**. The energy replay agrees
to numerical precision. Thus the spherical orthogonality assumption misses
strong cancellation on these natural inputs. This is an explanation of an
already observed failure, not an independent prediction or a new learned fit.

The lesson is to preserve interacting pieces together when needed, and to test
the resulting function through the actual normalization/readout. The exact
weight identity remains useful; its presumed behavioral benefit failed.

Primary evidence: [FineWeb validation](../../FROZEN_RADIAL_FINEWEB_V1_RESULT.json),
[cached cancellation audit](../../FINEWEB_RADIAL_CANCELLATION_V1_AUDIT.json).
These are in-distribution cached checks, not fresh/OOD circuit evidence.

## The optimizer test now running

The original fits alternated between sparse codes Z and dictionary B under

$$
\min_{Z,B}\ \frac12\|X-ZB\|_F^2+0.05\|Z\|_1,
\qquad \|B_j\|_2\le1.
$$

X contains normalized native weight readers, not text activations. Both fits
ran about 1800 seconds; final joint stationarity was **6.24e-4 / 6.72e-4**, above
the **1e-5** threshold. Accurate conditional solves did not settle the joint fit.

The new method updates dictionary directions and currently active code
magnitudes together using L-BFGS-B, then refreshes all codes so previously
inactive features can enter. It checks convergence against the original full
problem, including inactive-code conditions. The two planted controls reached
joint stationarity below 7e-9, but that is not a native-scale result or global
recovery theorem. [SciPy's L-BFGS-B documentation](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-lbfgsb.html)
also distinguishes objective-change and projected-gradient stopping criteria.

The [native protocol](../../NATIVE_COUPLED_L1_POLISH_V1_PREREGISTRATION.md) allows
600 soft fit seconds per start and compares final functions against the
corrected-encoder parents above. Converged but weak or unstable results would
redirect this route toward a different objective or structural assumption.
Another timeout would leave optimization unresolved. No result here yet
establishes the four desired circuit properties.

## 10:48 update: direct tensor fitting is substantially more effective

Both coupled L1 starts finished without convergence. Their final folded captures
were53.674% and53.643%, gains of only0.071 and0.035percentage points. Complete
function cosine remained0.700. Numerical checks held; all convergence, gain
and stability targets missed. This does not prove the L1 optimum lacks useful
structure, but gives little reason for an identical continuation.

The direct full-tensor step passed all checks and was much more productive:
**53.60% to55.96% / 55.94%**, with about **one second per gradient**. The full
two-start diagnostic took9.46seconds. It changes every shared feature and sparse
coefficient together using the composed polynomial error, including output
cross-cancellations. Native reader reconstruction also improved in these steps;
the small counterexample showing a possible tradeoff is not a claim that the
native objectives always conflict. [Native step receipt](../../FOLDED_SPARSE_DICTIONARY_STEP_V1_RESULT.json).

A sustained fit started at10:47:24. It optimizes the shared dictionary and sparse
codes while solving the output matrix exactly at every evaluation. This is
**variable projection**, reusing our previous conditional output solver rather
than inventing another decomposition. For candidate quadratic functions h_k,
their Gram matrix and native cross matrix are

$$
G_{jk}=\langle h_j,h_k\rangle_F,
\qquad C_{jk}=\langle h_j^{\rm native},h_k\rangle_F.
$$

The optimal output matrix is

$$
W_*=D C G^+,
$$

where G^+ is the pseudoinverse. The unrestricted output solve is global;
searching for the input functions remains nonconvex. The unembedding still
weights that nonlinear search. Eliminating the output variables does not
remove their storage cost, prove global recovery, or identify circuits.

The [registered fit](../../PROJECTED_SPARSE_DICTIONARY_FIT_V1_PREREGISTRATION.md)
allows up to3600softseconds per start, with saved accepted states, full joint
gradient checks and explicit rank/conditioning/cancellation diagnostics. It
starts from the original repaired dictionaries, and charges gains beyond their
already optimal output refits. All native weights enter the objective; no
historical weight split is described as held-out validation. Supports and
native product pairing remain fixed. No text or activation weighting is used.

The first five accepted steps reached63.07% capture, but this is an intermediate
optimization value, not a converged result or a validated behavioral program.
