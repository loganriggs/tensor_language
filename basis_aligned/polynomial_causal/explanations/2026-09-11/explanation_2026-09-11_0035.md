# Native-product selection result and a broader block method

The trained-product selection baseline completed in2.59seconds. It improves on
random selection but does not produce a compact, high-coverage representation.
The next method tests a different structural hypothesis: the entire family of
token quadratic functions may split into independent blocks after a nonorthogonal
coordinate change. Its implicit operator and synthetic recovery controls now pass;
no native block search has run yet. No text data entered either calculation.

## Finding blocks without requiring orthogonal readers

Write the quadratic contribution to token$v$ as$x^\top Q_vx$. A shared block
decomposition seeks one invertible matrix$W$ such that every

$$
W^\top Q_vW=\operatorname{blockdiag}(B_{v1},\ldots,B_{vb}).
$$

In coordinates$x=Wz$, each block can contain many interacting variables and can
contribute to many tokens. Cross-block quadratic terms vanish. This would identify
separate input subsystems in the folded quadratic numerator, without asking for a
few global scalar products. Blocks are disjoint in the new coordinates; the
physical reader directions need not be orthogonal. More general overlapping
subsystems remain a separate hypothesis.

The algebraic approach searches for matrices$Z$ satisfying

$$
Q_vZ=Z^\top Q_v\quad\text{for every }v.
$$

For example, if the decomposition exists, assign different scalar labels to blocks
in a block-scalar diagonal matrix$\Lambda$. Then$Z=W\Lambda W^{-1}$ satisfies
these equations. Its separated invariant subspaces can reveal the blocks.
This is the nonorthogonal joint-block problem studied by
[Cai and Liu](https://arxiv.org/html/1607.00716v2).
The current code implements the underlying linear operator and a controlled
recovery example, not their complete approximate native-data solver.

The earlier repository commutant toy concerns orthogonal blocks of positive
semidefinite consumer forms. It is prior art, but directly using its ordinary
condition$Q_vZ=ZQ_v$ would impose an extra restriction here. The new toy deliberately
uses indefinite forms hidden by a nonorthogonal matrix.

## Computing the operator without a gigantic tensor

Define the squared residual and its normal operator:

$$
\mathcal E(Z)=\sum_v\|Q_vZ-Z^\top Q_v\|_F^2,
$$

$$
\mathcal L(Z)=2\sum_vQ_v(Q_vZ-Z^\top Q_v),
\qquad\langle Z,\mathcal L(Z)\rangle_F=\mathcal E(Z).
$$

This operator is positive semidefinite and self-adjoint, even though$Z$ need not
be symmetric. Identity always solves the equations; discovering blocks requires
additional solutions or well-supported approximate solutions. A native eigen-search
must remove this trivial identity direction and report eigenvector residuals.

Let$H_j=\operatorname{sym}(l_jr_j^\top)$ and$F=UD$, so
$Q_v=\sum_jF_{vj}H_j$. The output Gram is$K=F^\top F$; the full vocabulary enters
through this exact matrix. Define

$$
\mathcal S(X)=\sum_{ij}K_{ij}H_iXH_j,\qquad S=\mathcal S(I).
$$

Then

$$
\mathcal L(Z)=2[SZ-\mathcal S(Z^\top)].
$$

Each sandwich contraction uses the existing$L,R,K$ matrices. It avoids storing
the50304×1152×1152tensor or a1152²×1152²normal matrix. The4608²FP64Gram needs
about170MB; a1152×1152trial matrix needs10.6MB in FP64. Native runtime and
eigensolver convergence are still unmeasured. An approximation in transformed
coordinates will also require condition-number and original-coordinate error
checks before it can justify a physical block split.

## What the controls establish—and the correction they required

The new CPU test plants blocks of sizes2,3,3 behind an invertible mixing matrix
with condition number4. It recovers those sizes, with off-block squared energy
8.2e-29. The implicit action agrees with dense formulas within1.2e-15, including
an independent test of free bilinear products. The ordinary commutator has a
substantial residual, showing why the nonorthogonal formulation matters. A generic
dense symmetric family has only the trivial scalar solution.

An initial control incorrectly required every recovered eigenvalue to be real.
The trace-free indefinite2×2block has a further algebraic symmetry producing a
complex-conjugate pair. Its two-dimensional invariant subspace is nevertheless
real. The correction groups conjugate eigenvalues and recovers their real
polynomial nullspace. There are four algebraic null directions in this example
but only three recovered real blocks: nullity is not automatically block count.
[Control and exact numbers](../../CONGRUENCE_BLOCK_OPERATOR_V1_CONTROL.json),
[implementation](../../congruence_block_operator_v1.py).

This does not reverse the earlier signed-square pencil result: recovering real
rank-one square factors and recovering real multi-dimensional blocks impose
different requirements. Likewise, algebraic separation of quadratic numerators
does not yet separate the model's RMS denominators, residual paths or final tanh.
Prediction, extraction, selective removal and composition remain to be tested
after a native structural candidate is found.
