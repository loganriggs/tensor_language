## How the agents make later agents better

This is a staged bootstrap, not six agents independently running six loosely related probes.

1. An implementation agent receives one bounded scientific question, exact allowed inputs, a maximum computation
   budget, and a list of interpretations that each possible result would license.
2. A different agent receives the frozen specification and tries to reproduce or falsify it without seeing the model
   result. It writes executable adversarial tests, not just prose criticism.
3. I merge only general lessons into shared code and prompts. For example, the current result contract now checks exact
   dataset membership, split separation, finite JSON numbers, declared field types, model-forward counts, zero weight
   updates, and hashes of all authoritative inputs.
4. The next implementation task inherits those tests plus concrete examples of earlier failures. It therefore starts
   at the previous wave's frontier instead of rediscovering bookkeeping errors.
5. Scientific lessons are promoted separately. A successful causal intervention becomes a reusable circuit primitive
   only if it predicts held-out behavior and passes active controls; a better serializer does not count as circuit
   understanding.

The natural scaling unit is therefore a pair: one builder and one independent critic. Once a pair finishes, I can give
the next pair a more precise counterfactual dataset, stronger negative controls, and a smaller set of plausible
computations.

## The computation being repaired in R584

Let $x^+$ be the normalized input to a later MLP when the upstream numeric signal is present, let $x^-$ be the input
when that signal is deleted, and let $\delta=x^+-x^-$. A bilinear MLP has the form

$$
M(x)=D[(Lx)(Rx)],
$$

where $Lx$ and $Rx$ are two learned linear feature vectors, their product is coordinate-wise, and $D$ maps those
products back into the residual stream. The exact output difference is

$$
M(x^+)-M(x^-)
=D[(L\delta)(Rx^-)+(Lx^-)(R\delta)]
 +D[(L\delta)(R\delta)].
$$

The first term measures how the numeric signal combines with all other information already present. The second
measures the signal combining with itself. This is an exact algebraic identity, not a rank approximation. The causal
question is whether one of these interaction paths specifically predicts successor behavior while leaving copy
behavior alone. If neither is selective, the broad signal has not yet been split into useful computations.

## The computation being protected by R586/R587

The earlier R580 run measured 3,024 unique prompts and passed its scientific conditions, but it serialized one metadata
field as a one-element list instead of a string. R581 independently reproduced all scientific numbers but correctly
failed the exact result contract. R586 is a clean prospective repetition with the same rows and thresholds and only
the result-type error repaired. It is already frozen and model-free tests pass. R587 is now being authored independently
before R586 may run.

This may look strict for a metadata error, but it protects the more important next experiment. That experiment replaces
four distributed attention contributions using frozen recipient and donor score/value factors:

$$
e_r u_r,\qquad e_d u_r,\qquad e_r u_d,\qquad e_d u_d.
$$

Here $e$ is the attention score on the relevant equality edge and $u$ is the value vector after the head's output
matrix. Subscripts $r$ and $d$ mean recipient and donor examples. These four conditions are replay, score-only swap,
value-only swap, and joint swap. They must make different predictions on selector-only and payload-only edits. Caching
all factors before any intervention prevents an early score swap from silently changing a later value factor.

## What counts as progress

The agents are not optimizing rank reduction. A promoted circuit must increasingly satisfy these goals:

- state the computation being performed;
- group the same computation when it is distributed across heads or layers, and split a module when it has several jobs;
- predict held-out and meaningfully different examples;
- run as an extracted computation rather than depending on one saved activation trace;
- be removable or interchangeable without damaging unrelated behavior on active controls;
- explain composition and reuse by later computations; and
- remain identifiable under equivalent changes of basis in the network.

review the R584 repair, and then execute the frozen four-condition score/value experiment. Each boundary supplies the
tests and evidence contract for the next two-agent wave.
