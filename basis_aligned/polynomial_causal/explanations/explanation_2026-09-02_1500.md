# Attention1 is the named source shared by MLP0's token and interaction responses — 2026-09-02 15:00 UTC

## Where this fits in the goal

We are trying to replace native attention-head and MLP boundaries with computational pieces defined by what they
read, compute, write, and how downstream modules use them. Such a piece must ultimately predict held-out and shifted
inputs, compose with other pieces, and support selective intervention without disturbing unrelated computation.

The previous update established a reproducible but still opaque rule at MLP1: the real normalized MLP1 input predicts
the downstream effects of MLP0's token-only branch (`T`) and token-by-context interaction branch (`I`) very well, but
does not adequately predict the context-only branch (`C`). Rung491 asked which actual residual-stream source inside
that whole MLP1 input makes the T and I rule work.

## The exact computation

Immediately before MLP1, the unnormalized residual stream is a sum of:

- the token embedding and skip path;
- attention0's write;
- MLP0's fixed remainder and its exact `T`, `C`, `I`, and normalization-correction (`S`) branches; and
- attention1's write.

RMS normalization divides that sum by one scalar length per token. Multiplying every source by that same scalar gives
source contributions to the normalized MLP1 input. A small separately stored numerical remainder retains the exact
effect of BF16 operation order and rounding. The resulting identity is

`z_native = z_embedding + z_attention0 + z_MLP0-other + z_MLP0-T + z_MLP0-C + z_MLP0-I + z_MLP0-S + z_attention1 + z_numerical`.

The measured relative squared error of this sum was `7.18×10^-28`. This is effectively exact bookkeeping, not a
learned approximation.

For MLP0 branch `b`, let `delta_b` be the change it causes in MLP1's normalized input. MLP1 is quadratic, so the part
of its output response that uses the real native state can be written with its bilinear form `B`:

`B(delta_b,z_native) = sum_source B(delta_b,z_source)`.

That second equality is exact up to `2.62×10^-12` relative squared error. It lets us ask whether the branch-induced
change is being multiplied by the embedding path, an attention write, a particular MLP0 branch, or another named
source—without choosing a rank, sparse dictionary, or arbitrary coordinate rotation.

## What was physically tested

For every source and each T/I/C target, the experiment ran two interventions:

1. inject only that source's MLP1 response term; and
2. inject the complete native-state response with that source's term removed.

Layers2–17 were recomputed after every injection. A source counted as necessary only if removing it materially
worsened the per-token causal effect, its singleton effect was nontrivial, and its same-position MLP1 write beat16
controls in which that source state was shifted to another token position. The complete necessary-source set had to
match in two discovery halves before the source-decomposed intervention outcomes on documents500–999 could open.

## Result: attention1 is the unique shared source

All registered checks passed in discovery and both validation quarters. The stable necessary sets were:

- T: `{MLP0-I, attention1}`;
- I: `{attention1}`; and
- C, descriptively: `{embedding, MLP0-T, MLP0-I, attention1}`.

Therefore, attention1 is the unique named source shared by T and I. This does **not** mean attention1 is exclusive to
T and I: C also uses it, but C's complete native-state response was already insufficient and cannot be declared solved
by a component inside that failed parent.

On held-out source-decomposed interventions, leaving attention1 out reduced effect-direction cosine by13.26/13.28
percentage points for T and10.49/10.73 points for I. It increased the best-scale adjusted error by31.14/31.17 points
for T and28.79/29.60 for I.

![Held-out effect of removing attention1's MLP1 response term](assets/attention1_shared_modulator_rung491.svg)

The attention1 singleton effect was large—75–79% of the complete native-state effect's RMS—but it was not sufficient
alone. For T, its effect cosine/error was about`.68/.73`; for I, about`.85/.524`, narrowly missing the registered`.50`
error boundary. The interpretation is therefore “necessary shared modulator,” not “standalone T/I circuit.”

The numerical remainder was only`.34–.42%` of the complete T/I write and was never selected. Thus this result is not
an artifact of BF16 rounding. The tightest real clause was the T same-position write control: it cleared the shifted
control requirement by about`.014` cosine, but did so independently in all four document halves with stable control
values.

## What this establishes—and what it does not

Rung491 establishes, on held-out intervention outcomes, that attention1's actual residual write is necessary for how
MLP1 responds to both T and I. This is a named connection across modules:

`attention1 write → MLP1 input → T/I downstream response`.

It does not yet establish a semantic name for the information attention1 carries, a smaller attention1 subcomponent,
new-corpus OOD generalization, preservation of unrelated circuits, or compression. Attention1 remains a module-level
source boundary; later work can decompose it further only after this boundary survives a real source intervention.

## Current experiment: edit the reader, then compare with removing attention1

Rung492 is now running through the managed GPU service. It makes a narrower intervention than simply deleting
attention1. Let `a` be attention1's contribution to the normalized MLP1 input. In both the real and branch-absent
trajectories it computes MLP1 on `z-a`, while leaving attention1's residual write physically present for later layers.
For a quadratic MLP1, the edited write difference must satisfy

`MLP1(z_native-a)-MLP1(z_absent-a) = original MLP1 difference-B(delta_b,a)`.

The experiment compares the resulting change in complete branch effect with a true attention1 knockout, which also
removes attention1's direct residual path. Sixteen shifted-position edits are controls. It tests T, C, I, and S and
freezes the complete supported branch group rather than assuming the answer is T/I-only.

A pass would show that the identified attention1→MLP1 connection is an executable, position-specific part of the
effect of removing the real source, while causing less native-model change than deleting attention1 entirely. A
failure would keep rung491 as a local MLP1-output attribution and block portable-path or adoption language. Neither
outcome changes rank or claims compression.
