# Dual-command shared-head/module factorial

The physical state result says temporal and is–was commands occupy a stable rank-12 task-typed
direct sum, not one shared subspace. The exact-weight result nevertheless identifies six common
interfaces: L9H1, L11H3, and L15H5 write into both task spaces; L11H3's value map and L15H5's q/q2
maps read both. Weight energy is only a nomination. This experiment asks whether those exact heads
and their complete parent attention modules are exercised by both commands.

For each same-sequence endpoint, let `m_t(x)` and `m_i(x)` be the temporal and is–was answer-minus-
foil logits. Let `x^(t)` toggle only the temporal cell bit and `x^(i)` only the is–was bit. For role
`r`, the native gold change is

`g_r(x) = m_r(x^(r)) - m_r(x)`.

At the query token immediately before role `r`'s answer, a causal swap replaces either all nine
pre-output-projection head slices at a nominated layer or just its named 128-dimensional slice by
the captured value from `x^(r)`. If the patched change is `e`, signed recovery is
`<e,g>/<g,g>`; cosine, direction agreement, and relative residual prevent scale-only success.
Every intervention also measures the other role's margin, which distinguishes shared weight use
from a shared undifferentiated computation.

The three head swaps are run singly and together. Only if the simultaneous effect agrees with the
sum of singleton effects to relative error at most `.25`, in both phases and both roles, may a
greedy combination be used next. Otherwise subsequent subset search must model interactions. The
complete parent-module arms ensure that a failed nominated head can still localize a real module
route rather than falsely closing the entire layer.

The causal outcomes remain sealed unless the prefix-preserved native bank licenses all 32 rows.
