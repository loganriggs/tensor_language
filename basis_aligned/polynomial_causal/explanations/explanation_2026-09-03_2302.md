## What counts as a high-quality circuit

The target is not merely a low-rank approximation with small cross-entropy cost. We want a computation that:

1. has a clear behavioral meaning—what it reads, computes, and writes;
2. can group pieces of different attention heads or MLPs when they implement the same variable, and split a module
   when it implements several variables;
3. predicts held-out and genuinely shifted examples;
4. can be executed or transferred independently;
5. can be removed or edited without damaging unrelated computations;
6. explains reuse and interaction with other circuits; and
7. remains stable across datasets and harmless internal changes of basis.

Rank, parameter count, storage, and reconstruction error can price an explanation after we have one. They do not by
themselves establish any of these properties.

## The behavior we are trying to explain

The verified induction task contains two possible source locations and two possible payload assignments. The model
must use the final query to select the matching source, then copy the payload attached to that source. R586 showed that
the model performs all four selector-by-payload conditions reliably. R587 independently reconstructed the rows,
factorial comparisons, bootstrap samples, split boundary, model-call count, and hashes without calling the model.

So the behavioral target is solid. R585 asks whether four attention sites implement it as a product of two simpler
quantities.

At attention site $h$ and source role $r$, define

$$
e_h^x(r)=p_h^x(q,k(r))\,
\mathbf 1[\text{token before source }r=\text{query token}],
$$

where $p_h^x(q,k(r))$ is the ordinary attention probability from the final query position to source $r$. The indicator
keeps only the registered equality-successor edge. This is the **selection score**: how strongly this prompt selects
that source through the equality relation.

Define

$$
u_h^x(r)=W_h^O v_h^x(k(r))\in\mathbb R^{1152}.
$$

Here $v_h^x(k(r))$ is the source's value vector and $W_h^O$ maps it into the model's 1,152-dimensional residual stream.
This is the **copied content vector**. Their exact local write is

$$
T_h^x=\sum_{r\in\{A,C\}}e_h^x(r)u_h^x(r).
$$

For a recipient prompt $x$ and donor prompt $y$, the causal test replaces the local term by

$$
\begin{aligned}
t_h^{xx}&=\sum_r e_h^x(r)u_h^x(r) &&\text{recipient replay},\\
t_h^{yx}&=\sum_r e_h^y(r)u_h^x(r) &&\text{change selection only},\\
t_h^{xy}&=\sum_r e_h^x(r)u_h^y(r) &&\text{change copied content only},\\
t_h^{yy}&=\sum_r e_h^y(r)u_h^y(r) &&\text{change both}.
\end{aligned}
$$

The intervention runs at L5H5, L7H3, L8H3, and L8H4. All recipient and donor factors are captured before any edit, so
an earlier intervention cannot change a factor that a later intervention claims to hold fixed.

This crossed design gives opposing predictions. A source-selection edit should respond to $t^{yx}$ but not $t^{xy}$.
A payload edit should respond to $t^{xy}$ but not $t^{yx}$. An edit that changes both should need $t^{yy}$. Active
answer-preserving controls test whether the intervention is merely a broad contextual write.

## What the latest review cycle changed

The review is adversarial in a concrete sense: the critic constructs a complete but misleading result package and
checks whether the validator rejects it. Each accepted criticism becomes a test and a reusable rule for later agents.

### Iteration 4: failure reasons had to come from measurements

The previous candidate could correctly declare that the measurement setup was invalid but attach an arbitrary reason.
For example, it could claim a replay failure even when the saved replay measurements were exact. The repair now
reconstructs the complete FIT or SELECT failure list from retained endpoint rows, factor arrays, intervention arrays,
and structural checks. The list is sorted into one canonical order and must match the result exactly.

Some checks use large intermediate tensors that are not saved. Their failure cannot be independently reconstructed
from the final package. These now stop the run before it can publish a result:

- reconstructing the complete native attention output;
- comparing replay and native full-vocabulary logits;
- capturing every required factor;
- reconstructing the live factor at the intervened state;
- verifying that the hook applied the requested residual-stream update; and
- encountering a nonfinite number.

This distinction is important. A **scientific null** says the measured causal effect failed a frozen hypothesis and
must retain all evidence. An **implementation-integrity failure** says the measurement itself cannot be trusted and
must not produce a scientific result.

### Iteration 5: preserve both local and end-to-end structural checks

Some counterfactual arms are algebraically required to be identical. For example, if a payload did not change, the
payload-only arm should equal replay. The frozen preregistration required the final output-logit vectors to agree:

$$
\max_{v\in V}|\ell^{(a)}_v-\ell^{(b)}_v|\le10^{-5}.
$$

Iteration 4 replaced this with equality of the four inserted 1,152-vectors because the latter can be reconstructed from
saved $e$ and $u$. The independent critic caught that this was a silent weakening: equal intended local tensors do not
by themselves test that batching, hooks, and the downstream forward pass actually applied them identically.

The current repair therefore does both:

1. compare the complete final-logit vectors during execution and stop before publication if they differ; and
2. save the local inserted-tensor equality and reconstruct it independently during audit.

The exact set of intervention logits needed for these checks is now generated from the frozen structural-identity
manifest instead of a hand-written list of families. This makes the mechanism reusable when a later circuit adds a new
counterfactual family.

## What the two-agent bootstrap has accomplished

The builder–critic loop has produced reusable rules rather than merely delaying execution:

- semantic tokens and positions must equal frozen counterfactual authority;
- direction rows must name the exact recipient and donor;
- inserted tensors must reconstruct from saved selection and content factors;
- every saved margin, cross-entropy, vocabulary change, and causal statistic must recompute from lower-level values;
- positive results and scientific nulls need complete phase-specific evidence;
- invalid-measurement reasons must also be derived from evidence;
- unretained implementation checks must stop publication;
- an auditable local check supplements rather than replaces a registered end-to-end check; and
- interrupted publication must be recoverable without overwriting complete or unrelated files.

These rules are now in the shared playbook, so the pending-opener and numbered-list agents will start from a stronger
interface than R585 did.
