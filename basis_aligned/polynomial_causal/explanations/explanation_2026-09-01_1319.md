## Goal

We are compiling the 546M-parameter bilin18 transformer into a smaller, understandable tensor program that is
still predictive on new text, composes when several parts are replaced, preserves the direction of named causal
interventions, and is cheaper under a literal count of every stored number.  A small reconstruction by itself is
not enough; it must survive those physical tests.

## What just passed

The clean layer-16 result from the preceding update has a mathematical factorization using **14,984 numbers**.
The implementation scored so far retained 5,314,176 numbers; the physical factor implementation is the next
gate. Its computation is four scalar quadratic functions of the layer input. Each quadratic function is a
signed sum of two squared input projections, so the variable part uses eight squared projections in total.  The
four resulting scalars select four 1,152-dimensional output directions, and one constant 1,152-dimensional vector
is added.  That constant is included in the price.

The new test asked whether this tiny program preserves what happens when attention layer 16 is replaced by its
fixed average output.  We measured the loss change at every one of 256,000 token positions in both the untouched
model and the model containing the quadratic replacement.  The comparison was signed: a helpful change and a
harmful change do not count as equivalent merely because they have the same magnitude.

## What this means—and what it does not

This is much stronger than saying that four output directions correlate with ordinary layer-16 activations. The
quadratic function preserves the direction and scale of a named upstream intervention as that intervention
passes through the rest of the model.  It has therefore reached causal identification for this test.

It is **not yet adopted**.  On ordinary text by itself, replacing the whole native MLP16 adds `0.03898` cross-
entropy and preserves only `27/62` circuit behavior checks.  The current smallest adopted program adds only
`0.01233` and preserves `43/62`.  The signed pass shows that the small layer-16 representation is meaningful; it
does not erase its prediction cost.
