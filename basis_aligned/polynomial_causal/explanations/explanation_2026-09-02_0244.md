# Equality-term subset result — 2026-09-02 02:44 UTC

## Short version

The preregistered natural-text experiment has now run. It tested every subset of four exact equality/copy terms from
L5H5, L7H3, L8H3, and L8H4 under both removal and extraction. The instrument passed exactly: native replay error was
zero, all 33 configurations ran with the intended layer dispatch, no code documents or held-out attention0 outcomes
were opened, and the run finished in 41.95 seconds.

The result does not justify grouping L8H3 and L8H4 as one circuit. Their interaction point estimate suggests
redundancy, but its preregistered simultaneous uncertainty interval crosses zero. A broader result is reliable: the
early pair L5H5+L7H3 and the layer-8 pair L8H3+L8H4 provide strongly overlapping downstream benefit. Repeat context
also changes the size of the equality service, especially whether there is one previous match or several.

This points below native head terms. The next experiment should ask which downstream attention/MLP computations treat
pieces of these writes as the same variable, and which residual pieces are context-specific. It should not open the
code subset outcomes yet, and it should not replace this question with rank reduction.

## Exact computation and data

At query position `q`, each term selects source positions `k` satisfying

`token[q] = token[k-1]`.

It then routes the head's value from `k`, weighted by that head's two continuous attention scores. The four terms use
the same discrete token-equality relation but have different score functions, value features, output maps, and layer
positions.

For each of the 16 subsets, the experiment ran:

- **removal:** subtract those equality terms from the otherwise native selected heads; and
- **extraction:** delete all four selected head writes and restore only those equality terms.

The run used 192 frozen natural-text documents. It did not train a decomposition or choose examples from model
outcomes. The task conditions were frozen from token IDs: all equality/copy positives, matched negatives, near/far
repeats, one/multiple previous matches, off-target positions, and all scored positions.

## The combined equality service is large and selective here

Restoring all four equality terms after deleting the four heads recovered:

| Condition | Recovered CE effect |
|---|---:|
| matched copy/induction positives | `+.49184 nat` |
| all positive equality/copy positions | `+.50334 nat` |
| matched negatives | `-.02405 nat` |
| off-target positions | `+.00438 nat` |

Positive recovery means lower CE than leaving the four heads deleted. On this natural-text role, the equality terms
restore about half a nat on the intended positions and almost nothing over the large off-target set. The negative
matched-negative value means restoring the terms slightly worsens those deliberately matched positions.

Removal gives the same qualitative result from the other direction: removing all four adds `+.46856 nat` on the
matched positives and only `+.00346 nat` off target. This reproduces the already-known all-four endpoints and confirms
that the new subset wrapper is operating on the intended computation.

## Each term is useful alone, but their effects overlap

On all positive positions, extraction of one term at a time recovered:

| Term | Recovery | Percentage of all-four recovery |
|---|---:|---:|
| L5H5 | `+.23290 nat` | `46.3%` |
| L7H3 | `+.21613 nat` | `42.9%` |
| L8H3 | `+.30772 nat` | `61.1%` |
| L8H4 | `+.17944 nat` | `35.6%` |

Those percentages sum to about 186%, not 100%. Therefore the four terms do not contribute independent slices of the
final improvement. Later computation can obtain overlapping benefit from several of them.

A Shapley allocation—splitting every measured interaction equally among its participating terms—assigns
`+.12844`, `+.10774`, `+.16968`, and `+.09748 nat` to L5H5, L7H3, L8H3, and L8H4. The ordering is identical in the two
96-document halves (Spearman correlation approximately 1). This is stable importance accounting, not proof that the
heads are the correct semantic units.

## L8H3 and L8H4 are suggestively redundant, but unresolved

For L8H3 and L8H4, define the interaction as

`recovery(both) - recovery(L8H3) - recovery(L8H4)`.

The point estimate is `-.10774 nat`. Both document halves are negative (`-.09122` and `-.12394 nat`). But the
preregistered simultaneous 95% interval is `[-.25600, +.04052] nat`, which crosses zero. Under the frozen rule this is
**additive or unresolved**, not a confirmed redundant group.

The interval is deliberately conservative: it controls one uncertainty band over every reported subset interaction
and task condition. The consistent negative halves are useful evidence for the next design, but they do not license
opening code outcomes or claiming interchangeability.

## The early and layer-8 blocks have robust overlapping benefit

Let the early block be L5H5+L7H3 and the layer-8 block be L8H3+L8H4. Their interaction is

`recovery(all four) - recovery(early block) - recovery(layer-8 block)`.

The result is `-.22418 nat`, with corrected simultaneous 95% interval `[-.37244, -.07591] nat`. The two document
halves are `-.18688` and `-.26076 nat`, both negative. Thus later computation obtains substantially overlapping
benefit from the two depth blocks.

This does not mean the two blocks literally compute the same vector or are freely interchangeable. It rules out a
simple independent-stage account of their CE benefits. Possible explanations include:

- they are alternative providers of a shared copy variable;
- later readers saturate once either provider supplies enough of the variable;
- the nonlinear CE objective compresses two different useful writes into overlapping loss improvement; or
- each block mixes a shared part with a private part.

Downstream response and patch tests are needed to distinguish these explanations.

## Context changes the strength, but has not yet split semantic roles

All-four extraction recovery is:

| Context | Recovery |
|---|---:|
| nearest earlier match at most 16 tokens away | `+.37146 nat` |
| nearest earlier match more than 16 tokens away | `+.54343 nat` |
| exactly one previous occurrence | `+.69821 nat` |
| at least two previous occurrences | `+.34839 nat` |

The one-versus-multiple difference is stable in both halves, and every singleton term is stronger with one previous
match. The L8H3/L8H4 pair is more redundant with one prior match than with multiple prior matches. Near versus far
also changes the pair interaction stably, although the ordering of the four singleton changes is not stable across
halves.

This is real context dependence under the registered rule, but it is not yet a clean head specialization. All four
terms mostly move in the same direction, and normalizing by the overall effect size makes the near/far and
one/multiple pair differences much smaller. A plausible interpretation is that the same redundant service matters
more on some examples, not that separate heads implement named “near,” “far,” “single-match,” and “multi-match”
circuits. The next experiment should discriminate these hypotheses directly.

## Analysis correction preserved

The first result file computed the early-versus-layer8 interval with a pointwise bootstrap threshold even though the
preregistration required the same simultaneous threshold used for all interactions. The numerical outcomes and point
estimate were correct, but that interval was too narrow.

The original result is preserved. A CPU-only correction re-read the saved per-document sufficient statistics, loaded
no model and no new rows, and recomputed the joint maximum-deviation interval. The corrected interval is wider:
`[-.37244, -.07591]` rather than `[-.27570, -.17266]`. It still excludes zero, so the registered cross-block conclusion
does not change. The correction receipt identifies the invalid original field and hashes both parent artifacts.

## Next direction already started

The next object is a downstream-reader-defined decomposition of the four equality writes.

For each term and context, measure how every later attention and MLP write changes. Treat the resulting response as a
candidate interface, not as a semantic label. Then ask:

1. Is there a shared downstream response used by both the early and layer-8 blocks?
2. Are the remaining response directions specific to one-match versus multi-match contexts?
3. Which later attention or MLP component causes the shared response to matter? Patch its induced write into a
   removal run and test whether it repairs the expected CE effect.
4. If a later MLP is selected, split its bilinear products by these causal responses rather than by native channel or
   low rank.

This can turn the robust block redundancy into a computational statement such as “these cross-head pieces supply the
same variable to this reader,” or falsify that statement and force a finer Q/K-versus-value decomposition. Rank can be
used only as a matched-capacity control for the response model; it is not the discovery target.

The durable research goal remains active. The previous pause produced a concrete safeguard in the research-driver
skill, and this turn continued through preregistration, implementation, managed execution, correction, interpretation,
and the next circuit-level design rather than stopping at the explanation.
