# Explanation update — 2026-09-04 14:38 UTC

## 1. High-level goal

We are trying to describe the model as a collection of understandable computations, not merely compress its weights or find
directions with high activation energy. A successful circuit description should tell us:

- what information is read;
- what operation is performed;
- what information is written;
- which later computation uses it;
- whether the same computation is shared across heads, MLPs, or tasks;
- whether the description predicts held-out and shifted examples; and
- whether we can extract, swap, or remove it without damaging unrelated computations.

Rank reduction alone does not establish any of these. The current fast screen instead asks a direct causal question: if a donor
prompt has the other value of a meaningful variable, does replacing one internal state of the recipient make the recipient behave
like the donor, while appropriate controls remain unchanged?

## 3. The first candidate

The candidate tested whether one internal state carries the choice between a period and a question mark across two different
sentence constructions.

- **A1:** a reporting frame changes from statement to question, for example `The pilot states: that is a remarkably bright
  lantern` versus `The pilot asks: is that a remarkably bright lantern`.
- **A2:** a different construction changes from statement to question, for example `The pilot describes that object as a
  remarkably bright lantern` versus `Does the pilot describe that object as a remarkably bright lantern`.
- **P:** the reporter word changes while the sentence type and correct punctuation remain the same. A genuine sentence-mode state
  should not change under this edit.
- **C:** an unrelated instruction asks the model to copy an earlier visible period or question mark. This uses the same two output
  tokens. It was intended to detect a generic punctuation-output direction that is not specific to sentence mode.

There were 32 linked groups and 128 rows. Both target edits were balanced in both directions. Every prompt ended with the same long
suffix within its group, had no trailing space or quote, and was checked so that appending `.` or `?` adds exactly one standalone
GPT-2 token.

## 4. Exact computation

For a prompt whose registered answer is token (a) and whose foil is token (b), native capability uses the logit margin

$$
m = \operatorname{logit}(a)-\operatorname{logit}(b).
$$

The model is correct on that row when (m>0). Capability is not pooled across all examples. It is checked separately for each
construction, answer direction, and recipient/donor side. A1, A2, and P require at least 85% accuracy in every cell; C requires at
least 75%.

Had capability passed, the runner would have replaced the donor's internal vector into the recipient at one final input position.
For an answer-changing pair, all scores are put on the donor-answer axis. If the recipient margin favors the recipient answer,
its donor-oriented score is (-m_{\text{recipient}}). The donor score is (m_{\text{donor}}). After intervention, the recipient
still reports logits in recipient-answer order, so its donor-oriented score is (-m_{\text{patched}}). Recovery is

$$
R=
\frac{-m_{\text{patched}}-(-m_{\text{recipient}})}
     {m_{\text{donor}}-(-m_{\text{recipient}})}.
$$


Thus (R=0) means the replacement did nothing, and (R=1) means it moved the paired answer score all the way from the native
recipient value to the native donor value. The denominator must be genuinely positive; weak, zero, or sign-reversed donor behavior
is invalid evidence rather than something repaired with a numerical epsilon.

For P, where the correct answer does not change, the score is the absolute movement caused by replacement divided by the median
native target shift:

$$
E_P=
\frac{|m_{\text{patched}}-m_{\text{recipient}}|}
     {\operatorname{median}(m_{\text{donor,target}}+m_{\text{recipient,target}})}.
$$

The fixed screen thresholds require both A1 and A2 to have mean recovery at least 0.50 and the correct sign on at least 80% of
rows. P must move by at most 0.20 target units. C is an unrelated answer-changing behavior, so its mean absolute recovery must be
at most 0.35. High C transfer counts against selectivity.

The planned site search contains:

- 19 residual-stream states: the embedding state and the state after each of 18 blocks;
- 36 whole-module outputs: attention and MLP output at each layer; and
- only if the best passing whole module is attention, the 9 pre-output-projection head contributions inside that one layer.

This is 228 forward calls for the first stage and at most 264 with head expansion. Right-padding variable-length prompts reduced the
maximum from an unnecessary 593 length-specific calls to 264 while leaving the evaluated examples unchanged.

## 5. What actually happened

The native capability table was:

| family/cell | recipient accuracy | donor accuracy | result |
|---|---:|---:|---|
| A1, statement → question | 100% | 100% | pass |
| A1, question → statement | 100% | 100% | pass |
| A2, statement → question | 100% | 100% | pass |
| A2, question → statement | 100% | 100% | pass |
| P, reporter rewrite in statement | 100% | 100% | pass |
| P, reporter rewrite in question | 100% | 100% | pass |
| C, visible period → question mark | 100% | 0% | fail |
| C, visible question mark → period | 0% | 100% | fail |

The model did not follow the explicit punctuation-copy instruction. It predicted the grammatically natural end of the sentence.
The failure is symmetric: whichever side asked for the grammatically natural punctuation passed and the other side failed.

Therefore the terminal result is `native_behavior_incapable`. The runner stopped after 8 native calls, 256 example evaluations,
2,048 bytes of answer/foil numbers, and 1.990 seconds. It ran no residual, module, or head intervention.

This does **not** show that a construction-general sentence-mode state is absent. It shows that C was not a valid behavioral
control for this model. Without native C capability, low or high patched C transfer would have no clear meaning.

## 6. Prior results and what would count as new

The prior-art receipt explicitly binds the old question-circuit results:

- §1282 found an attention-layer-10 question-state carrier;
- §§1284-1289 localized the earlier behavior to head 10.5 and upstream writers;
- §1313 found head 10.5 much stronger for `?` than for `.` or `!`;
- §1345 showed that 10.5 also serves comparative refinement, narrowing the phrase “question-specific”;
- §§1597-1600 traced a rank-2 MLP11 question slice and `?` output channel to heads 9.7 and 10.5 plus MLP9 and MLP10; and
- §1631 showed that simply selecting head 10.5 is not question-specific, because random rank-2 bases also select that head,
  although the question slice has unusually high concentration there.

Accordingly, finding attention layer 10 or head 10.5 again would be replication, not discovery. The intended new result would have
been a bidirectionally transferable state shared across two syntactic constructions and selective against an endpoint-matched
unrelated behavior. That question remains open because the control failed before intervention.

## 7. Engineering lesson and current plan

The first valid terminal arrived about 42 minutes after the ten-minute operating plan began. Most of that was one-time shared
infrastructure; the scientific run itself took two seconds. There was one avoidable failed execution: the computation finished,
but the strict result writer initially rejected tuple containers. A recursive strict-JSON conversion and regression test were added,
then the managed retry succeeded. No partial result or duplicate ledger entry was created.

The current bottleneck is now counterfactual and control design, not GPU time. Two independent circuit-only workers are preparing:

1. a pronoun-antecedent state candidate; and
2. a pending-quote or quote-parity state candidate.

Each must first search the old results and dossier, state whether it is new, a replication, an extension, or a contradiction test,
and build meaningful A1/A2/P/C examples. An uncertain control template should receive a small developmental capability probe on
examples that will never enter the frozen scientific set. This prevents another full dataset from being built around a behavior
the model does not perform, without using development outcomes to tune scientific thresholds.

If one of the next screens passes, the follow-up is not a rank sweep. It is to find the smallest rotated state or interaction that
still supports held-out interchange, trace how earlier head/MLP outputs write it and later weights read it, and test extraction plus
selective removal. That is the bridge from a fast causal location to the compositional, weight-level circuit description we want.
