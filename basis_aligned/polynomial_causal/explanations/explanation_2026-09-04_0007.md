## What counts as a high-quality circuit here

The goal is a smaller transparent program for the model, not merely a low-rank approximation. A claimed circuit should
eventually tell us:

1. what information it reads, what computation it performs, and what it writes;
2. whether parts of different heads or MLPs implement the same variable, and whether one head or MLP should be split;
3. what it predicts on held-out and out-of-distribution examples;
4. whether the proposed computation is sufficient to reproduce the target effect;
5. whether removing or changing it selectively changes the intended behavior;
6. whether the same subcomputation is reused in another behavior; and
7. whether its identity is stable across data splits, fitting restarts, and equivalent changes of basis.

Storage, compute, rank, and reconstruction error remain useful prices or controls. They do not establish any of these
claims by themselves.

## The deep reference computation

For one induction head, the proposed equality-copy contribution is

$$
B(E,U)=e_Au_A+e_Cu_C.
$$

$e_A$ and $e_C$ are the attention weights on two registered matching-source roles. $u_A,u_C\in\mathbb{R}^{1152}$
are those sources' value vectors after the head's output matrix. Thus $E$ describes which source is selected and $U$
describes the content written from that source.

For recipient prompt $x$ and donor prompt $y$, the experiment compares:

$$
\begin{aligned}
B(E_x,U_x)& &&\text{recipient replay},\\
B(E_y,U_x)& &&\text{change selection only},\\
B(E_x,U_y)& &&\text{change copied content only},\\
B(E_y,U_y)& &&\text{change both}.
\end{aligned}
$$

This is a decomposition below the native head boundary. It asks whether selection and copied content are reusable
variables across L5H5, L7H3, L8H3, and L8H4.

## What the first cross-review caught

The induction diagnostic, R591, was designed to determine why a self-replay and the untouched model differed by more
than the frozen maximum-logit tolerance of $10^{-5}$. Its first exact candidate was blocked for four reasons:

1. The code could label padding or batch membership as the cause using the observer or replay conditions. The frozen
   definition allows only untouched-model comparisons to assign those two causes.
2. The dry-run receipt saved the count and hash of its 256 selected examples but not the actual ordered example IDs.
3. The managed wrapper hashed a producer file and later reopened that mutable path for execution. A file replacement
   between those operations could execute bytes that were never reviewed.
4. The advertised outcome-blind dry run called an R585 authority function that transitively parsed earlier R586/R587
   result artifacts. No result was leaked into a model score, but a dry run that promises not to read outcomes must not
   read them anywhere in its call graph.

The repair now in progress makes the classification use the registered untouched-model comparisons, emits all selected
IDs, constructs its panel from the outcome-blind row manifest, and executes an immutable snapshot of the reviewed
producer bytes.

## What the second cross-review caught

The numbered-list replication, R590, passed the critic's attacks on its scientific logic and evidence package. In
particular, its reports and decision are derived from saved row-level values; numerical reconstruction failures stop
execution; phase-specific row support is exact; and result, receipt, and evidence files are published together.

It was still blocked at the managed execution boundary. The wrapper checked the main producer and then imported it,
but that producer imports several executable dependencies at module load time. Those dependencies were checked only
after some of their code could already have run. The repair now pre-verifies the complete executable dependency set
before the first import and removes the checked-path/reopened-path race.

This distinction matters because provenance is not just a list of hashes saved after execution. The executed code must
be exactly the code those hashes identify.

## A cleaner intervention derived on the parent track

The current replay subtracts two implementations of the same mathematical term. One first projects each value and then
sums; the other first sums 128-dimensional head values and then applies the output matrix. These are equal in real
arithmetic but need not be bitwise equal in floating point. A small difference can be amplified by later layers.

If R591 identifies that contraction difference as the cause, the prospective replacement is a centered change using
one fixed expression:

$$
\begin{aligned}
\delta_{\mathrm{replay}}&=B(E_x,U_x)-B(E_x,U_x)=0,\\
\delta_{\mathrm{selection}}&=B(E_y,U_x)-B(E_x,U_x),\\
\delta_{\mathrm{content}}&=B(E_x,U_y)-B(E_x,U_x),\\
\delta_{\mathrm{joint}}&=B(E_y,U_y)-B(E_x,U_x).
\end{aligned}
$$

Self-replay is then literally the zero tensor. The joint change also separates as

$$
\delta_{\mathrm{joint}}
=\delta_{\mathrm{selection}}+\delta_{\mathrm{content}}
+\sum_r(e_{y,r}-e_{x,r})(u_{y,r}-u_{x,r}),
$$

where the last term is the part requiring both the donor selection and donor content. This gives later circuit agents
a general recipe for splitting a bilinear computation into two single-factor changes and their interaction.

This is a conditional derivation, not a modification of the frozen R591 experiment. R591 must first measure which
source of disagreement is actually active.
