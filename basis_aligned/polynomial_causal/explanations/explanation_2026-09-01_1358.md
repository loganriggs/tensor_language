# Plain-English update — 2026-09-01 13:58 UTC

## Goal

The full project goal is to replace the 546-million-number bilin18 transformer with a smaller tensor program that
still predicts new text, composes when several pieces are installed together, preserves named causal effects, and
has parts we can explain and edit. For MLP0 specifically, the goal is stronger than compression: separate what it
writes about the current token, what it computes from token and context together, and what it computes from context
alone, then determine which distinctions downstream computation actually uses.

## The exact token-only experiment

We evaluated all 50,257 real tokens at sequence length one. At length one, attention0 can attend only to the token
itself, so the complete input and output of MLP0 are exact deterministic functions of token identity—there is no
sampled surrounding context.

For each token we ran two paths:

1. the native path;
2. a counterfactual path that removed only MLP0's bias-free output.

Both paths retained the identical raw token vector, attention0 value, MLP0 bias, and learned block1 mixing
coefficients. We defined MLP0's downstream causal effect as the difference between the paths in attention1's output
and MLP1's output. Thus two tokens count as similar only if MLP0 makes downstream computation react similarly—not
merely because their MLP0 vectors point in similar directions.

The sparse program used 256 possible coordinates and exactly 16 active coordinates per token. It was trained on
four fifths of token IDs and scored on the untouched fifth. Controls included a code trained only to reconstruct
MLP0, a response-shuffled code, ordinary dense low-rank maps, and a linear map from the raw token vector.

## What we learned

The first surprise is scale. Block1's learned coefficients are `0.012695` for the incoming block0 state and `8.0`
for the raw normalized token vector—a coefficient ratio of about 630. But MLP0's output is correspondingly huge.
After applying those coefficients, the isolated MLP0 term has **2.26 times the median norm** of the explicit raw-token
term. Their median absolute cosine is only **0.215**, so MLP0 is not just placing another copy of the embedding in the
same direction. It writes a large, mostly different token-dependent signal.

The second result is that “downstream” is not one homogeneous consumer:

| exact token-only object | dimensions needed for 90% of squared variation | participation rank |
|---|---:|---:|
| MLP0 write | 601 | 74.5 |
| attention1 causal response | **156** | **17.4** |
| MLP1 causal response | **734** | **121.8** |
| attention1 and MLP1 joined | 841 | 54.4 |

Participation rank is a smooth effective-dimension measure: it is small when variation is concentrated in a few
directions and large when many directions matter. Attention1 sees a compact shared effect, while MLP1 preserves a
much broader set of token-specific distinctions.

The single sparse code therefore failed its registered claim. On held-out tokens it predicted only **33.1%** of the
joined downstream response. The activation-only code reached 32.0%, the response-shuffled code 28.9%, and an
ordinary dense 256-dimensional map reached 35.4%. The joint code was extremely reproducible across two seeds, so
the miss is not an unstable optimizer. Sparse coding is close to the dense ceiling at that width; the obstruction is
that the combined downstream response itself is broad.

We also found no held-out pairs satisfying the deliberately strong condition “response cosine at least 0.8 while
MLP0-write cosine at most 0.5.” That prevents us from claiming that this one dictionary has found tokens with the
same overall downstream effect despite different storage locations.

## Interpretation

The simple picture

`raw token copy + small shared MLP0 correction`

is wrong. A better current picture is:

`raw token path + large nonlinear MLP0 token transform`,

where attention1 reads a compact shared slice but MLP1 retains many more token-specific distinctions. There may be
useful groups for a particular consumer, but there is no evidence for one small token partition or one 16-active
sparse code that is sufficient for both consumers.

This is compatible with “numbers share a feature” and “different numbers remain distinguishable.” The shared
feature may be part of attention1's compact response, while MLP1 continues to use private coordinates. It is not yet
evidence that any particular sparse atom means “number”: individual semantic names require stable token membership
and a held-out causal edit.

## Next direction

The registered rule forbids tuning the failed sparse code or immediately promoting it into live token-by-context
tests. The next independent test instead asks whether MLP0's large token-only write is a transformed representation
of token identity:

- fit a held-out linear/orthogonal map between the raw token vectors and MLP0 writes;
- measure whether the MLP0 write can recover the exact token among all 50,257 candidates;
- separate that recoverable token-identity component from the residual;
- measure attention1 and MLP1 responses to the identity component and residual separately.

If token identity is recoverable and accounts for the broad MLP1 response, that private part is interpretable even
if it is not compressible: MLP0 rewrites the token into the coordinate system MLP1 wants. If the residual instead
carries the causal effect, the next target is that residual—not another generic clustering pass. Only after this
token-only question is settled will we return to the exact token×context and context×context branches.
