# Circuit research update — 2026-09-04 07:18 UTC

## Outcome first

Task 21 completed and failed its native-capability gate for a specific reason: the model continued a three-token
repetition perfectly, but was unreliable when the newest token appeared twice after one older conflicting token.  The
run and an independent audit are valid.  We therefore closed task 21 without localizing a circuit, opening later data,
or weakening the task.

The next strict task is subject–verb agreement.  This is a better circuit target because the controlling subject is not
the final token, archived examples indicate the model is capable, and there are old layer-1/layer-11 hypotheses that a
new authority can test rather than rediscover.  A CPU-only generator and semantic validator are now being built after
a dossier-first audit.

## 1. What task 21 computed

Task 21 tested local verbatim repetition.  The answer was always the immediately previous token.  Every underlying
token group had four matched prompt changes:

- A1 replaced all three occurrences in the trailing repeated run, so the answer changed;
- A2 kept one old target visible, then placed the new target twice at the end, so the answer changed;
- P changed an unrelated leading word while keeping the answer fixed; and
- C added one more copy of the same target while keeping the answer fixed.

For each prompt, the saved margin was

$$
m=\ell(\text{registered answer})-
\max_{f\in\text{registered prompt-word foils}}\ell(f).
$$

A row counted as correct only when $m>0$.  This is a restricted forced-choice test, not full-vocabulary top-1
accuracy.  The model had to reach at least 90% on all base prompts and all donor prompts, at least 85% in each
side-by-transformation cell, and positive mean margins on both sides.

The reviewed managed adapter made exactly four base batches and four donor batches.  Each batch contained 21 prompts
of eight tokens, so the run made

$$
8\text{ forwards},\qquad 168\text{ row-side evaluations}.
$$

It retained two `float32` arrays per batch—the answer logit and maximum-foil logit—so the raw numeric evidence was

$$
8\times2\times21\times4=1{,}344\text{ bytes}.
$$

There were no backward passes, weight changes, hidden-state captures, component labels, or localization outputs.

## 2. The exact result

![Task 21 native capability by linked transformation](assets/task21_capability_gate.svg)

All 84 base rows passed.  Donor accuracy was 74/84 = 88.10%, two successes short of the 90% overall gate.  The detailed
result was:

| Cell | Correct | Accuracy | Mean margin |
|---|---:|---:|---:|
| base A1 | 21/21 | 100% | +3.236 |
| base A2 | 21/21 | 100% | +3.236 |
| base P | 21/21 | 100% | +3.157 |
| base C | 21/21 | 100% | +3.236 |
| donor A1 | 21/21 | 100% | +3.100 |
| donor A2 | 12/21 | 57.14% | +0.685 |
| donor P | 20/21 | 95.24% | +2.835 |
| donor C | 21/21 | 100% | +6.229 |

The overall base and donor mean margins were both strongly positive: +3.216 and +3.212 logits.  If we had kept only
average margin, the behavior would have looked robust.  The linked cell gate exposed the actual problem: nine of the
21 donor A2 prompts chose some registered foil over the answer.

A1 and A2 have exactly the same answer token and exactly the same three foil token IDs within every group.  In A1, the
new target appears three times at the end and all 21 rows pass.  In A2, the first of those three positions is changed
back to the old target, leaving `old, new, new`; nine rows fail and mean margin falls by 2.415 logits relative to the
matched A1 rows.  The difference is therefore the intended older-conflict/latest-run manipulation, not an easy-token
imbalance or a different foil set.

The evidence stores only the maximum foil score, not which foil produced it.  We cannot claim that the old target was
the wrong answer actually selected; one of the filler words may have been the maximum on some rows.  Identifying that
would require evidence that was not registered for this capability run, so we leave it unknown.

The one donor-P miss had margin -0.037, nearly a tie, and is not needed for the decision.  Donor A2 alone misses the
cell gate by six rows.

## 3. Why this is a valid negative rather than a broken experiment

The independent audit checked the whole execution chain:

- the queue executed the exact adapter SHA approved beforehand;
- all 19 frozen code, authority, review, model, and authorization roles matched;
- the result and receipt cryptographically bind all 24 evidence files;
- every saved call matches the frozen call manifest;
- all 168 row IDs, sides, transformations, answers, and foil sets reconstruct exactly;
- the raw byte and forward-call prices are exact; and
- only FIT appears in the closure—SELECT, TEST, and out-of-distribution phases were never opened.

The result file correctly contains `hard_abort` and nulls for every possible circuit projection.  “Projection” here
means the summary fields that a passing run could expose; keeping them null prevents a failed task from accidentally
selecting a layer or circuit.  The detailed arithmetic above was reconstructed afterward for audit and does not turn

## 4. What happens to the predictive-state idea

The 06:30 proposal defined a state by the complete set of future responses and interventions it predicts.  For task 21,
that would have meant saving relative logits for all 21 candidates, then finding a residual subspace whose interchange
reproduced that response.  An ideal local copier would have 21 answer-identity states and a 20-dimensional
mean-centered logit representation.

That experiment is now closed for task 21 because native capability failed.  We will not use richer evidence to find a
subpopulation on which the task passes.  The method itself transfers to the next task that clears capability:

$$
u\sim v\quad\Longleftrightarrow\quad
F(u,t)=F(v,t)\text{ for every registered future test }t.
$$

This remains the proposed answer to “what counts as the same feature?”: not the same attention head, raw direction, or
rank, but the same consequences for declared downstream computations.  Interchange, necessity, sufficiency, and exact
bilinear weight expansion are then needed to connect that high-level state to physical model weights.

## 5. Why subject–verb agreement is next

The next behavior asks whether the model selects singular ` is` or plural ` are` from the grammatical subject while
ignoring a nearer noun with the wrong number.  For example, schematically:

```text
The key near the cabinets ...  ->  is
The keys near the cabinet ...  ->  are
```

This is nonlocal: the last noun can disagree with the subject, so copying or classifying only the immediately previous
token cannot solve it reliably.

The dossier audit recovered three pieces of old evidence:

1. An 80-row algorithm-verification screen reported 100% overall accuracy and 100% on 40 incongruent examples, with
   mean `is`/`are` margin +3.769.
2. Earlier state swaps suggested that a grammatical-number feature is formed near layer 1, survives through the middle
   stack, and is used near layer 11.  L11H3 contributed but was redundant and was not sufficient by itself.
3. A later natural-text test found that removing the proposed `{L11H3, L15H5}` pair changed `is/are` accuracy by only
   0.0052, refuting that pair as the complete agreement circuit.

These results are useful hypotheses, not proof under the current standard.  The old 80-row screen did not provide the
new linked A1/A2/P/C transformations, four isolated phases, selective causal tests, or complete package receipts.  The
new generator will reuse its vocabulary and lessons while independently balancing subject number, attractor number,
answer token, noun identity, and template position.

The intended controls are being resolved before freeze:

- A1 and A2 change subject number in two different syntactic constructions, so the answer changes;
- one answer-preserving control changes the attractor while keeping the subject and answer fixed;
- another uses an unequivocally plural coordinated subject while changing irrelevant surface material; and
- the out-of-distribution phase lengthens or fronts the construction to test fixed-position shortcuts.

There is an active design choice between changing only the attractor's lexical identity and flipping the attractor's
number.  The first cleanly tests surface-word invariance; the second is a stronger grammatical distractor test.  We
will either register both as distinct controls or justify one prospectively—never swap them after seeing model results.

## 6. Parallel diagnostic work remains separate

The numeric-roundness line found that a direction in attention 8 moves the step-versus-plus-one logits, but editing the
carrier alone changes relatively few final decisions; downstream MLPs are needed.  Later audits found saturated
whole-component removal metrics and weak copy controls in parts of that battery.  A calibrated rerun still found no
behavior reaching its 0.25 writer-selectivity bar, so the negative broadly survived, but several intermediate claims
were narrowed or withdrawn.  Five reported GPU-price lines were also corrected because they had been copied from
budgets rather than measured receipts; a new audit now compares ledger prices with receipts automatically.

This is valuable diagnostic learning, especially the importance of capable controls and nonsaturated interventions.
It is not strict four-phase circuit evidence and does not alter task 21's result or the agreement authority now being
built.

The current live boundary is therefore clear: task 21 is durably closed, the subject–verb agreement generator is under
CPU semantic testing, and no new model run or agreement localization is authorized yet.
