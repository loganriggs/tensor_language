# Plain-English MLP0 token-only closure — 2026-09-01 14:41 UTC

## What we now know

The token-only part of MLP0 has a controlled causal decomposition:

`token-only write = shared operating point M + linear token control L + quadratic token correction Q`.

- `M` is one constant vector and supplies most of block 1's normal operating point.
- `L` compactly identifies the token and carries mild shareable structure. Rank 64 retrieves 97.6% of held-out token
  identities, but physical token grouping is mostly no better than simply choosing nearby `L` vectors.
- `Q` is an additional correctly paired correction. It removes 47.9% of the joined error left after `M`, versus
  4.3% for a wrong-token control, but it is predominantly private to each token.

The last open token-only question was whether `Q` could still be compressed through directions tailored to its two
immediate readers.

## Consumer-aware spectrum test

Using fitting tokens only, we built four fixed Q-action bases:

- directions most related to attention1's conditional Q effect;
- directions most related to MLP1's conditional Q effect;
- directions related to the two effects jointly, with the consumers balanced;
- the same joint calculation after shuffling token/effect pairings.

Held-out Q vectors were encoded and decoded in those bases at ranks 16, 64, 256, and 512, then physically inserted
after exact `M+L`. Ordinary Q-PCA was the equal-rank control. No held-out response labels entered any basis.

## Result

The consumers genuinely have different spectra, but the response-aware bases do not improve compression.

At rank 64:

- the attention-trained basis beats the MLP-trained basis on attention1 by **0.106 R²**;
- the MLP-trained basis beats the attention-trained basis on MLP1 by **0.069 R²**.

The cross-covariance spectrum explains why. Attention1 has one exceptional Q direction: its leading strength is 273,
then drops to 33, 30, 23, and 20. MLP1 is much flatter: 17.5, 14.3, 12.8, 10.4, and 7.7. In ordinary words,
attention1 reads a conspicuous narrow signal from Q, while MLP1 reads many weaker directions.

However, ordinary PCA is better at every tested rank:

| rank | stored Q-table values | joint response-aware R² | ordinary PCA R² | PCA cosine |
|---:|---:|---:|---:|---:|
| 16 | 823,696 | 0.189 | **0.207** | 0.458 |
| 64 | 3,291,328 | 0.375 | **0.398** | 0.639 |
| 256 | 13,161,856 | 0.665 | **0.698** | 0.840 |
| 512 | 26,322,560 | 0.827 | **0.865** | 0.931 |

The exact source Q table contains 57,896,064 values. Rank-512 PCA therefore uses about 45% as many values, but still
misses enough causal effect that it was not licensed as a replacement. The registered compact-basis predicates fail,
and the strong null fires because no response-aware basis beats PCA by even 0.02 R². No rank confirmation follows.

## Interpretation

This closes the present token-only compression search without forcing a success:

- attention1 reads a narrow, identifiable part of Q;
- MLP1 reads a broad Q spectrum;
- rotating the action basis toward either measured reader does not beat plain high-variance directions;
- exact token-specific Q remains necessary under the frozen standards.

So the reason MLP0 is not redundant with later raw-token access is now concrete. It supplies an operating point, a
prepared token-control signal, and a broad nonlinear correction that MLP1 consumes across many directions. Later
layers having the raw token does not give them these prepared signals for free.

## Next branch: context

We will stop token-only rank and grouping searches. The repository already contains an exact algebraic split on real
contexts:

`TT = token×token`, `X = token×context + context×token`, and `CC = context×context`.

All three were previously shown to matter, with large pairwise downstream interactions. The next work should start
from that dossier rather than repeat it: connect the newly understood token-only `M/L/Q` roles to the existing `TT`
branch, then isolate interpretable structure in `X` and `CC` under crossed token/context controls. No token-only result
is automatically promoted into live context.
