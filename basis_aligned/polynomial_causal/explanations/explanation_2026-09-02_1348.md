# The second claim — and the first to survive held-out validation (13:19–13:48)
*Written at 13:48 UTC, at the chapter boundary.*

## What was claimed, in plain terms
MLP0 — the network's first big computation — sends three kinds of signal
downstream: a current-token signal (T), a context signal (C), and a
token-times-context interaction signal (I). The question for three rungs
has been whether any later computation treats two of these as "the same
kind of thing." Today's answer, validated on documents the experiment
never touched during discovery: **at the next MLP, T and I are read by
the same continuous mechanism.** Their incoming changes are different,
but the live state that multiplies those changes can be SWAPPED between
them and the downstream causal effects are preserved (agreement .95–.97,
in both directions, in both held-out quarters, with position-shuffled
controls far behind at ~.35).

## Why this one counts
- It is causal (physical interventions, not curve-fitting), held-out
  (documents 500:1000 opened only after the discovery result froze), and
  a POINT prediction (the experiment predicted exactly one edge — T–I —
  and that C would join neither pair; both came true, and even the
  near-misses are informative: T and I happily accept shared context,
  while C's own live state is not interchangeable — fitting, since C IS
  the context branch).
- It took instrument honesty to get here: the first attempt failed its
  own precision bars (set too tight for bfloat16 arithmetic), was
  preserved as a failure, and the repair derived its new bars from the
  arithmetic's unit roundoff rather than from the measurements — then
  validation measured the SAME error independently, vindicating the
  derivation.
- Together with the morning's guarded projector claim, the compiled
  program now has TWO behavioral contracts: a one-dimensional equality
  channel whose code-register composition is frame-stable, and a shared
  MLP1 live-state factor for token and interaction signals.

## Interpretation guard added before adoption

The registered result is fully valid, but “T and I are read by the same continuous mechanism” is stronger than the
current evidence permits. The graph labels a pair only when both swap directions pass. Looking within each fixed
target shows that C is also a strong midpoint donor: for T, C's midpoint is slightly better than I's; for I, C's
midpoint is almost as good as T's. The pairs involving C disappear because the reverse *C-target* direction misses,
not because C's state is a poor donor for T and I.

There is a precise mathematical reason this might be generic. Every branch midpoint is

`midpoint_b = native MLP1 input - branch change_b / 2`.

Thus every swapped midpoint contains the same large native state. The position-shift controls correctly show that the
state must come from the same token position, but they do not distinguish a T/I-specific state from this shared
native-state term.

The correct present claim is therefore: **the pre-registered bidirectional T--I midpoint-interchange graph predicts
held-out effects at `.95–.97` agreement.** Whether that graph identifies a specifically shared T/I reader remains
under test. Rung489 now physically separates the native-state term from branch-specific curvature, compares T/I
donors against both C and native-state controls within each target, and only licenses extraction if the specific
T/I explanation survives. This guard was identified and recorded before rung488 finished; it is not a response to a
bad held-out result.

## Rung489 result: the stronger interpretation failed

Rung489 answered the guard with a strong null. T/I-specific midpoint donors failed: for both T and I, the common
native-state term predicted the target better than the registered cross-branch midpoint. One common reader for all
three branches also failed because C missed the effect criteria in both halves.

The branch-level numbers are still structured:

- T native-state prediction: `.972/.970` cosine and `.234/.242` adjusted error;
- I: `.981/.982` and `.194/.191`;
- C: `.871/.870` and `.492/.493`.

Thus T and I pass the native-state response test strongly while C does not. But the exact finite response cannot be
treated as a simple linear contribution. Curvature-only effects and their nonlinear downstream interactions are
large and cancelling: for T, each is about 2.7 times the RMS of the complete effect; for I they are about 0.9 times;
for C about 0.7 times.

The corrected conclusion is:

> Rung488's held-out graph is a valid threshold-defined observation, but it is not a T/I-specific circuit. Rung489
> falsifies that semantic interpretation. It leaves a narrower T/I-versus-C response split and proves that finite
> curvature and downstream interaction must remain explicit.

Rung490 has frozen that narrower branch signature and is testing it on the previously unopened native-state and
curvature interventions for documents500–999. A pass will allow T and I to share only the native-state response term
inside a branch-resolved model; every branch will retain its separate finite correction. A failure will keep all
three branch readers separate. Neither outcome licenses a rank or compression claim.
