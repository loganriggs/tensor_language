# The morning the instruments examined themselves (08:00–10:30)
*Written at 10:30 UTC, while the big attention rung still runs.*

## What happened, in one paragraph
A new experiment failed its own strictest self-check in a way that should
have been impossible — and instead of shrugging, the failure was chased
through five layers of diagnosis down to a genuinely new fact about the
system we measure with: **the model's forward pass, re-run in a different
process, gives answers that differ by far more than anyone's tolerance
assumed — and the size of that difference follows a clean mathematical
law.** Nothing about the science of the last days is damaged; every verdict
compared quantities inside one process. But the discovery changes how every
future measurement must be designed, and it was made honestly: by receipts,
forensics on git history, and pre-registered hypothesis tests — not by
hand-waving.

## The chase, step by step
1. A "projector-form" intervention experiment failed its bridge check by
   .1–.2 nats against values recorded three hours earlier — while every
   internal check (replay, closure, a doubled-input invariance) was exact.
2. A 4-second diagnostic isolated the broken link: fresh recomputation
   no longer matches the morning's stored values — the experiment's own
   logic was fine (its two intervention forms agree to two millionths).
3. A replication probe ran the ORIGINAL experiment's own code, unmodified,
   on its own first batch: it no longer reproduces its own stored output
   (.084 nat off). Same code, same data, same weights.
4. Git-history forensics: fourteen consecutive health-check receipts
   spanning the whole window are BIT-IDENTICAL — so the machine did not
   globally change; the drift is specific to this measurement pathway. A
   repo-wide diff shows nothing it reads changed. Two hypotheses survive,
   with opposite predictions, and deciding experiments are queued.
5. The law: the drift's size grows exponentially with how many layers sit
   between the intervention and the readout — 1.218× per layer, fitting
   all three measured points to within 4 parts in 10,000. Extrapolated to
   depth zero it predicts .0143 — almost exactly the old, empirically
   chosen "wobble tolerance" of .015. The old tolerance was right, but
   only for shallow measurements; deep ones need exponentially more room,
   or (better) must be designed to compare only within one process.

## Why this matters for the project
- **Trust is preserved, precisely:** every published verdict compared
  quantities within one run or against cryptographically frozen data —
  those stand exactly as before.
- **Design changes:** new experiments now carry their baselines IN-RUN
  (two are already queued/registered this way, including the big MLP0
  factorial), and a provisional depth-dependent tolerance table
  (ops/NOISE_FLOOR_SCHEDULE.md) replaces the single magic number.
- **A possible cure is queued:** pinning the GPU library's workspace is
  predicted to restore bit-exact reproducibility across processes; the
  test runs right after the current big rung finishes.
- **A monitoring tripwire now exists:** the half-hourly health check now
  fingerprints a fixed forward pass bit-for-bit, so any future drift gets
  time-located within thirty minutes instead of surfacing as a mystery.

## Meanwhile
The big attention rung (480) has been running healthily for two hours; the
equality-circuit arc closed earlier this morning with the finding that the
three cooperating MLPs share behavior but not representation. The next
chapter — whichever way 480 lands — starts from cleaner instruments than
the program has ever had.
