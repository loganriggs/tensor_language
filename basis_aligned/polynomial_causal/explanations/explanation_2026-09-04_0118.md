# Direct answer: faster circuit experiments and DAS-to-weights status — 2026-09-04 01:18 UTC

## Short answer

Yes, we can save a lot of time by sharing the parts of circuit experiments that should be mechanically identical. A
fresh audit estimates that roughly 3,000–3,600 lines across the recent circuit pipeline repeat experiment bookkeeping.
In R590 alone, about 1,000–1,150 of the 1,699 producer-and-adapter lines are generic rather than specific to numbered
lists. We are now building the first narrow shared implementation and have asked Claude to independently attack its API
and add adversarial tests.

The honest answer on distributed alignment search (DAS) is:

- we **have** trained rotated activation subspaces using causal interchange objectives on the real model;
- we **have** proved and tested an exact way to turn a product-space DAS projector into quadratic weight formulas;
- we **have not** yet found a real learned DAS subspace that passes the circuit controls and then installed that same
  learned object as a successful weight-level circuit.

Those are three distinct milestones. The algebraic bridge exists and passes planted tests. The real-model circuit
identification step has failed selectivity so far, which means claiming “DAS folded into weights” for a real circuit
would currently be an overstatement.

## What we can reuse safely

The reusable layer should handle experiment integrity, not decide the scientific meaning of a circuit. These parts
should be shared:

1. exact row identities, semantic groups, and FIT/SELECT/FINAL_TEST/OOD separation;
2. deterministic model-call manifests, batches, tensor widths, and forward prices;
3. primitive evidence shapes, hashes, and joins back to the correct examples and intervention arms;
4. invalid-result precedence and the distinction between a diagnostic failure and a scientific null;
5. recomputing every summary and final decision from primitive evidence;
6. atomic evidence/result/receipt publication and recovery after a crash; and
7. capturing and hashing executable dependencies before importing or running them.

The circuit-specific code should still define:

- what the proposed variable means;
- how each counterfactual changes it;
- the exact attention, MLP, or residual-stream intervention;
- what unrelated behaviors must remain unchanged; and
- the metric, sign, denominator, threshold, and opposing predictions for that circuit.

This split matters. A generic framework can prevent a SELECT leak or a malformed evidence package. It cannot determine
whether “pending opener,” “copy selector,” or “successor use” is the right causal variable.

We already have several useful pieces:

- `result_contract.py` checks strict JSON types, row membership, split closure, and execution envelopes;
- the observed-model facade provides one checked boundary to bilin18;
- R590 contains strong atomic publication and immutable-dispatch machinery; and
- `derive.py` generates closely related below-block probes and has reduced those builds to a few minutes.

`derive.py` is appropriate when one diagnostic probe differs from its parent in a small code region. It is not enough
for circuit experiments because textual substitution does not establish counterfactual meaning, evidence joins, or
causal controls.

## The shared framework now being built

The first slice is deliberately small. A declarative `CircuitExperimentSpec` describes artifacts, authority fields,
phases, call families, retained arrays, validity predicates, terminal order, and publication paths. The compiled output
is data—a complete ordered call/evidence contract—not a generated scientific algorithm.

A circuit retains three ordinary reviewed functions:

1. build and validate its semantic authority;
2. turn primitive evidence into its scientific measurements; and
3. turn those measurements into its preregistered terminal and next action.

Acceptance is shadow parity rather than “the new tests pass.” Before any live experiment adopts the framework, it must
reproduce:

- the exact R578/R585 row, endpoint, direction, cell, and bootstrap identities;
- R590's exact 510-call possible manifest, including its 379-call FIT-only null path; and
- synthetic R592 failures after each of its four intervention arms, including three simultaneously nonfinite arrays.

Historical experiment bytes and results will not be rewritten. The framework must pass on two different circuit
shapes before becoming the default. We will abandon or shrink it if it grows beyond 1,200 production lines before
shadow parity, requires circuit-specific escape hatches, weakens immutable execution, hides primitive evidence, or
fails to reduce per-circuit code and review time materially.

The measured target is roughly 650–1,000 fewer production lines and 300–440 fewer experiment-specific test lines for a
complex circuit, with 50%–70% fewer review cycles spent on generic infrastructure. It will not save the time needed to
invent valid counterfactuals or interpret a scientific failure.

Claude has been explicitly assigned the independent side of this work through `AGENT_BOARD.md`: red-team the proposed
API and contribute tests for counterfactual-role confusion, inactive controls, split leakage, padding drift, partial
arms, several nonfinite arrays, mutable transitive imports, successful producer returns, and diagnostic/scientific
namespace confusion. Codex owns integration; neither side approves its own implementation.

## What DAS means here

DAS learns a rotated activation subspace whose interchange produces a specified high-level counterfactual. For a
recipient activation $x$, donor activation $x'$, and an orthonormal basis $U$, the usual intervention is

$$
x_{\mathrm{intervened}}=x+UU^\top(x'-x).
$$

The projector $P=UU^\top$ replaces only the component of $x$ inside the learned subspace. The learning objective should
reward the correct causal effect on answer-changing examples and penalize effects on answer-preserving controls. A low
rank or a good in-sample fit is not sufficient.

### Real DAS experiments we ran

R540 trained ranks 1, 2, 4, 8, and 16 at the residual stream entering block 8 for pending-opener counterfactuals. It
used 45 fits and 10,800 gradient-bearing suffix evaluations. Even rank one moved every requested closer comparison,
but almost all answer-preserving controls moved too. The learned rank-one direction also aligned strongly with a direct
closer-token readout. It learned how to steer the answer, not an isolated pending-opener state.

R556 repeated the idea at the stronger layer-13 head-8 site and explicitly penalized full-vocabulary changes on surface,
distance, and punctuation controls. Ranks 2–16 still moved all targets, but every fit failed at least one control. Its
recorded terminal is therefore no selected rank and no opening of FINAL_TEST or OOD.

So we did actual real-model DAS-like causal optimization. It produced a useful negative result: these linear subspaces
do not yet isolate the desired semantic variable under the current sites and counterfactuals.

## The exact tensor bridge from DAS to weights

For a bilin18 MLP, let

$$
g(x)=(W_Lx)\odot(W_Rx)\in\mathbb R^{4608},
\qquad
M(x)=W_Dg(x)+b.
$$

Instead of learning a subspace in the 1,152-dimensional residual stream, we can learn a projector
$P=UU^\top$ directly in the 4,608-dimensional product activation $g(x)$. The selected output is

$$
M_P(x)=W_DUU^\top g(x).
$$

For each learned column $u_\ell$ of $U$, define

$$
Q_\ell=\frac12\left[
W_L^\top\operatorname{diag}(u_\ell)W_R+
W_R^\top\operatorname{diag}(u_\ell)W_L
\right],
\qquad
d_\ell=W_Du_\ell.
$$

Then the projected computation is exactly

$$
M_P(x)=\sum_{\ell=1}^{k}d_\ell\,x^\top Q_\ell x.
$$

This is the desired tensor property: a learned product-space direction becomes one explicit quadratic function of the
MLP input and one explicit residual-stream output vector. Donor-to-recipient interchange also compiles exactly:

$$
W_DP[g(x')-g(x)]
=\sum_\ell d_\ell\left({x'}^\top Q_\ell x'-x^\top Q_\ell x\right).
$$

R536 tested this with a planted projector. Gradient descent recovered the planted subspace with essentially perfect
projector overlap; held-out relative error was $4.64\times10^{-16}$, and direct versus compiled output and interchange
agreed within the registered $10^{-10}$ tolerance. Rotating the columns inside the same learned subspace did not change
the compiled function.

That was a toy algebra-and-recovery test. The real-model stage was not completed because the available circuit labels
were not portable to fresh documents and an earlier MLP0 effect table had only 0.106 cross-half stability and localized
0/32 held-out circuits. Optimizing a 4,608-dimensional projector against that unstable target would have generated a
precise-looking but unidentifiable answer.

## Related weight translations are not the missing DAS result

Two later experiments establish nearby pieces:

- R573/R576 translated an exact layer-8 attention source contribution from cached layer-0 values into a weight formula.
  The translation was numerically exact, but removal damaged copying as well as list succession. It is a broad numeric
  carrier, not a selective circuit.
- R582/R590 decomposed a later bilinear MLP's response into the carrier combined with background, the carrier combined
  with itself, and their sum. The decomposition is exact algebra. The new independently audited R590 run found no
  selective term: the strongest MLP8 term passed 10/12 target cells and 9/12 successor-versus-copy action gaps, but
  preserved copy in 0/12. SELECT correctly remained closed after 379 FIT-only forwards.

R592 is also not DAS. It is a hand-specified four-site interchange of attention coefficients and projected copied
content. Its purpose is to test whether the selector and content factors have the distinct causal effects predicted by
the induction counterfactuals. If it holds, DAS or a block-term tensor decomposition could then search for the shared
cross-head coordinates that implement those operational factors.

## What the full DAS-to-weights success would require

The next valid end-to-end claim has to complete this chain:

1. define several independently constructed counterfactuals for one semantic variable;
2. show the full candidate site can transfer them while active unrelated controls survive;
3. learn a product-space or residual-space projector on FIT only;
4. predict held-out constructions and SELECT effects without refitting;
5. show selective interchange and removal, including interactions and redundancy;
6. compile the same projector into quadratic weight terms;
7. verify compiled and activation interventions agree through the full model; and
8. test composition, untouched OOD, and literal program cost.

For a residual-space projector, the downstream bilinear MLP can also be split exactly. Writing
$x=Px+(I-P)x$, its output contains subspace-by-subspace, subspace-by-rest, rest-by-subspace, and rest-by-rest products.
That tells us exactly which quadratic weight terms use the learned state. But a donor interchange still supplies
$Px'$ externally. A genuine standalone replacement must additionally explain how the model computes that semantic
state upstream; algebra alone cannot turn an externally supplied counterfactual into an autonomous circuit.

The current strategy is therefore not “try more ranks.” It is to make R592's selector/content causal test valid, then
use downstream behavior to define the shared cross-head basis, and only then learn and compile a minimal quadratic
program for that identified computation.
