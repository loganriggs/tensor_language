# Explanation update — 2026-09-03 13:10 UTC

## Goal and current question

We want circuit units defined by computation and downstream use, even when they cut across native attention heads.
They should predict on new and out-of-distribution inputs, compose, and allow selective interventions without changing
unrelated behavior. Compression or low rank alone is not the target.

The immediate question was whether either of the two score factors from equality-related head `L8H3` could replace
either score-factor slot of `L8H4`. Rung 532 suggested yes on the 62-circuit census. Rung 533 added the two missing
key-permutation controls and tested separate natural-text and code corpora.

## What was computed

Write the two `L8H3` score factors as `(a,b)` and the `L8H4` factors as `(c,d)`. The target score contribution uses
the elementwise product `c*d`. For each of the four mappings `a→c`, `b→c`, `a→d`, and `b→d`, we replaced one target
factor while retaining its other native factor and the target head's native value/output path.

Each mapping had a matched control that used the same factor and scale but reversed the valid earlier-token keys at
every query position. This preserves magnitude while breaking which earlier token is paired with the query. The run
measured the target contribution's change in cross-entropy loss on copy-positive tokens, matched copy-negative
tokens, and all remaining tokens. It used 192 natural documents and 192 repository-disjoint code documents, split in
half and run both with the source head's equality contribution present and removed: eight contexts total.

## Registered result: identification invalid, not a scientific null

The physical instrument passed exactly, but the complete-product positive control met every registered bar in only
4/8 contexts. The preregistration says that a failed positive control invalidates the factor-family identification
test. Therefore we cannot call the four factors a globally interchangeable circuit, nor can we reject that idea.

The failure has a clear form. On code with the source equality term removed, the complete source product reproduced
the target's useful copy effect extremely well in both halves:

- copy-effect cosine: 99.0% and 99.1%;
- relative error: 21.8% and 17.4%;
- aggregate copy-effect recovery: 87.5% and 87.0%.

But it changed matched copy-negative loss relative to the native target by 0.0249 and 0.0233 nat, above the frozen
0.01-nat limit. In plain terms: the source and target heads compute nearly the same useful copy signal, but they do
not reject false or misleading matches in the same way on code.

All four factor mappings beat their own key-permuted controls in 8/8 contexts. Their copy-effect behavior passed in
7/8 or 8/8 contexts, but their full pass rates fell to 5/8 or 6/8 once matched-negative specificity was required.
Those are informative descriptive results, not a retroactive lowering of the registered standard.

The donor-present versus donor-absent effect vectors were also stable in only 2/16 comparisons. This means the
factor's causal effect depends strongly on whether the redundant source-head contribution is still in the model—an
interaction ordinary one-component attribution would mix into that component's apparent importance.

## Better decomposition: shared copy signal plus private filtering

The result suggests a basis more useful than the two native score branches. Let

```text
P_s = complete L8H3 equality-score product
P_t = complete L8H4 equality-score product
gamma = the previously fitted scalar mapping P_s toward P_t

shared signal S = gamma * P_s
private correction R = P_t - S
therefore P_t = S + R exactly.
```

Complete score products are unchanged by reciprocal rescaling of their two factors, so this split avoids the factor
branch gauge that complicated the earlier interpretation. The scalar `gamma` was frozen before rung 533. A CPU test
verified exact recomposition to below `4e-16` on an independent synthetic tensor.

This gives a concrete hypothesis matching the data: `S` is the cross-head shared copy/equality signal, while `R`
implements `L8H4`'s target-specific context or false-match correction. Rung 534 will physically install `R` alone and
compare its effect with the observed marginal effect of adding `R` to `S`:

```text
standalone private effect = CE_absent - CE_R
marginal effect after S   = CE_S - CE_native.
```

If those vectors match on unseen private-arm outcomes, `R` is an autonomous circuit component. If they do not, it is
only meaningful as an interaction with the shared signal. Key-reversed and sign-flipped residuals prevent a generic
norm or damage direction from passing. This differs from the old rung-464 result, which exchanged 19 later-layer
correction writes; here we are splitting the layer-8 score product itself before the value/output computation.
