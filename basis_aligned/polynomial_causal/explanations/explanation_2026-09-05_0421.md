# Explanation update — 2026-09-05 04:21 UTC

## 1. Current goal

The immediate goal is to build one reusable system that can produce hundreds of well-supported circuit records. A basic screen should
take about ten serial minutes from choosing a non-duplicated question to recording either a candidate circuit or an honest null.
Compression, activation reconstruction, variance preservation, and rank reduction are not circuit discoveries and are not the current
work.

A useful circuit record should eventually state what information is represented, which computation uses it, how it affects the task,
whether it predicts held-out examples, and whether it can be removed or changed without damaging unrelated behavior. The fast screen
is only the first causal localization step; it does not by itself identify the smallest computation.

## 2. The important correction to the fast-screen interpretation

Each screen swaps a donor activation into a recipient example and measures the answer-logit margin. The margin is

$$
m = \text{logit(correct answer)}-\text{logit(foil)}.
$$

For an answer-changing target row, donor recovery is

$$
R=\frac{m_{\mathrm{intervened}}-m_{\mathrm{recipient}}}
        {m_{\mathrm{donor}}-m_{\mathrm{recipient}}}.
$$

The two target families, A1 and A2, ask whether the same site transfers the intended variable in two constructions. P changes the
surface form while preserving the answer. C tests another behavior. The old single pass/fail result mixed two questions:

1. Does the site carry the target variable?
2. What else does the site affect?

That made a shared circuit look like “no circuit” whenever a related C behavior moved too. The new shared profiler selects candidate
sites using only the A1/A2 transfer gates and reports each P/C family separately as a response profile. Residual-stream boundaries are
reported separately as ceilings because replacing the final residual state nearly reproduces the answer by construction.

This changes the correct reading of the numeral experiments. At attention block 8, every numeric-sequence run passes the target gates:
A1 recovery is 74.7%, and A2 recovery is 58.7% or 65.2% depending on the second construction. The same swap transfers the related
numbered-list behavior by 92.4%, but transfers the punctuation control by only 1.36%. Its raw movement on digit-form answer-preserving
edits is 0.695 logit-margin units, versus 0.155 for word-form edits. Thus attention block 8 is a numeric target carrier with strong
overlap with another numeral behavior and a surface-dependent response. It did not disappear when the control changed.

The profiler also exposed a numerical reporting problem. The old normalized P score divided P movement by a scale computed from the
chosen target families. Changing A2 changed that scale, so the same P rows and identical intervention logits were reported as 0.056
and 0.019. The profiler now retains the raw logit-margin movement, which remains 0.155 in both runs.

## 3. Candidate construction is now declarative

Four numeric-sequence experiments differed only in which A2, P, or C family they used. They previously copied the same 222–255-line
row builder four times. They are now four 56–58-line declarations over one shared builder. This reduced the implementation from about
961 repeated lines to 476 total lines including the shared implementation.

The refactor was required to preserve the scientific bytes, not merely produce similar data. At the refactor boundary, all four
experiments preserved every row, specification, model-call manifest, and compiled dry run exactly. Claude then found a pre-existing
misleading label: two experiments used the word-form P family but called its row generator a digit-form rewrite. Correcting that label
changed the specification and compiled-manifest hashes, as it should, while leaving the actual rows and ordered model calls unchanged.
The current golden test pins the corrected versions. In particular, it checks:

- every generated row and its canonical SHA-256 hash;
- the corrected compiled intervention specification;
- the unchanged ordered model-call manifest;
- the corrected dry-run evidence manifest.

One focused test also proves the intended comparison structure: changing C leaves A1/A2/P byte-identical; changing P leaves A1/A2/C
identical; and changing A2 leaves A1/P/C identical. A new family comparison is therefore a small declaration rather than another copy
of the full builder.

## 4. Fast-screen evidence now reaches the canonical circuit queue

The generated campaign queue previously said the subject–verb-agreement circuit had no causal site even though the fast screen had
already found one. The reason was organizational: fast-screen results correctly live in a screen-only ledger, while the canonical
version-2 circuit records drive the campaign queue. There was no reviewed bridge between them, so later work could repeat localization.

A new generic publication adapter provides that bridge. It does not automatically call every screen a circuit. A small publication
spec must explicitly map A1/A2/P/C to families already defined in an existing behavior record, name the existing data split, and name
the nontrivial site being promoted. It then checks the result against the append-only fast-screen ledger, recomputes the site's fixed
gates, records the exact result hash, appends the evidence event, and creates one later claim revision. Re-running the adapter is
idempotent: it produces no duplicate event or claim.

The first migrated result is subject–verb agreement. At the full output of attention block 11, donor replacement produced

$$
R_{A1}=61.90\%,\qquad R_{A2}=60.62\%,
$$

with 100% donor-direction consistency in both target families. The answer-preserving P movement was 3.31% of the registered target
scale, and absolute C recovery was 3.56%; both are below their fixed 20% and 35% limits. The weakest native capability cell was 87.5%,
above its 75% family-specific gate. Attention block 11 and head 11.3 were the two non-residual sites that passed.

The historical overall ranker selected `resid:18`, the trivial final residual ceiling. The publication spec instead records the
passing attention-11 module as the mechanistic candidate and explicitly labels the evidence as FIT-screen-only. The canonical claim is
now `site_live`, not “activation identified.” Consequently, the generated campaign queue now reports causal-site evidence as held and
asks for held-out syntax, selective removal, and sufficiency rather than another localization compiler.
