## Goal

We want to explain MLP0 as a token-only part, a token-by-context part, and a context-only part. For the token-only
part, the immediate question is why MLP0 writes token-dependent information when every block already has a direct
copy of the raw token vector.

## A strong answer from all 50,257 tokens

The new test used the complete length-one token population. We fitted maps in both directions between the raw
normalized token vector and MLP0's bias-free write using four fifths of token IDs, then evaluated the untouched
fifth. We also injected the token-predictable part of the write through the real block1 computation and compared its
causal attention1 and MLP1 effects with native MLP0.

The raw vector and MLP0 write are not related by a simple rotation or accurate global linear reconstruction:

- the best linear write-to-raw map explains 22.7% of raw-vector squared variation;
- the best linear raw-to-write map explains 39.7% of MLP0-write squared variation;
- the best orthogonal map has mean cosine 0.387.

Those numbers miss the registered “simple linear transport” bars. We preserve that negative result.

But squared reconstruction error hides the important structure. Taking the raw-vector prediction decoded from an
MLP0 write and finding its nearest vector among all 50,257 tokens recovers the exact held-out token **90.4% of the
time**, and one of the top five **96.2%** of the time. With shuffled token pairing, both accuracies are zero. MLP0's
write therefore says which token it came from extremely clearly, even though distances and directions are warped.

## Why MLP0 writes this when the raw token is already present

The strongest result comes from causal injection. We took only the part of MLP0's write predicted from the raw token
by the held-out linear map, inserted it in place of the full MLP0 write, and ran native block1. That component explains
only 39.7% of MLP0's write variation, yet it reproduces:

| downstream consequence | response R² | signed-direction cosine |
|---|---:|---:|
| attention1 effect | **0.926** | **0.979** |
| MLP1 effect | **0.972** | **0.986** |
| joined effect | **0.972** | **0.986** |

Here response R² measures how closely the per-token causal changes match after removing MLP0; 1.0 would be exact.

This suggests a concrete role:

> MLP0 rewrites current-token identity into directions that attention1 and MLP1 are prepared to use.

The direct raw-token path tells later blocks which token is present in the embedding coordinate system. MLP0 supplies
a nonlinear, causally aligned version of that identity. The two paths are not redundant merely because both depend
on the same token.

## What the residual means

Subtracting the raw-token-predictable component leaves an exact residual. It is not a small tidy collection of
shared features: its participation rank is 291, compared with 73 for the native write, and injecting it alone has
only 0.247 response R² despite 0.849 of the native response norm. It produces a large response in the wrong mixture
of directions. This explains why the preceding generic sparse code failed: it spent capacity reconstructing broad
activation variation that downstream computation does not value in the same way.

We should not yet call the token component a simple linear copy. Three of four preregistered predictions failed
because Euclidean linear reconstruction was too weak. The precise supported statement is narrower and stronger in
the right currency: exact token identity is highly decodable from the nonlinear write, and a token-predictable slice
is almost sufficient for the immediate causal effect.

## Mathematical next step

MLP0 is exactly quadratic. Under the finite vocabulary distribution, any quadratic function has a canonical
orthogonal-polynomial decomposition:

`constant + best linear function of the raw token + quadratic residual`.

The “best linear function” is the component just tested causally. It can be nonzero because the finite vocabulary is
not a symmetric Gaussian cloud: its third moments let a quadratic function project strongly onto degree-one token
coordinates. The next experiment will factor the exact quadratic token kernel and measure the complete rank curve
of this causally sufficient degree-one component—without enlarging the failed sparse dictionary. That will tell us
whether it is a compact shared token code or a mostly private coordinate conversion.

Only after that token-only object is settled should we transport the same decomposition to the exact token×context
and context×context branches.
