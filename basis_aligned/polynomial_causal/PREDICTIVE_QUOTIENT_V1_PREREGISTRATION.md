# Predictive quotient v1: frozen execution protocol

Date: 2026-08-28

Status: prospective protocol and pure CPU kernel only. This file authorizes no row,
model, validation, final, publication, promotion, or metric observation. The numerical
launcher and source-closed consumer must be committed and reviewed before validation
rows are deserialized.

## Question and exact object

The question is not whether selected MLP0 codes have low Euclidean rank. It is whether
the downstream compiled model distinguishes substantially fewer than 64 naturally
reachable code directions.

Let $z_{bi}\in\mathbb R^{64}$ be the selected executable MLP0 code for row $b$ at
position $i\in[64,256)$. Let $\ell_{bt}(z)$ be the deployed P/P/N student's logits at
scored output position $t$. For a one-position physical edit, define

$$
O_{bi}=\sum_{t=64}^{255}J_{bt,bi}^{\mathsf T}
\left(\operatorname{diag}(p_{bt})-p_{bt}p_{bt}^{\mathsf T}\right)J_{bt,bi},
\qquad
O=\mathbb E_{b,i}[O_{bi}].
$$

This includes every future scored logit which causally reads position $i$. It does not
collapse all code positions into one broadcast edit. This matches the already frozen
transport intervention: one code direction at one registered scored position per row.

The ideal edit-prior covariance $C$ is the exact *unclipped* float64 selected-L0 fit
covariance already bound into `TransportInterventionGeometry`; it describes which edit
directions are natural-sized, not a context-paired reconstruction target. The quotient
spectrum is that of $H=C^{1/2}OC^{1/2}$. For ideal edits drawn independently of context
with covariance $C$, the rank-$d$ tail $\sum_{j>d}\lambda_j$ is exact for the empirical
mean local Fisher quadratic form. It is not exact for reconstructing paired
$(z_x,O_x)$ states, and it is not yet a nonlinear or OOD guarantee.

The frozen 32-direction consequence bank is a separate finite test ensemble: it uses a
clipped square root of $C$, Rademacher draws, and per-direction RMS normalization. Its
finite empirical covariance is therefore not $C$, and the raw-$C$ tail is not claimed
as its exact average loss. Direct per-direction predictions test transport from the
ideal prior to that registered external ensemble.

## Relationship to the older compiler adjoints

The state-complete compiler's object named `empirical_fisher_loss` does not estimate
this $O$. It uses one realized suffix-CE gradient $g_t$ per token, clips its norm,
normalizes the directional loss, and adds a 0.05 Euclidean floor. It was a fit objective
at a frozen teacher state. Predictive quotient v1 instead samples the full categorical
output Fisher, does not clip VJPs, adds no isotropic floor, and evaluates a deployed
student interface. The old adjoints remain a named comparison control; they cannot be
silently reused as the quotient Gramian.

## Frozen student and support

1. Program: the canonical selected true program after suffix validation selection.
   The MLP0 write is its selected-L0 physical code; MLP1 and the suffix execute exactly
   as that selected deployable P/P/N program specifies. There are zero literal native
   MLP0/1/2 calls in the student.
2. Role: all 192 canonical suffix-validation rows, in their frozen 48 batches of four.
   This role may select a quotient but supplies no OOD or final confirmation.
3. Internal graph objects: the complete graph-bearing MLP0 code `[4,256,64]` and
   student logits `[4,256,50304]`, both float32. These are the tensors physically used
   by the suffix and must remain owned inside the source-closed consumer.
4. Retained VJP support: code positions 64:256, shape `[4,192,64]` per probe. Probe
   objectives also use output positions 64:256. Token IDs remain restricted to
   tokenizer support 0:50,257; all 50,304 vocabulary logits remain in each softmax and
   must not be sliced or renormalized.
5. Fisher distribution: the student's own detached softmax distribution. Labels and
   the O/O/N teacher are not inputs to the Gramian.
6. Natural covariance: reuse the canonical fit-role $C$ byte-exactly. Validation codes
   must not replace or refit $C$.

If canonical program selection, row publication, or final lifecycle is incomplete, the
run is NO-GO. A new quotient calculation must not become a side door around those gates.

## Frozen probes and estimator

The primary categorical probe seeds are

```text
2026082860, 2026082861, 2026082862, 2026082863,
2026082864, 2026082865, 2026082866, 2026082867
```

The independent stochastic-replication seeds are

```text
2026082868, 2026082869, 2026082870, 2026082871,
2026082872, 2026082873, 2026082874, 2026082875
```

For each seed and scored output position, draw one $y_{bt}\sim p_{bt}$ by inverse CDF.
Uniforms are generated by a seeded CPU `torch.Generator` in float64, then transferred
to the float32-softmax CDF. Plateau-safe inverse CDF uses
`torch.searchsorted(..., right=True)`. Hash the resulting target IDs into every batch
receipt.

For each probe, differentiate the scalar

$$
S=\sum_{b,t}\log p_{bt}(y_{bt})
$$

with respect to the complete MLP0 code trajectory, and retain positions 64:256. Graph
causality makes each returned vector the sum of independent output probes that can read
that input position. Conditional cross terms vanish in expectation, hence

$$
\mathbb E[\nabla_{z_{bi}}S\,\nabla_{z_{bi}}S^{\mathsf T}]=O_{bi}.
$$

Accumulate only float64 outer-product sums, counts, per-assigned-edit scalar quadratic
responses, target hashes, and closure ledgers. Raw logits, codes, graphs, and VJPs must
not leave the observed consumer. No clipping, centering, isotropic floor, label loss,
or per-batch normalization is permitted. Divide the global outer-product sum by its
global count exactly once.

## Rank and stability rules

Construct primary $O_A$, replication $O_B$, and combined $O=(O_A+O_B)/2$. Solve in
the support of canonical $C$ using float64.

The solver constants are `psd_rtol=1e-10` and `support_rtol=1e-12`. Every reported
spectrum has 64 entries in descending order, with exact zeros outside the covariance
support. The candidate rank is the smallest $d$ retaining at least 95% of
$\sum_j\lambda_j$, but it exists only if $0<d<\operatorname{rank}_{support}(C)$ and
$\lambda_d/\lambda_{d+1}\ge2$. A cut which merely keeps the complete covariance
support is not compression. Otherwise report `no certified knee`.

Before any nonlinear consequence claim, all of the following must hold:

1. primary versus replication relative trace difference, divided by their mean trace,
   is at most 5%;
2. the $L^1$ distance between their trace-normalized spectra is at most 0.10;
3. their independently selected 95%-response ranks, without imposing the gap rule,
   differ by at most two;
4. at the combined cut, normalized chordal distance between the *whitened orthogonal*
   projectors
   $\lVert P_A-P_B\rVert_F/\sqrt{2d}$ is at most 0.15;
5. using the already frozen intervention row permutation, the first and second 96-row
   halves satisfy rules 1--4 with the combined 16-probe bank;
6. all eight frozen orthogonal gauge replays preserve the combined spectrum to
   relative $10^{-8}$ and the physical rank-$d$ projector response to $10^{-6}$.

There is no post-observation increase in probe count, altered cut, alternative row
split, smoothing, or eigenvalue floor. Failure is informative and receives no quotient
dimension.

## Consequences required beyond reconstruction

Let $a$ be the canonical teacher-selected amplitude multiplier times the frozen
`natural_rms`; the half-amplitude is exactly $a/2$. For each row's frozen position and
covariance-shaped direction $\delta$, the local prediction uses its own sketches, not
only the population-average $O$:

$$
\widehat{\mathrm{KL}}_{b}(a)=
\frac{a^2}{2P}\sum_{p=1}^{P}(g_{p,b,i}^{\mathsf T}\delta_b)^2.
$$

The direct response currency is literal per-row

$$
K_b(a)=\sum_{t=64}^{255}\sum_{v=1}^{50304}
p^{(0)}_{btv}\left(\log p^{(0)}_{btv}-\log p^{(a)}_{btv}\right)
=\mathrm{KL}(p_{\rm unedited}\Vert p_{\rm edited}),
$$

summed over all 192 scored positions and the full vocabulary, with no token averaging.
Compare at $a$ and $a/2$. Pooled centered response is
$R^2=1-\sum_b(\widehat K_b-K_b)^2/\sum_b(K_b-\bar K)^2$; a nonpositive denominator
fails. Per-row relative error is
$|\widehat K_b-K_b|/\max(K_b,10^{-12}\text{ nat})$. Required validation consequences:

1. pooled response $R^2\ge0.5$ and median relative error at most 25%;
2. halving amplitude changes median KL by a factor in $[3.2,4.8]$;
3. for each of the 32 registered directions, construct
   $\delta_R=A_d\delta/\operatorname{RMS}(A_d\delta)$ and
   $\delta_D=(I-A_d)\delta/\operatorname{RMS}((I-A_d)\delta)$, where $A_d$ is the
   natural-coordinate quotient map. Any component RMS at most $10^{-12}$ fails the
   comparison. At matched unit coordinate RMS and amplitude $a$, discarded directions
   have median KL at most 10% of retained directions;
4. freeze 16 mixtures by pairing direction $i$ with $i+16$ for $i=0,\ldots,15$,
   adding them, and renormalizing each mixture to unit coordinate RMS. Use the same
   amplitude $a$ and assign the 192 canonical rows evenly by mixture index. Their
   median relative prediction error is at most 30%, testing cross-direction
   composition;
5. the rank-$d$ physical edit projector is invariant under all gauge replays.

After validation freezes $O$, $d$, and every projector, repeat without reselection on
the untouched final role. Final failure is recorded and receives no causal-interface,
OOD, or simplicity credit. A genuinely shifted corpus remains required before calling
the quotient distributionally transported.

## Controls and cheapest falsifiers

- Compare against covariance PCA at the same rank and against the older clipped
  label-CE adjoint Gramian when available on a common legal support.
- Shuffle the per-row VJP summaries among rows while preserving each row's assigned
  edit direction and position. It must lose conditional nonlinear edit prediction;
  shuffling rows of separately averaged $C$ and $O$ would be a void control because
  the quotient theorem uses their product of marginals by design.
- Reject immediately for disconnected code/logit graphs, any native student call,
  vocabulary slicing, graph-bearing tensor escape, target replay, nonfinite VJP,
  incomplete batch counts, or residual broker identity.
- Report execution time separately for model forward, 16 backwards, CPU transfer, and
  float64 reduction. The expected expensive term is repeated backward traversal, not
  FineWeb loading.
