# MLP9 native mixed-state precision discriminator

13 September 2026. Registered before scoring. Previous MLP9 local response passes but correcting its mixed state leaves most behavioral nonadditivity. This tests whether native rounding versus the compiled formula invalidates that conclusion.

160 existing prefixes, 96 regional and 64 FineWeb; six arms: native, child removal, parent removal, remainder removal, parent minus predicted MLP9 mixed state, parent minus actually measured native MLP9 mixed state. Both corrections occur at the same post-block9 boundary, and the remaining native model runs normally. The latter is a diagnostic oracle requiring four native trajectories, not a deployable circuit.

- A: first five outcomes replay the prior experiment within 1e-4 aggregate relative error on each panel.
- B: native-versus-formula correction outcome discrepancy is at most 1% of original final interaction norm in each of eight cells.
- C: native correction leaves more than 50% of original interaction norm in every cell, confirming the prior negative mediation conclusion under this precision control.

Null: local numerical errors amplify enough to change the prior verdict. No bar is weakened in the original experiment. Report raw ratios even if predictions fail.

Descriptive addition: record difference-of-differences of block states and attention/MLP outputs in blocks10–17. Verify block mixed state equals learned residual coefficient times previous mixed state plus attention and MLP mixed outputs, up to native rounding. Record norms and cancellation. This is an algebraic census, not causal localization; a large increment can be generated by nonlinear propagation of an upstream interaction.
