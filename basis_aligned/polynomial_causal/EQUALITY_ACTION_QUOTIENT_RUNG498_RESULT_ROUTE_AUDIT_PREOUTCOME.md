## Decision this experiment actually resolves

Rung498 is not searching for a decomposition. It asks whether one common finite-action observation table can recover
the already established directed relation `L5H5 score -> L8H4 score`, reject a fixed wrong score donor and a fixed
wrong payload donor, and preserve the relation when the earlier donor contribution is removed.

The circuit targets changed by this test are stable identification, selective replacement, and composition. A pass
does not change the simplicity ledger: no parameters or computation are removed. Rank, reconstruction, and average
CE are not discovery criteria.

## Pass route: prospective directed score-reuse graph

If and only if A--E pass, the immediate successor is a separately preregistered search over the four known
equality-attention terms:

`{L5H5, L7H3, L8H3, L8H4}`.

The candidate object is the continuous equality **score**, not the whole head, private query/key coordinates, or
the output/value vector. For every ordered pair with an earlier donor and later recipient, use the same action table,
task masks, circuit fingerprints, document partitions, fixed RMS scaling rule, and early-present/early-absent
backgrounds as rung498. Candidate selection may use only discovery half0. Confirmation freezes the directed edges
on discovery half1; the30 validation circuits and documents500:1000 remain conditional.

An edge means only: the donor score restores the recipient score's dedicated equality effect and downstream circuit
fingerprint under both earlier backgrounds while fixed payload and wrong-score controls fail. Mutual edges may define
an operational equivalence class; one-way edges define directed simulation or reuse, not equality. Heads are never
merged merely because they share one score edge. Their payloads remain separate unless independently interchangeable.

This successor advances cross-head grouping, held-out prediction, selective substitution, and reuse. It dies if the
chosen graph does not reproduce without reselection, if payload controls also pass, or if an edge disappears under
early removal. A later adoption test would still need simultaneous installation of all proposed edges, unrelated-task
preservation, OOD text, and literal program pricing.
