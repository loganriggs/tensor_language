# Hourly strategic review — 2026-08-28 16:05 UTC

## Decision in one paragraph

The early-MLP work should not split into two unrelated projects.  The nearly complete
suffix-transport experiment asks the right causal question: can a replacement for
MLP0 produce a state that MLP1 and the rest of the model can actually use?  The new
empirical fourth-moment machinery asks a narrower representation question: which
small polynomial grammar best approximates an MLP on natural states?  Therefore the
moment machinery is now a candidate grammar *inside* the state-complete/suffix path,
not an alternative local-fit objective.  The highest-priority implementation gap is
the missing semantic final owner and create-only publisher for suffix transport.

## What is actually known about the hard part

1. **The first three MLPs are the dominant current-ship error source.**  On held-out
   rows their Shapley allocation is 0.7277 of the total 0.8727 ship nats; on
   novel-rare tokens it is 1.0776 of 1.176 nats.
2. **They cannot be treated independently.**  Interaction accounts for 43--64% of
   the total absolute effect in the measured token cells.  MLP2 can be harmful by
   itself and helpful after upstream replacement.  This licenses a joint interface
   experiment, not three unrelated compression scores.
3. **The old affine compiler did not supply that interface.**  The authoritative
   state-complete v2.1 run recovered only 33.69% of joint teacher KL and only 26.10%
   of its projected oracle gain.  Good local prediction did not become causal
   replacement fidelity.
4. **Ordinary coefficient rank is the wrong current bet.**  MLP1 and MLP2 both have
   numerical rank 1152 in every measured folded-tensor mode.  Dense Tucker/HOSVD
   loses on storage and product count at almost every registered point.  This does
   not rule out compression on natural activations.
5. **A universal lexical/content code has not been established.**  A prose-trained
   basis captures 16.59% of code variation, only 32.2% of the code-local top-64
   ceiling.  It beats random by about threefold but fails as an OOD-complete
   producer/consumer language.

## Largest missing interfaces

- **MLP0 producer $\rightarrow$ MLP1 consumer:** an executable parent code or
  suffix-selected replacement that beats matched shuffles and false-parent controls.
- **Early package $\rightarrow$ complete ship:** one common-support
  attention $\times$ early-MLP $\times$ deep factorial, so local fidelity can be
  translated into the actual ship CE denominator.
- **Projected upstream state $\rightarrow$ MLP2/3:** a conditional program that
  distinguishes genuine transport from downstream compensation.
- **Attention routing $\rightarrow$ value/content:** a typed account rather than a
  single undifferentiated low-rank matrix.
- **Compression $\rightarrow$ useful simplicity:** equal-fidelity evidence that a
  smaller grammar improves OOD prediction, extraction, selective editing/removal,
  composition, or a certified cost bound.

## Candidate pruning

- **Retained:** finish and run the frozen suffix-transport L/R/S/T discriminator.  It
  directly tests local loss, suffix loss, independently fitted site corrections, and
  physical parent-code transport on one support with causal nulls.
- **Retained but subordinated:** empirical fourth-moment/Wick factorization.  It is a
  cheap way to choose between linear, native-product, CP-like, Tucker, Down, and null
  grammars, but it earns no causal credit until inserted into the transported-state
  experiment.
- **Retained:** the complete early-MLP cube and then the ship macro cube.  These are
  the shortest falsifiable tests of composition and residual CE.
- **Deferred:** direct coefficient-space CP, more HOSVD layers, and norm-minimize then
  HOSVD.  Gauge balancing may improve numerical canonicalization, but it cannot
  change the folded tensor or repair the wrong metric.
- **Deferred:** an MLP0 lexical SAE by itself.  It becomes important when MLP1/2
  readers are jointly sparse in the same overlapping code and edits have low
  non-descendant collateral; feature labels alone do not establish this.
- **Pruned:** more blind gate-count/ridge sweeps or isolated local $R^2$.  Those knobs
  have already produced stable local fits that fail executable causal gates.

## Ranked next five

1. **Complete and audit the suffix-transport semantic final owner and publisher.**
   Highest immediate information gain and almost no GPU cost.  The rest of this
   lifecycle already has 202 passing CPU tests; without the final owner, no legal
   result can be produced.
2. **Execute the frozen L/R/S0/S1/T experiment with all mapped controls.**  This is
   the first experiment that can distinguish wrong local objective from missing
   executable transport.  It is prospective, falsifiable, and directly causal.
3. **Put any admitted early package into the one-support current-ship macro cube.**
   This mints the correct denominator and measures attention/early/deep interactions
   instead of borrowing them from older rows.
4. **Compile MLP2/3 conditionally on the admitted upstream state.**  Independent
   MLP2 compression is scientifically misleading while compensation remains large.
5. **Freeze a held-out map-rank sweep with rank-1 tables.**  The new discovery run
   shows that the embedding-to-row map is 94.3% of the efficient program's stored
   values.  This is now a better certified-simplification target than another table
   rank.  Score CE, OOD, and the existing causal bank, not top-1 alone.

Empirical-M4/Wick selection remains the first fallback grammar if L/R/T rejects the
current affine family, after its audit defects are closed.  Typed attention routing
and value/content compilation is the next large interface after the early block and
the cheap map audit.

This ranking favors expected information gain, causal relevance, whole-model
composability, falsifiability, low GPU cost, and nonredundancy.  A high local
reconstruction score is deliberately insufficient.
