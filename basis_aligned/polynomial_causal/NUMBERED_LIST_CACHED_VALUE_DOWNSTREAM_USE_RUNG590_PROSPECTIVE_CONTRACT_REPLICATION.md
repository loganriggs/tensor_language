## Prospective contract repairs

1. **Evidence-derived reports and terminal.** Primitive capture and intervention rows live in a separate evidence
   artifact. Before publication, R590 independently validates exact authority membership and primitive identities,
   recomputes every FIT/null/SELECT report and bootstrap, derives the first FIT candidate, split opening, interactions,
   predicates, forward count, decision, and next step, and requires exact equality with the result.
2. **Unretained exactness failures hard-abort.** Native replay and tensor reconstruction checks whose full tensors are
   not retained must all be at most `1e-10` immediately after each FIT or SELECT capture. Otherwise execution aborts
   before staging or final publication. Such a failure cannot become `downstream_use_decomposition_null`.
3. **Atomic package.** Evidence, result, and receipt are written and validated in one unique same-filesystem stage.
   Final publication uses atomic renames with the receipt last as commit marker. The result binds the evidence digest;
   the receipt binds both result and evidence bytes. Recognizable interrupted R590 stages/partials are quarantined by
   the managed adapter before unused-namespace checks; complete or arbitrary occupied paths are refused untouched.
4. **Forward-call shape authority.** A model-free manifest enumerates every possible high-level source-model call:
   source-present trajectory, source-deleted trajectory, native smoke replay, real component suffix, and null component
   suffix. Each records split, logical batch membership, batch size, sequence length, and a dynamic-token-matrix
   validation mode. The registered batches are at most 24 rows and use their exact common token length. The dry run
   rejects fixed `(4,256)` validation or any hidden/missing call before enqueue while retaining separate checkpoint and
   model-structure validation at load time.
5. **Phase-specific panel support.** Following the shared v5 handoff, R590 emits and hashes the exact ordered row IDs
   and the split-by-condition-by-representation-by-source-level census. Because this replication evaluates the whole
   authorized panel rather than sampling it, FIT must contain all 576 authorized FIT rows (16 in each of 36 cells) and
   SELECT, if opened, must contain all 288 authorized SELECT rows (8 in each cell). Missing cells, rows from another
   split, replacement/duplicate rows, or silent panel shrinkage fail before publication.
