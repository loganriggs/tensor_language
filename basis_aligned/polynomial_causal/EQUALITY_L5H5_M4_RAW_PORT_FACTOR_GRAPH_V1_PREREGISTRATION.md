an input.  This prospective extraction test removes that oracle port.  A new
standalone executor accepts only derived/native raw `Q1,K1,Q2,K2` head ports
and rotary cosine/sine, then performs native head normalization, rotation,
factor products, and arithmetic-residual construction internally.

On the same frozen 192 natural and 192 code documents:

1. Raw-port graph score closure must be at most `2e-6` relative L2.
2. Its full behavioral additive arm must match the exact interaction authority
   within `2e-5` relative L2 and cosine at least `.99999` in every subtype and
   half on both panels.
3. Each of the four raw-port node-removal effect norms must match the validated
   precision-factor parent within `.002` absolute on copy-positive and both
   halves on both panels.
4. Each node's incremental noncopy mean must match the parent within `2e-5`
   nat, and the arithmetic-roll effect cosine must match within `.002`.
5. The package declares zero oracle score inputs, zero learned parameters, four
   nonconstant nodes, and 16 native Q/K projections.

Failure of gates 1–2 is invalid.  Later failure is an extraction-equivalence
null.  This test does not claim to reduce the upstream projection count.

no fits, gradients, parameter updates, or new text.
