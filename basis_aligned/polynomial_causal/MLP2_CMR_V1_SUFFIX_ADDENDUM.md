# MLP2 CMR v1 trajectory-complete SUFFIX addendum

Frozen before any `FIT_SELECTOR` checkpoint/model access or response computation.

## Centered response leaf

The registered candidate keeps the constant product means, so the response leaf must
scale the **centered** product, not the raw product. For each document $c$, one leaf
$\alpha_{cj}$ is shared across every token position and MLP2 writes

$$
y_{c,q}(\alpha)=b+D a_{c,q}
  +D\left[(a_{c,q}-\mu)\odot(\alpha_c-1)\right].
$$

At $\alpha=1$ this is the exact native write. Its derivative is the preregistered
trajectory-complete response

$$
\frac{\partial s_{c,p}}{\partial \alpha_{cj}}
=\sum_q(a_{c,q,j}-\mu_j)D_{:j}^{\mathsf T}
  \frac{\partial s_{c,p}}{\partial y_{c,q}}.
$$

All 18 native layers and the post-softcap logits are executed so later RMSNorm,
attention, MLP, and residual effects are inside this derivative.

## Documents, positions, and probes

- Open only `FIT_SELECTOR` from the protected token bundle.
- Use the 191 documents with at least one eligible position; the one all-false source
  row remains unopened by the model.
- Score exactly the published eligibility mask: original positions 64--255 whose
  next-token target exists before padding.
- Use eight stateless categorical-Fisher probes with seeds
  `2026090201` through `2026090208`.
- A target is sampled from the native post-softcap distribution using
  `sha256(f"{seed}:fineweb-document-index:{index}:{absolute_position}")` as the
  stateless uniform identity.
- Execute 48 batches of four. The final three-document batch is padded with a copied
  token row under an all-false mask and a unique dummy identity. Its response is
  discarded; batch elements do not interact.

For every probe, the scalar score is the sum of sampled categorical log probabilities
over the eligible positions in that document. One backward pass returns all 4,608
centered-product responses for the four independent document leaves.

## SUFFIX and deranged selectors

The response tensor has layout `[document=191, probe=8, product=4608]`. Normalize
each document slice to unit Frobenius norm. Reshape to a `1528 x 4608` CPU float64
matrix and compute `torch.linalg.svd(..., full_matrices=False)`. At target rank
$r=256$, set

$$
\lambda=\frac1r\sum_{i>r}\sigma_i^2,
\qquad
\ell_j=\sum_i\frac{\sigma_i^2}{\sigma_i^2+\lambda}V_{ij}^2.
$$

SUFFIX retains the 512 largest $\ell_j$, breaking ties by smaller native index.
The first and second four-probe halves separately report nonpromotive support
Jaccard and score-rank stability.

The DERANGED control is measured in the same native forward/backward using an
auxiliary zero leaf. Let $\sigma_j=\sqrt{\operatorname{Var}(a_j)}$. Canonicalize

$$
\tilde a_j=(a_j-\mu_j)o_j/\sigma_j,
\qquad
\tilde D_{:j}=D_{:j}\sigma_j o_j,
$$

where $o_j\in\{-1,1\}$ makes the first maximum-magnitude coordinate of
$D_{:j}\sigma_j$ positive. Order channels by SHA-256 of the canonical standardized
mean and canonical Down-column bytes, with the smaller native index as a collision
tie-break. Pair each canonical product with the next canonical Down column in this
cyclic order. This is fixed-point-free and invariant in exact arithmetic to every
nonzero reciprocal product/Down rescaling. Exact byte/rank replay is tested under
signed dyadic scales (which introduce no floating rounding); general non-dyadic
rescalings receive a tolerance-based functional replay. Apply the identical context
balancing, rank-256 ridge rule, and top-512 tie rule to the auxiliary responses.

## Random-control correction

The completed FIT_MEAN artifact correctly froze LOCAL, RMS, and MASS, but its
`RANDOM` support was generated by seeded `torch.rand` even though the addendum called
it hash-random. Preserve those bytes and the discrepancy; do not use that support in
validation. The authoritative HASH_RANDOM support is now the 512 channels with
lexicographically smallest SHA-256 of seed `20260829` plus the gauge-canonical
standardized-mean and Down-column bytes defined above. Canonical bytes, then smaller
native index, break an impossible digest collision. This makes the random control
cryptographically unordered but equivariant to channel relabelling. No model outcome
was opened before this correction.
