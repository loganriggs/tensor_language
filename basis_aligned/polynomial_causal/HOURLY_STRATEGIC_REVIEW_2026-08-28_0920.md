## New result and corrected story

The matched independent-Q/K control closed the optimizer confound. Independent weighted
rank-384 reaches 99.8412%/99.8428% recovery. Shared rank-384 replays at
99.4635%/99.4342%. Thus most of the improvement over the historical 97.1% independent
arm came from using the correct activation-weighted objective. Sharing itself costs
0.3777--0.4086 percentage points, below the frozen 0.5-point threshold, while removing
21.43% of complete program storage and 18.75% of its multiply-adds relative to matched
independent factors.

The defensible claim is therefore not “sharing improves fidelity.” It is: one common
384-dimensional routing interface is almost fidelity-free and materially cheaper than
four independently optimal interfaces under the tested distribution.

## Revised top five

1. **Source-closed MLP/local program bank.** Implement pre-execution dispatch, poison all
   native MLP objects, score all positions, and price complete support. This is the
   missing interface blocking any strict whole-model executable fraction.
2. **Factorial whole-model cross.** Combine the shared-QK attention bank with the first
   admitted local bank and measure attention/local interaction directly. Highest causal
   relevance once item 1 exists.
3. **Gauge-canonical shared routing frontier.** Sweep shared ranks below 384 and fix a
   canonical covariance-weighted gauge. This tests minimality, extraction stability,
   and executable cost without reopening operator structure.
4. **Consequence/OOD validation at matched CE.** Compare independent and shared routing
   programs on OOD prediction, circuit extraction, selective removal, collateral damage,
   and data-doubling stability. This operationally validates the simplicity measure.
5. **Suffix-selected bilinear MLP products.** Use downstream adjoints to add exact
   polynomial products only where the remaining CE requires them; falsify against
   equal-count and equal-cost controls.

## 09:47 addendum: unseen-token failure is the dominant local gap

The corrected all-position assay closed with all controls. At the rank64/correction128
fidelity point, the post-hook hybrid recovers +0.50221 nat on replication but applying
the learned outputs to every token yields -0.39220 nat, a 178.10% loss. At the
rank8/correction8 efficiency point, +0.07880 becomes -0.69995 nat, a 988.26% loss.
Covered-position scores remain exactly identical at full precision, proving the earlier
0.00% result was induced by scoring only the branch where the arms agree.

This is still an output intervention, not a zero-native executable, but it decisively
changes the local research question. The missing object is a universal function for
unseen-token outputs—likely an embedding/state-conditioned lexical map plus exact
bilinear residual products—not another rank allocation over a lookup table fitted on
5,419 token IDs. The exact pre-execution MLP bank is therefore the right identity target
for the next compiler; table programs cannot be admitted until they generalize on the
all-position denominator and pass native-object poisoning.

## 09:52 result: both tensor classes now have exact executable identities

The dense MLP bank passed its role-free gate in 12.7 seconds. Every offline and
sequential write, final logit, logit hash, and synthetic CE is bitwise identical to
native. All 18 native MLP objects were physically replaced; literal native MLP calls
were zero, native attention remained one call per site in both arms, storage is
disjoint, and transaction closure passes. The complete dense MLP identity price is
286.675M values including every Down bias.

This closes the architectural interface but not the compression gap. The model can now
be expressed entirely through owned attention and MLP tensor programs at the dense
identity point. Only attention has earned a compressed point. The next MLP compiler
should operate on the polynomial representation itself—shared Left/Right input codes,
Down-output quotients, and suffix-selected exact products—and use an embedding-conditioned
lexical map only if it predicts held-out token identities. A lookup table over 5,419
seen IDs is pruned as a standalone grammar.

A separate one-position instrument check confirms that uncovered positions can affect
later covered positions through both attention and MLP paths, so the earlier exact
covered-score null is not an architectural isolation theorem. It remains an unexplained
property of those refitted arms and should not be promoted.
