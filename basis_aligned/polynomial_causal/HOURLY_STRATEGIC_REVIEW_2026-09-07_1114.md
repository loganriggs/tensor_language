# Hourly strategic review — 2026-09-07 11:14 UTC

## Circuit interpretation targets and full goal

The controlling targets remain: (1) specify what is read, computed, written, and later
used; (2) group cross-module pieces and split native modules when function demands it;
(3) predict held-out/OOD behavior; (4) extract a sufficient executable interface;
(5) selectively remove, swap, and edit it; (6) predict composition and reuse across
tasks; and (7) identify it stably across corpora, gauges, and fits.  The program-level
goal remains a smaller transparent tensor program that is predictive, composable,
manipulable, and honestly cheaper in literal storage/compute/edges/state.  Rank or KL
improvement alone cannot satisfy it.

## Alternative routes and ranking

1. **Corrected full-patch task-mode weight-edge atlas.** Targets: computation,
   grouping/splitting, stable identification.  Measurement: task-by-source-by-response
   incidence, own/cross energy, exact-weight closure, and additive residual.  Kill it if
   causal incidence is diffuse, task typing disappears under the corrected ratio, or
   exact weights fail to close.  This remains highest information and is live.
2. **Joint top-edge/complement factorial.** Targets: extraction and selective
   manipulation.  Measurement: jointly patch the v2-ranked task edge set, its
   complement, and cross-task set; demand held-out behavior and response-coordinate
   recovery.  Kill simple edge additivity if the joint set follows neither singleton
   prediction nor a stable signed interaction correction.
3. **Genuinely new task bank without refitting.** Targets: OOD prediction and stable
   identification.  Measurement: capability-only new temporal and is-was constructions,
   then one frozen rank46/rank4/rank8 comparison.  Kill the current task programs if
   rank-four typing or rank46 support fails prospectively.
4. **Multi-environment finite-operator DAS.** Targets: stable identification and reuse.
   Measurement: hard DIM-level feasibility on every task/reader family, then complement
   plus centered-logit KL selection, with a complete family unopened.  Kill optimized
   DAS if complete-family selection again chooses DIM/step zero.  It remains downstream
   of the weight-edge atlas because the atlas defines the missing readers.
5. **Predictive-state/Hankel realization.** This could canonicalize state across task
   families, but it is demoted until the edge/intervention table supplies enough distinct
   input-output experiments; otherwise Hankel rank would be another descriptive rank.

The current route survives the alternatives because it converts the already causal
task subspaces into named native writers/readers and immediately yields a selective
joint patch test.  It is not a capacity sweep: the decisive measurements are edge
causality, task interchange, weight closure, and joint manipulation.
