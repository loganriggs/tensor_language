# Rung501 preregistration — directed finite-action graph among four equality scores

**Registered:** 2026-09-02 18:24 UTC

**Parent:** rung500's fully calibrated copy-task plus MLP9 reader observation.

**Claim level:** prospective directed relation discovery below whole-head boundaries. A validated edge means one
continuous equality score can supply another score's task and named-reader effects under registered actions. It is
not whole-head equivalence, a complete circuit, or compression.

## Fixed objects and directed candidates

The four known equality terms are `L5H5`, `L7H3`, `L8H3`, and `L8H4`. Test every causally available earlier-to-later
score substitution plus both directions between the simultaneous layer8 heads:

1. `L5H5 -> L7H3`;
2. `L5H5 -> L8H3`;
3. `L5H5 -> L8H4` (live known-positive tripwire);
4. `L7H3 -> L8H3`;
5. `L7H3 -> L8H4` (live known-negative tripwire);
6. `L8H3 -> L8H4`; and
7. `L8H4 -> L8H3`.

The donor object is only its continuous equality score matrix. The recipient keeps its own payload—the source-token
values after its value and output maps. Whole-donor and payload-donor arms are retained as typed controls. One-way
edges mean directed simulation/reuse. Only the two same-layer directions can form a mutual operational equivalence,
and only if both independently validate.

## Frozen scales and actions

For each ordered pair, fit only two RMS ratios on rung459's fixed96 fit documents: donor-to-recipient equality-score
RMS and donor-to-recipient payload RMS. All seven pairs are computed in one analytical pass per batch, with no loss,
reader, or candidate outcome. These scales are then frozen.

For every pair on the1000 circuit-census documents, evaluate the recipient as native, absent, donor-score,
donor-payload, and whole-donor under donor-present and donor-absent backgrounds. The complete model suffix runs after
every edit. Compute final per-token CE and MLP9's1,152-dimensional write-response sufficient statistics using rung500's
exact copy-positive, non-copy-equality, and all-non-copy masks.

## Data partitions and no reselection

- selection: documents0:250;
- confirmation: documents250:500;
- conditional validation: documents500:750 and750:1000.

All seven candidates are scored against fixed thresholds; there is no best-pair ranking. A candidate edge is selected
only on the first partition and must reproduce without threshold or scale changes on confirmation. Validation opens
only if the known positive passes, the known negative fails, all instrument clauses hold, and at least one *new* edge
survives confirmation. All confirmation survivors enter validation; none may be dropped.

## Edge criteria in one partition

An ordered pair is an edge only if, under both donor-present and donor-absent backgrounds:

1. copy-task recovery lies in `[.65,1.40]`, per-document effect cosine is at least`.75`, positive-scale residual is at
   most`.70`, and off-target CE change is at most`.01 nat`;
2. MLP9 copy-response cosine is at least`.75`, positive-scale residual is at most`.70`, and native/hybrid response
   RMS are each at least`1e-4` of MLP9's native write RMS;
3. the score hybrid beats its same-donor payload control in MLP9 response by`.30` cosine or`.30` residual;
4. MLP9 copy cosine exceeds both non-copy controls by`.10`; and
5. donor-present versus donor-absent score-hybrid MLP9 responses have cosine at least`.75`, while task recovery changes
   by at most`.30` and the fitted MLP9 scale changes by at most50%.

These are rung499/rung500's calibrated bars, with only the task-recovery interval widened from`.75-1.30` to
`.65-1.40` for discovery. No rank, weight similarity, or generic circuit-battery coordinate enters edge selection.

## Predictions

### A — exact, live, and isolated instrument

All hashes/parents match; the96-row scale pass uses exactly24 analytical forwards and no outcomes; native/replay logits
and MLP9 writes are exact; factor reconstruction is at most`1e-10`; every action is live; all task cells have support;
call/capture counts equal the precomputed formula; and validation remains unopened unless B/C/D hold.

### B — calibration tripwires reproduce

`L5H5 -> L8H4` is an edge on selection and confirmation. `L7H3 -> L8H4` is not an edge on either and has negative
copy-task and MLP9 response cosine under both backgrounds. Failure invalidates this search observation even if another
candidate looks strong.

### C — at least one new confirmed directed edge

At least one of the other five candidates is an edge on selection and independently on confirmation. The set of
confirmed new edges is frozen before validation.

### D — graph semantics remain typed

Every confirmed edge rejects its payload control in both discovery partitions. A same-layer equivalence is named only
if both `L8H3 -> L8H4` and `L8H4 -> L8H3` confirm; otherwise report directed edges individually. No whole-head grouping
is inferred.

### E — held-out graph validation

Conditional on A--D, every confirmed edge repeats all five edge criteria in both validation quarters, the known
positive remains an edge, and the known negative remains anti-aligned and absent. The graph is the intersection of
confirmation and both validation-quarter edge sets; no failed edge is retained.

### F — interpretation and next adoption test

F requires A--E. Each retained edge identifies a reusable copy-score computation according to downstream task and
MLP9 use. The next step is simultaneous installation/removal of the retained edges with unrelated-task and OOD
controls, followed by literal program pricing. Rung501 itself saves and adds zero deployed parameters.

## Null routing and price

A failure repairs only the instrument. B failure retires this graph assay. A/B true but C false means the calibrated
known edge is isolated among this family. D failure means apparent edges confuse score and payload. E failure leaves
discovery-only candidates with no graph claim. None routes to rank/SAE/quantization.

The unoptimized action price is one direct native plus one analytical replay plus nine nonshared actions per pair:
`65 forwards/batch`. Discovery therefore costs`8,125` forwards and conditional validation another`8,125`, plus24
