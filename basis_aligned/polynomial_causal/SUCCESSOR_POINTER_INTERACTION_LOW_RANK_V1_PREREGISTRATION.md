# Successor pointer cross-type interaction low-rank V1

The registered attention/MLP8–12 response mediator contains a large negative cross-type interaction at the final residual. This experiment asks whether that 1152D calibration term has a low-dimensional interaction basis that transfers to a new sequence length. It does not refit or compress the attention and MLP component responses.

FIT is every frozen length-six group (five month, three digit). HOLDOUT is the outcome-blind length-seven authority frozen before this preregistration (four month, two digit). For each dataset and aligned condition, capture native final residuals after transplanting coherent attention8–12 only (`A`), MLP8–12 only (`M`), or both (`AM`). Define the cross-type residual interaction exactly as `I = r_AM - r_A - r_M + r_native`.

Fit an uncentered SVD basis to the eight FIT late-swap interaction rows only. Evaluate ranks 1, 2, 4, and 8. For each row and rank, use the row's orthogonal projection coefficients and form `r_synth = r_A + r_M - r_native + projection(I)`. Apply the native final RMS, unembedding, and tanh softcap directly. Select the smallest rank whose FIT synthetic arm, in both families, has backward-margin projection 0.80–1.20 and cosine >= .95 versus the exact `AM` effect; recovers >= .80 of full-vocabulary `AM` logit RMS; and keeps late-forward and early-backward RMS at <= .50 of the native backward target. If no rank passes, HOLDOUT remains sealed.

Freeze the selected FIT basis and apply it without refit to the length-seven late and early interaction rows, still using row-specific orthogonal projection coefficients. HOLDOUT must meet the same bars in both families. Report basis energy and all component, exact interaction, additive-state, projected-state, readout-exactness, and control metrics for every rank opened. A pass establishes low-dimensional interaction coordinates only; coefficient generation, component compression, and a non-oracle executable interface remain external.

The exact self and all-module ceilings must pass on both lengths, and direct readout of cached late-native residuals must reproduce model logits within `1e-5`. Price: 22 full forwards, 154 sequence evaluations, zero gradients/updates, plus 90 explicitly counted final-readout row evaluations (14 native exactness, 64 FIT rank arms, and 12 selected-rank HOLDOUT arms). No centered PCA, gain, fallback rank after HOLDOUT, subgroup, row repair, threshold change, or quantization.
