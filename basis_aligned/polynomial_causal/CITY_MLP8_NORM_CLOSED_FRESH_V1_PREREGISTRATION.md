# CITY_MLP8_NORM_CLOSED_FRESH_V1 preregistration

## Purpose

Confirm the norm-closed MLP8 value mediator on a fresh FineWeb panel. The earlier norm-closed result used opened mediator fixtures; this run must not reuse those rows for the primary gates.

## Frozen design

- Select the first 20 eligible FineWeb documents after the frozen selector state advances beyond the prior 20-document mediator panel; use 40 sequences, 240 fixed probes, and record the capable-pair count.
- Use the installed norm-closed interface with native `z8`, upstream value delta, token IDs, and no supplied edited RMS9. Keep the full native suffix for readout evaluation.
- Use the validating worker and persist row hashes before result computation. A dataset-library interpreter abort is an invalid execution, not a result; reproduce with the worker or stop.

## Gates

1. **Prediction:** norm-closed generated RMS/readout must replay the native mediator reference with relative effect error at most 0.05 and no sign-changing numerical mismatch attributable to the interface.
2. **Direction:** at least 90% of capable corrected swaps positive; report the count and document-level reversals.
3. **Preservation:** global and reversed-subgroup controls at most 0.35 of the target effect; report both, even if the global gate passes.
4. **Null:** all 16 same-boundary norm-preserving random controls beaten by the real correction.
5. **Interface:** installed and isolated replays must match the local norm-closed program within the declared numerical tolerance.

## Interpretation rule

Passing these gates establishes a fresh norm-closed mediator at its declared native boundary. It does not establish token-only execution, full-suffix extraction, independent direct/MLP8 composition, or simplicity. Any reversed subgroup or composition failure remains a failure of the corresponding property.
