# Subject-number direction-cardinality rank-one compression V1

The registered subject-number program stores ten fixed 1152D direction-by-background-cardinality L11H3 writes plus two unchanged direction vectors. A weights-only CPU factorization of the ten writes, without reading third-corpus causal outcomes, shows that one uncentered SVD axis captures 98.85% of aggregate write energy. This experiment freezes rank one directly; it does not sweep ranks or refit against behavior.

Replace each of the ten cardinality writes by `alpha[direction, cardinality] * axis`, using one shared 1152D axis and ten stored scalars. Keep the two direction-only vectors charged and unchanged, though they need no repeated intervention arm. On all 32 rows and 16 E/A/U/W background subsets of the existing prospective third-corpus authority, evaluate base, native exact, original cardinality, and compressed rank-one cardinality arms.

The compressed arm must reproduce the original installed program with cosine >= .98, relative L2 error <= .20, and sign agreement >= .95. Against native exact effects it must independently meet the registered original bars globally, on intermediate cardinalities, and within both templates: global cosine >= .75, relative L2 <= .75, sign agreement >= .75; intermediate cosine >= .70, error <= .85, sign >= .70; each template cosine >= .65, error <= .90, sign >= .65. Exact closure must remain <= `5e-5`. No gain, offset, row coefficient, new reader, target fit, rank fallback, or quantization is allowed.

The write bank shrinks from 11,520 to 1,162 FP32 scalars (10.09% retained). Charging the two unchanged 1152D direction vectors, the declared interface shrinks from 13,824 to 3,466 scalars (25.07% retained). This is a causal compression screen on an already known authority; a pass still requires fresh-construction confirmation before stable reuse is claimed. Price remains nine physical forwards, 2,144 example evaluations, and 2,048 causal installations, with zero gradients or updates.
