# `is`/`was` structural holdout v26 native-capability gate

## Why v26 exists

V25 was the first genuinely structure-diverse bank. Its capability-only receipt showed that the
model natively supported four complete target/control structure pairs: fronted era phrases,
subordinate-clause prefixes, reported-source frames, and postnominal temporal modifiers. The other
four pairs failed at the construction level. V26 is a new held-out authority over those four
supported structure families, with 16 new compound profession phrases and no reused prompt text or
row IDs. It does not select individual v25 successes.

The 64 rows contain four target constructions and four matched controls. Each construction has
eight rows, four in each direction. Every base/donor pair is token-position aligned. Prompt lengths
are measured from the sealed authority before execution.

## Capability-only execution

Run the native model on every base and donor prompt in exactly two forwards (128 sequence
evaluations). For every construction x direction x side cell (four rows), require at least 3/4
correct. For every construction (eight rows), require at least 6/8 rows jointly correct on both
base and donor. These are construction-level gates; no row may be removed after outcomes.

Registered predictions:

A. The hash-bound authority, v25 null receipt, history disjointness, four target structures, four
   matched controls, pairwise alignment, exact population, observed length range, and price pass.
B. All four target constructions pass native capability.
C. All four matched control constructions pass native capability.
D. No causal outcome is accessed and price is exactly two forwards / 128 sequence evaluations.

Any A/D failure is invalid. Any B/C failure is an honest native-capability null and opens no causal
outcome. Only an all-pass receipt can license a separately preregistered structural causal test.
