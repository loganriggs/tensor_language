# Does one upstream joint-command state feed the shared readers?

The fixed four-head native shared-read interaction is material; crossed routing
and payload alone miss75–78% of its mixed write. Test whether a common upstream
joint-command residual component supplies that interaction, versus interactions
generated later from separate command features. This is a causal grouping test,
not a new structural reduction or claim that four-cell contrasts are a standalone
circuit. Prior-art search distinguishes MLP11 factor rescue and generic command
response modes from this shared boundary intervention.

Fixed boundary: output residual state after zero-based block8, immediately before
the first selected consumer L9H1/H4. Fixed consumers remain L9H1/H4,L11H3,L15H5,
both queries, all32 opened worlds/128sequences and both phases/all templates.
No boundary/head/source search or post-result choice. First-value memory and
original-embedding input stay native. At all positions compute

    r'_ab = r_ab - (-1)^(a+b) r_hat11.

r_hat11=(r00-r01-r10+r11)/4 in FP64, return r' in deployedFP32. This preserves
mean and separate command modes algebraically while removing the mixed mode.
It is a specified cross-cell internal-state intervention; r' need not correspond
to a naturally occurring token sequence. Its computation requires all four cells
and the native prefix; it is not an independently identified semantic variable.
