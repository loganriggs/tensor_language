# Reader-facing explanations

This directory answers a different question from the experiment logs:

> What do we currently think the model is doing, why do we think it, and what is
> still missing?

Start with [What “understood” means](00_WHAT_UNDERSTOOD_MEANS.md), then read the
component chapters:

- [MLP0](01_MLP0.md)
- [MLP1](02_MLP1.md)
- [MLP2](03_MLP2.md)
- [MLP3](04_MLP3.md)
- [MLP4](05_MLP4.md)
- [Attention](06_ATTENTION.md)

## Required structure for every component chapter

1. **Native computation:** the exact operation implemented by the checkpoint.
2. **Simpler recovered program:** what replacement reproduces the operation.
3. **Semantic hypothesis:** what information the operation appears to represent or
   transform in human terms.
4. **Causal evidence:** replacement, removal, patching, composition, and OOD tests.
5. **Counterevidence:** failed predictions and evidence against an overly neat story.
6. **Unresolved residue:** what behavior and dependencies remain live.
7. **Confidence:** separate confidence in the algebra, computational surrogate,
   causal role, and semantic interpretation.

“High-fidelity replacement” and “semantic understanding” are not synonyms. A lookup
table can reproduce a function while explaining little; a named feature can sound
meaningful while causing almost no behavior. A component is only strongly understood
when both sides meet and survive composition and distribution shift.

## Math and figures

The prose uses standard LaTeX delimiters (`$...$` and `$$...$$`) so it can be
converted to MathJax/KaTeX HTML without rewriting equations. Figures embedded in the
chapters are real PNG files, not Mermaid source or textual placeholders. SVG versions
are retained for later HTML publication.

Figures are reproducibly generated by
[`assets/render_explanation_figures.py`](assets/render_explanation_figures.py) from
checked-in result JSON where a quantitative plot is possible. Any explicitly
editorial maturity graphic is labeled as such and must not be mistaken for a metric.

## Evidence labels

- **Exact:** follows algebraically from the implemented forward pass.
- **Measured:** directly reported by a checked-in intervention or evaluation.
- **Supported interpretation:** multiple measurements agree, but the semantic label
  is still an inference.
- **Hypothesis:** plausible and testable, without decisive causal evidence.
- **Unknown:** the current evidence does not identify it.

Every important number links to its source artifact. The experiment files remain the
authority if this prose and the data ever disagree.
